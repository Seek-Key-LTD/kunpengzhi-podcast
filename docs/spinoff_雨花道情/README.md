# 《雨花道情》· 专栏档案与大纲总则

> **主理人**：**紫金**（法定真名 **王佑德**，Jude Wang；江湖浑名 **王永乐** · 中科大天文与南大历史双聘 · 43岁）  
> **地标**：南京雨花台 / 紫金山天文台下茶肆 / 合肥科学岛  
> **核心立意**：**"我卖的不是星星，是下一次能一起抬头的时间表。"**  
> **阵营**：深空校表人 · 报盘与核账两头跑 · 会脸红的带货讲师

---

## 一、专栏题眼解剖

1. **"雨花"的两重账**：
   - **雨花石**：一块河滩石头凭什么值钱？它是**注意力拟制稀缺**的最小样本——与黄金（超新星遗骸）、石油（古生物尸油）同属一科，只是它的锚完全在人眼里。**《雨花道情》的题眼就是"石头为什么值钱"**；
   - **雨花台**：刑场。道情在此开口，天生带一层"向后看的账唱到头空"的意思。
2. **"道情"的文体义**：一把渔鼓、两片简板，唱的从来是**出世之眼冷观入世之局**——叹世、劝世、财富到头空。**道情是讣告体**，正是给"尸体本位制"写讣告的那支曲子。
3. **紫金的自我限制**（承 EP01 刍议）：任何推断必须把观测、计算、解释、制度选择分开标注；**不能复算、不能说明误差、不能提出撤回条件的，只能算故事，不能算账**。

## 二、双名分工律（本栏第一规矩 · 违此即塌栏目）

紫金在剧中出场两次，**不是重复，是复式记账的两条腿**：

| | **王佑德**（本名） | **王永乐**（浑名） |
|---|---|---|
| 出处 | 法统金榜法定真名，"天佑其德" | 江湖浑名，中科大众科普口径 |
| 主场 | S01《道名记》明史：靖难、大礼议、字做账 | S08.5《天权记》深空单口硬核推导 |
| 语法 | **证真**：可复算、可撤回、可审计 | **报价**：预售一个尚未抵达的窗口 |
| 能不能卖货 | **不能** | **能** |

年号在明代就是唯一的公共时间标准——**奉正朔即承认谁的表**。所以"王永乐"这个名字本身就是校表权的化身，而"王佑德"是验表的那一个。

> **铁律：王佑德不卖货，王永乐不核账。**
>
> 串一次线，人物就废——观众会立刻认出他变成了李永乐的山寨版，而那正是全栏目唯一不能发生的事故。
>
> **李永乐不带货，所以他才是李永乐**：他没有任何敞口。紫金会卖，而且卖的是尚未发生的事；人类只有一样东西能给"未到账的未来"定价，就是**可复核的时间表**。严谨在这里不是清高，是他这门生意的许可证。

## 三、单期结构规格（节奏引擎）

《廊桥疑梦》靠解剖学推进；《雨花道情》靠**两个名在一期之内互相切换**推进：

1. **起板 · 报盘（约 90″，王永乐，〔戏〕）**：道情唱两句，挂小蜜蜂，先亮收款码。**货在前，理在后**——纲领九章拖到最后一章才掏二维码，是同一个毛病的正面教材。
2. **拆账 · 核（约 20′，王佑德，〔史〕/〔推〕/〔设〕）**：粉笔上黑板。**这一段不许有货、不许有梗，只许有误差范围与撤回条件。**
3. **收板 · 还原（约 30″）**：*"天地这本大账，今晚且唱到这！"*——这句是从年号切回本名的开关，简板一收，货下架，人还原。

**〔戏〕字幕规矩**（承 EP01）：所有"发财"结论一律标〔戏〕；天体数据、轨道计算、观测方法仍按〔史〕/〔推〕/〔设〕分栏。

## 五、限界

- 本栏只管**头顶的引力、脚下的年号、以及"未来如何被共同定价"**；地表断层归黄鹤，湖相岩心归敦煌，深海大洋归琅琊，大气响应归番禺，古DNA归良渚，资产负债表与货币史正章归渔阳，条约文本归珞珈。
- 固定对手位：**青衣**弹优惠券与递润喉糖，**珞珈**在评论区刷"请先阅读现行规则"——他一被提醒就装信号断了，随后乖乖把免责声明贴到屏幕上。
