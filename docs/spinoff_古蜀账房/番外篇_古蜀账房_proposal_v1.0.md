# 《三更道场》番外篇 ·《古蜀账房》Proposal

## 一、定位（股价）

**一句话**：用复式记账法清算三星堆与金沙的千年糊涂账。

**核心差异**：
- 别人讲"挖出来了什么"——我们讲"这东西在账上怎么平"
- 别人做考古科普——我们做**审计报告**
- 每集一个"糊涂账"，用经济学/力学/音韵学/贸易网络的框架，重新解码已出土文物

**调性**：比正片更松弛，三个老头在茶台抽烟喝茶打算盘，想到哪聊到哪，但最后必须有渔阳的"封账"环节兜底。

---

## 二、目标受众

1. 正片观众（已接受三更道场方法论）
2. 对三星堆/古蜀文明好奇、但不满意主流"神秘文明"叙事的人
3. 喜欢硬核考据+生猛表达的硬核听众

## 四、形式规范

### 角色配置（三人茶台，无青衣）

| 角色 | 定位 | 口头禅/动作 |
|---|---|---|
| **乐山** | 实证考古派 | "坑里挖出来什么我就说什么，没挖出来的别瞎编" |
| **峨眉** | 跨学科解码派 | "我从力学/音韵/经济角度给你解一个新的" |
| **渔阳** | 审计派 | "这笔账平不平？" / 结尾封账 |

### 单集结构（45-60分钟）

1. **开场开账**（3分钟）：渔阳把算盘往桌上一放——"今儿算哪笔账？"峨眉报主题，乐山补充考古背景
2. **主体对话**（35-45分钟）：峨眉提假说→乐山用实证踩刹车→渔阳时不时插一句"这笔账不对"
3. **结尾封账**（5-7分钟）：渔阳合上算盘，把本期内容分三类：
   - **借方（〔史〕）**：有凭证、可查实的硬事实
   - **应付账款（〔设〕）**：假说、推论、待核查
   - **坏账核销**：被实证推翻的说法
   - 最后一句："本期账平/未平，封账。"

### 制作要求
- 三人同场录制，茶台布景（烟斗、盖碗、算盘）
- 无连线学者，无复杂仪式
- 后期可配文物图片、数据图表
- 比正片短，制作压力小

## 六、合规边界（硬约束）

1. **分层铁律**：所有假说必须标〔设〕，不得当〔史〕讲。结尾封账必须明确区分。
2. **证据底线**：基于已出土文物和正式发掘报告，不编造未发现的"证据"。
3. **不碰红线**：不涉及民族主义排他、领土争议、现实政治。
4. **考古数据**：以四川省文物考古研究院、成都文物考古研究院的正式报告为准，抖音/自媒体数据只能作参考。

---

## 七、成功指标（怎么算成了）

1. 每期至少有一个"原来还能这么解释"的解码点，让听众觉得值
2. 渔阳的"封账"环节成为标志性段落，观众愿意截图传播
3. 6期下来，古蜀文明的核心糊涂账（大立人、太阳轮、金杖、迁都、贸易链）全部过一遍审计
4. 不翻车——没有被考古学界抓出硬伤（因为我们全标了〔设〕）
