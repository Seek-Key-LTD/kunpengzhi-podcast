# 《天球视界动力学：纬度约束、星空库存与神话资源对照表》

> **核心命题**：**【地理纬度决定可见天区；可见天区构成神话、导航、历法与宇宙论直接取材的视觉库存边界。】**  
> 天球不是全人类共有的均质视觉全景；地理纬度与岁差共同切分了不同文明可直接经验的宇宙资源与神话边界。

## 一、球面天文学基础模型与参考系说明

### 1. 视界几何公式
设观测者地理纬度为 $\phi$（北纬为正），天体赤纬为 $\delta$。在理想海平面无遮挡地平线下：
- **天体南中天最高地平高度**：$a_{\max} = 90^\circ - |\phi - \delta|$
- **天体下中天最低地平高度**：$h_{\min} = \delta + \phi - 90^\circ$
- **北天恒显圈（拱极星 / 终年不落）条件**：$\delta \ge +(90^\circ - \phi)$
- **南天绝对盲区（终年沉没水下）条件**：$\delta \le -(90^\circ - \phi)$

### 2. 坐标系与时代基准
- 本表天体赤纬主要以 **现代 J2000 坐标系** 为基准几何参考；
- 涉及古希腊古典时代（约公元前 500 年至公元前 150 年）或更早时期时，**明确引入地轴进动（岁差）对赤纬的修正效应**（如天极靠近天龙座 $\alpha$ 或小熊座 $\beta$、部分南天亮星赤纬相对今天偏北约 $2^\circ \sim 5^\circ$）。

## 四、科学与方法论结论

1. **神话形象库的物理可得性限制（约束而非单因）**：
   - 地理纬度决定了夜空的视觉库存。希腊世界向南打开了约 $12^\circ \sim 20^\circ$ 的南天低空带，使“低空船形星区（南船座北部）”能进入其神话叙事与航海象征；
   - 鄂霍次克海因高纬度遮蔽，在物理上绝对缺乏这一深南视觉素材，因此极北文化不会原生出依赖南船座低空航行的神话体系。
2. **北极中心宇宙论的地理生态**：
   - 极北高纬（$50^\circ\text{–}60^\circ\text{N}$）的北天极高达 $50^\circ\text{–}60^\circ$，大熊（北斗）、天龙等在极夜中常年天顶旋转，为《黄帝内经·上古天真论》及北亚萨满的“极天不动、四时运转”提供了坚实的视觉经验土壤。
3. **反对跨纬度与跨时代的机械星名套用**：
   - 任何严肃的天文-文化比对，必须严格执行：
     $$\text{具体地点纬度 } \phi + \text{具体历史年代岁差 } \Delta + \text{天体真实赤纬 } \delta + \text{地平遮挡与大气消光} \Rightarrow \text{真实可得性}$$
   - 破除“希腊能看全天”或“两地看同一片天”的粗暴假设，以可证伪的球面天文计算建立坚实的学术护城河。
