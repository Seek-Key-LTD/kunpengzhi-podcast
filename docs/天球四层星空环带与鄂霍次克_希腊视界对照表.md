# 《天球视界动力学：纬度约束、星空库存与神话资源对照表》

> **核心命题**：**【地理纬度决定可见天区；可见天区构成神话、导航、历法与宇宙论直接取材的视觉库存边界。】**  
> 天球不是全人类共有的均质视觉全景；地理纬度与岁差共同切分了不同文明可直接经验的宇宙资源与神话边界。

---

## 一、球面天文学基础模型与参考系说明

### 1. 视界几何公式
设观测者地理纬度为 $\phi$（北纬为正），天体赤纬为 $\delta$。在理想海平面无遮挡地平线下：
- **天体南中天最高地平高度**：$a_{\max} = 90^\circ - |\phi - \delta|$
- **天体下中天最低地平高度**：$h_{\min} = \delta + \phi - 90^\circ$
- **北天恒显圈（拱极星 / 终年不落）条件**：$\delta \ge +(90^\circ - \phi)$
- **南天绝对盲区（终年沉没水下）条件**：$\delta \le -(90^\circ - \phi)$

### 2. 坐标系与时代基准
- 本表天体赤纬主要以 **现代 J2000 坐标系** 为基准几何参考；
- **历史计算窗口**：必须按公元前 1500 年、公元前 1000 年、公元前 500 年、公元 150 年（托勒密时代）等明确历元分别计算岁差修正量；**不可将“距今 2000—4000 年”视作同一套静态星空**。

## 四、科学与方法论结论

1. **阿尔戈神话与南船座的可见性约束**：
   - 古希腊阿尔戈神话与南船座之间可以存在一种值得研究的“可见性约束”，但不应写成简单的一一对应。古代 Argo Navis 横跨很大的南天范围；从爱琴海和爱奥尼亚沿岸可见的主要是其北缘、若干局部星区以及在特定岁差时代可能临界出现的亮星，而非整艘巨舰。
   - 相较之下，鄂霍次克海 $50^\circ\text{–}60^\circ\text{N}$ 的观察者对赤纬约 $-40^\circ$ 以南的南船座主体与半人马座大部无直接视界。
   - 故“希腊具有较极北大洋更开放的南方低空星空”是强结论；“阿尔戈神话由完整可见的南船座直接产生”则是尚不能成立的强断言。Argo Navis 的古代构成与现代能见度还会受岁差影响，应按具体年份计算。
   - **〔史〕岁差定年锚**：托勒密《天文学大成》（约公元 150 年，亚历山大 31°N）已将今南十字诸星编录于半人马座脚部；约公元 5–6 世纪起，岁差使南十字整体沉至地中海—爱琴海地平线下，欧洲此后不再直接见录（但丁约 1300 年所写“南天四颗圣星”，已成对不可见星空的追忆）。这把“南船/半人马/南十字之可见窗口＝爱奥尼亚纬度 × 特定古纪元”钉进了可定年的文献史，使第四层由静态地理表述升级为**岁差定年器**。
2. **北极中心宇宙论的地理生态**：
   - 极北高纬（$50^\circ\text{–}60^\circ\text{N}$）的北天极高达 $50^\circ\text{–}60^\circ$，大熊（北斗）、天龙等在极夜中常年天顶旋转，为《黄帝内经·上古天真论》及北亚萨满的“极天不动、四时运转”提供了坚实的视觉经验土壤。
3. **反对跨纬度与跨时代的机械星名套用**：
   - 任何严肃的天文-文化比对，必须严格执行：
     $$\text{具体地点纬度 } \phi + \text{具体历史年代岁差 } \Delta + \text{天体真实赤纬 } \delta + \text{地平遮挡与大气消光} \Rightarrow \text{真实可得性}$$
   - 破除“希腊能看全天”或“两地看同一片天”的粗暴假设，以可证伪的球面天文计算建立坚实的学术护城河。
