## 一、球面天文学基本可见性模型

设观测者地理纬度为 $\phi$（北纬为正），天体赤纬为 $\delta$。在理想水平地平线下，天体南中天的最高地平高度为：
$$a_{\max} = 90^\circ - |\phi - \delta|$$
天体下中天的最低地平高度为：
$$h_{\min} = \delta + \phi - 90^\circ$$

由此导出三层动态阈值系统：
1. **北天恒显圈（拱极星 / 终年不落）**：$\delta \ge +(90^\circ - \phi)$
2. **可升可落带（季节性升落）**：$-(90^\circ - \phi) < \delta < +(90^\circ - \phi)$
3. **南天永不可见盲区（终年在水线以下）**：$\delta \le -(90^\circ - \phi)$

## 三、方法论与文化天文学结论

1. **神话形象库的物理可得性限制**：
   - 希腊阿尔戈英雄号（Argo Navis）神话，其核心星座南船座在爱琴海低空半浮半沉，天然契合“未知南方、冒险与海界”的神话结构；而在鄂霍次克海，该星区在物理上完全处于地平线之下，极北先民无法直接从中取材。
2. **北极中心宇宙论的强地质/地理生态**：
   - 在 $50^\circ-60^\circ\text{N}$，北天极高度达 $50^\circ-60^\circ$，大熊（北斗）、天龙、仙王永不落入海面，在极夜中绕天顶恒显旋转，为《黄帝内经·上古天真论》及道家“天心不动、四时运转”的生命哲学提供了坚实的物理感知基础。
3. **反对跨纬度的机械星名比对**：
   - 任何跨区域星座比对，必须建立在 **“该时代地理纬度 $\phi$ + 该时期岁差 $\Delta$ + 地形地平线”** 的严格可得性计算之上。不能直接把希腊星图当成全人类共享的均质苍穹。
