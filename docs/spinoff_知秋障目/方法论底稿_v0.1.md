## 〇、定名案：为什么叫《知秋障目》（主创口述，2026-09-22）

专栏名是一语双关，双关的两层都焊在路砚秋自己身上：

- **知秋 = 路砚秋的"秋"**：知秋者，明察秋毫。名字里那个"秋"就是他的招牌——从一片叶子看到整个秋天，从一条痕迹重建整条证据链。
- **障目 = 同时也是"账目"**：
  - 一义"一叶障目"：时刻提防被单一痕迹遮蔽全局；
  - 一义"账目"：**这是他的账目**。六扇审的就是账——现场重建是账、物证链是账、来源鉴定是账、文书与媒体叙事里的证据缺口还是账。一叶知秋，是从账目里看出秋天；而假账、伪造的证据链、被篡改的现场，恰恰就是"账目障目"。

> 命门一句话：**他让账目说话，同时提防账目说谎。**

## 一、0.1 版：读懂对方的情报处理方式

> 以 CIA（Central Intelligence Agency）情报处理为样板，公开文献口径。

1. **情报周期**：需求定义 → 收集 → 评估 → 分析 → 分发 → 反馈。每条情报都有生命周期，不是"收到即生效"。
2. **来源分级与可信度**：来源按可靠程度分级（可靠/通常可靠/一般/不可靠/无法评估），信息按与其他来源的印证程度分级（已确认/很可能/可能/不太可能/无法判断）。证据强度必须与来源强度分开标注。
3. **分析纪律**：区分 FACT（来源直接支持的事实）/ ASSUMPTION（采用的前提）/ JUDGMENT（分析判断）/ UNKNOWN（当前无法确认）。替代解释必须列席。
4. **分发与保护**：情报按需分发、最小必要原则；来源保护优先于情报价值。

> 0.1 的意义：先学会读对方的棋谱，才有资格谈反制。不会读账的人，没有资格查账。

## 二、1.0 版：以彼之道反制——防泄露行为学

> 核心转向：**不再只是理解对方怎么处理情报，而是用他们处理情报的方式去反对——看他们怎么防止自己的情报被泄露，进而来揪出他们真实的用意。**

1. **防御动作即情报**：一个人拼命锁哪扇门，你就知道哪扇门后藏着他怕人看见的东西。保护等级、销毁痕迹、审批链、信息隔绝、双人复核——每一个"防泄动作"本身都是可判读的痕迹。
2. **一叶知秋判读框架**：
   - 观察：他们给什么打了最高密级、销毁了什么、在哪个环节设卡、谁被隔离在信息外；
   - 反推：这些防御动作暴露了什么"怕被看见"的东西；
   - 交叉：把反推结果放回六面观察的图里，与既有证据互相印证或证伪；
   - 落定：形成关于真实意图的推断，标注置信度与替代解释。
3. **防障目对冲**：反推出来的结论必须过"障目关"——这片"叶子"是不是对方故意放在你面前的？防御动作本身也可能是表演（假锁门、假销毁、假隔离）。真防御与表演防御的区分，是 1.0 层的核心手艺。

## 三、防障目装置：六面观察

六扇不是权力神位，是六个观察面。任何单一痕迹都可能遮蔽全局；只有把六面证据、替代解释和未知项放回同一张图，才可能从局部推断整体。

| 观察面 | 审什么 |
|---|---|
| 现场 | 物理痕迹、时间戳、空间关系、现场重建 |
| 时间 | 时序、窗口期、时间缺口、顺序合理性 |
| 来源 | 来源可信度、来源动机、来源是否被污染 |
| 接触 | 接触链、交接记录、谁能碰到什么 |
| 动机 | 谁有动机、动机强弱、谁从混乱中获益 |
| 叙事 | 谁在讲这个故事、讲给谁听、想达到什么效果 |

配套证据分级（对接 intelligence-ops 证据处理规范）：

```text
FACT       可由来源直接支持的事实
ASSUMPTION 为分析所采用的前提
JUDGMENT   分析判断
UNKNOWN    当前无法确认的部分
```
