## 【第二幕：《盲井》的黑色弹性——前现代资本的热力学毛细血管】

2003 年，导演李杨根据刘庆邦的小说《神木》拍出了电影《盲井》，让当时只有十六岁、一口河北邢台土话的王宝强一举成名。

很多人把这部电影看作底层互害、道德沦丧的刑事犯罪片。**但在宏观与制度法医的解剖镜下，它是人类工业史上对前现代资本‘毛细血管生态’最冷酷、最精准的切片！**

   │  2. 事故标价：冒顶塌方赔三十万，村支书盖章给两万       │
   │  3. 监管标价：安监站下乡发红包五千，换取停产通知延期   │
   └──────────────────────────┬─────────────────────────────┘
                              │ 道德底线：彻底归零 / 践踏人性尊严
                              ▼
   ┌────────────────────────────────────────────────────────┐
   │ 【热力学特征：近乎神迹的“超高抗压弹性（Resilience）”】│
   │  * 行情暴涨（每吨涨 10 块）：连夜开闸，雇流民三班倒狂挖│
   │  * 行情暴跌（亏损即弃坑）：挂一把生锈铁锁，工人原地遣散│

### 1. “万物皆有标价（Everything has a price tag）”

在那个时代，遍布雁北、吕梁、临汾的几万个私人小煤窑，运行的是一套野蛮到极点的丛林法则：
* 一条矿工的命，从五万涨到十八万、二十万；
* 一次局部冒顶事故，摆平村里和家属三十万；
* 乡安监站和县煤炭局的皮卡车开进山沟，后备箱里塞两条软中华、扔两个五千块的信封；
* **没有现代通风系统，没有瓦斯连续监控，没有千万级液压支架，甚至没有工伤保险。**

它道德败坏、践踏法治、血泪斑斑，每一吨挖出来的煤都散发着人血馒头的腥臭味。

### 2. 热力学上的“微观超弹性”

但如果你把道德滤镜关掉，纯粹从**系统热力学与经济弹性**的冷血角度审视：**这套毛细血管生态，拥有后现代巨型企业望尘莫及的生命力！**

* **近乎为零的沉没成本**：  
  一个小煤窑的初始投入，不过是几台二手的柴油空压机、几根木头坑木、几十把风镐和一条破皮带。它根本没有向工商银行借几十亿固定资产抵押贷款，它没有每个季度必须还本付息的债务绞索！
* **一把铁锁的终极出清力学**：  
  煤价一吨涨十块钱，老板连夜在路边招几十个盲流，提着马灯下井三班倒，供给像泉水一样喷涌；  
  一旦煤价雪崩、入不敷出，煤老板根本不需要开董事会，不需要打报告请示发改委，更不需要变卖资产破产重组。**他只需要花五块钱买一把粗铁锁，‘咔哒’一声把坑口铁门锁死，工人工资一结原地遣散回村种苞谷，自己开着大奔去太原或者北京买房！**  
* **几天之内，微观产能彻底休眠，全行业瞬间完成物理出清！**

### 3. 微观布朗运动的宏观阻尼

更神奇的是宏观统计学特征：  
全山西几千个、上万个小煤窑，没有一个上过 SAP 系统，没有一个财务总监懂得建回归模型。每个小老板全凭直觉、甚至全凭打麻将听来的小道消息在做决策——有的在偷挖，有的在休假，有的在躲安检，有的在借钱买炸药。

**这在数学上就是最纯粹的‘布朗运动（Brownian Motion）’！**  
几万个完全随机、混乱、非线性的微观骚动，在宏观大数定律的过滤下，彼此的波峰和波谷互相抵消。系统虽然看起来脏乱差、脓血直流，但在宏观上**反而天然具备一种粗糙的缓冲器（Damper），永远不会爆发系统性的全频带同频共振！**

### 1. 道德圣杯下的“毛细血管大铲除”

从 2008 年山西省启动震惊全国的‘煤炭资源整合与企业兼并重组’开始，中枢与地方达成了空前的法理共识：  
**‘宁要安全的少，不要带血的多！’**

* 小煤窑被当成毒瘤连根拔起，炸毁井口、物理填埋；
* 民营资本被清退，全省煤炭资源被强行收拢到同煤、焦煤、潞安、阳煤、晋煤、晋能等几大国有巨头怀中；
* 原本密密麻麻的几万根细小毛细血管，被彻底切除，全省工业的全部血流，被强行导入了极少数几根直径两米的**国有主动脉**。

### 2. 电算化系统的“宏观震荡器”

主事者以为，只要企业变大、上了现代电算化系统、交给高素质技术官僚打理，市场就会变得井井有条。

**大错特错！他们亲手制造了一台能摧毁一切的‘宏观震荡器’！**

1. **同质化算法诱发的‘全军同频踩踏’**：  
   * 巨头合并之后，各家集团在太原的大厦里设立了庞大的战略规划部与风险控制部；招的都是清华、北大、海归的金融与财会硕士；
   * 大家都用着 SAP 或者 Oracle 的 ERP 软件，看的是中钢协、国家发改委同一份季度宏观报告，运行的是同一套时间序列回归预测模型；
   * 当煤价跌到盈亏平衡线、系统警报在同一微秒拉响时，**全省不再有小煤窑的随机布朗运动，每一家巨头的计算机模型给出的‘最优解’完全雷同——‘流动资金即将枯竭，必须用最大产能摊薄固定成本，抢占长协现金流！’**  
   * 原本分散混乱的游击队，瞬间变成了一支步调高度一致、装备精良的重装机械化兵团，**在同一秒钟、以同样的速度，排着整齐的方阵轰鸣着冲向悬崖！**

2. **‘不可出清’的超级组织肿瘤**：  
   * 小煤老板可以拔钥匙锁井门，同煤、焦煤能锁井门吗？
   * 井口连着十几万在册正式工、几十万退休家属、医院、学校、供暖锅炉；
   * 账面上挂着几百亿在银行间市场发行的超短融（SCP）、中期票据（MTN）和定向债务融资工具（PPN），下个月就有 50 亿到期必须刚性兑付！
   * **巨型国企在生理上被彻底剥夺了‘休眠、止损与出清’的能力！** 它就像一头被切除了痛觉神经与止血机制的史前巨兽，哪怕腹腔被切开、肠子流了一地，为了维持那台必须每天给银行喂利息的造血机，它也必须红着眼睛拼命挥动爪子挖煤！

**生锈铁锁的弹性死了，取而代之的是一台停不下来的失血碎肉机！**

### 1. 迎泽宾馆联席会的无力呻吟

2015 年底，在太原五一广场旁的迎泽宾馆三楼会议室，气氛凝重得能拧出水来。

省国资委和发改委把各大煤炭集团的‘一把手’全召集在一张巨大的红木椭圆桌前开‘煤炭行业自律保价联席会’：  
* 领导在上面拍桌子：*‘同志们，讲政治！讲大局！不能再打价格战了！下个月开始，各家统一按现有产量下调 15%，谁降价倾销谁就是山西的罪人！’*
* 各大集团董事长神情庄重，纷纷表态发言：*‘坚决拥护省委省政府决定，同舟共济，绝不抢跑！’*
* 散会握手，大家在电梯里彼此热情寒暄、互递老刀与软中华，宛如异父异母的亲兄弟。

**然而，现实的荒诞总是在电梯门打开的那一瞬间降临！**  
各家老总刚走出迎泽宾馆旋转门，甚至还没坐进自己的奥迪 A8，第一件事都是掏出加密手机打给总调度室和主力矿长：  
*‘喂！别听刚才会上吹的！同煤和焦煤那帮人回去绝对不可能减产！他们账上比咱们还缺钱！听我命令：井下三班倒给我开足马力，趁着他们可能犹豫的这几天，连夜把洗好的精煤装车，抓紧抢占大秦线的车皮！快！’*

**联席会不仅没有消弭猜疑，反而成了各路诸侯抢跑的倒计时发令枪！**

### 2. 终极托拉斯的诞生：晋能控股把人捏成面团

既然行政协调是一纸空文，既然博弈论证明了‘只要存在两个以上的独立主体，囚徒困境就绝对无解’，那官僚系统最擅长、也最习惯的终极解法是什么？

**‘既然你们博弈，那我就消灭博弈的主体！’**  
**‘既然你们两只手互掐，那我就把你们的骨头打断、肉剁烂，捏成同一根柱子！’**

2020 年，山西省做出了一个震动全行业的终极决定：  
* **把同煤集团、晋煤集团、晋能集团三大万亿级国企就地肢解揉碎；**  
* **并入潞安集团和华阳新材料的煤炭资产；**  
* **强行组装出了一艘资产突破 1.1 万亿元、煤炭产能超 4 亿吨的超级史前巨兽——晋能控股集团！**

在成立大会的镁光灯下，横幅上写着‘深化国资国企改革的重大里程碑’。  
**但在宏观法医的解剖报告上，那张写着现代法人治理结构、反垄断、政企分开的改革初衷，在这一天被整整齐齐地塞进了骨灰盒，深埋进了太行山的黄土之下！**

这不是什么创新，这是十九世纪末洛克菲勒标准石油公司玩剩的**超级托拉斯（Trust）**；这是苏联二十世纪三十年代**重工业国家人民委员部与国家计划委员会（Gosplan）**的还魂复辟！

## 【第五幕：收钟·莫比乌斯环与计划经济停尸房】

> **时间**：夜间 20:45  
> **地点**：华严寺钟楼外，万籁俱寂，唯有远处运煤列车碾压铁轨的单调撞击声  
> **现场机位**：云中站起身，用铁火钳将炉膛里的蜂窝煤夹碎，黑色的煤灰在夜风中四散飞扬。他指着黑黢黢的夜空，声音低沉得像从地心深处挤压出来的一样。

“当——！

各位，把三十年的卷宗合上，回过头看一看我们走过的路。

三十年前，我们为什么要搞国企改制？为什么要搞抓大放小？为什么要搞混改、引入民资、打破大锅饭？  
初衷在当年的十四届三中全会、十五大报告里白纸黑字写得清清楚楚：  
**政企分开、打破行业垄断、引入市场竞争、建立产权清晰权责明确的现代企业制度！**

结果，整整折腾了三十年：
* 我们嫌弃小煤窑野蛮残忍，于是把最具市场弹性的毛细血管连根铲除；
* 我们造出了巨型国企，却发现同质化算法和不可出清的债务引爆了更恐怖的系统性啸叫；
* 我们在迎泽宾馆开联席会试图搞行政限产，却被诸侯博弈的冷血现实抽得鼻青脸肿；
* 最终，我们祭出的终极答案，居然是把所有人绑在一起，退回最原始、最僵化、最不需要动脑子的**‘超级行政单一垄断托拉斯’**！

```
                 【中国微观治理的“打摆子莫比乌斯环”】
  
  一放就乱（《盲井》脓血直流）
      ▲               │
      │               ▼
  一死又放         一乱就收（集中度狂热）
      ▲               │
      │               ▼
  一收就死（万亿托拉斯脑死亡）
```

这种现象，在医学上叫做**典型的‘周期性疟疾（打摆子）’**。

* **放的时候**，系统漠视法律与人命底线，靠野蛮生长和人血馒头换取微观弹性；
* **收的时候**，系统不计一切财务与效率代价，靠强权政治捏合，把所有人塞进一具关节早就钙化僵死的铁棺材里！

当年死在盲井底下、连个名字都没留下的几万个打工汉，用他们的尸骨，换来了早期中国工业原始积累最廉价的热量与动能；  
而今天坐在晋能控股集团大厦高层、喝着现磨咖啡、在电算化报表前心照不宣地编造‘世界五百强’成绩单的技术官僚，则合力把这场始于改革的试验，**稳稳地送回了它最早出发的那个计划经济停尸间！**

华严蒲牢，再响无益。  
夜深了，平城的风冷，大秦线的皮带机还在转。洗洗睡吧。”
