### 摘要 (Executive Summary)

本案对《出埃及记》核心地理名称的历史流变及苏联远东“比罗比詹（犹太自治州）”的国家工程进行文献法医与历史会计审计。

审计证实：
1. **希伯来原典无“红海”**：《出埃及记》（如 10:19 等）原文所用为 **יַם־סוּף（Yam Suph）**，实指“芦苇之海 / 水草之泽”；
2. **七十士译本的帝国科目偷渡**：公元前 3—2 世纪托勒密埃及亚历山大里亚的希腊语译官，为使文本对接希腊帝国知识市场，将地方性水草沼泽升级为广域帝国贸易通道 **Ἐρυθρὰ θάλασσα（Erythra Thalassa / 红海）**；
3. **比罗比詹的四重国家复式分录**：1928/1934 年斯大林设立比罗比詹犹太自治州，系“斯大林民族理论领土凭证、反锡安主义世俗红锡安替代、城市小资产阶级向农业无产阶级改造、黑龙江北岸防日屯垦国防”的四重国家资产负债表合并。

### 第一章 文本法医：《出埃及记》Yam Suph 原始凭证还原

#### 1.1 词根追溯与语义锚定
* **סוּף（Suph）**：在希伯来语中特指“芦苇、香蒲、水草”。在《出埃及记》2:3 摩西婴儿时期被置于尼罗河沿岸“芦苇丛”中时，使用的正是此词；
* **יַם־סוּף（Yam Suph）**：直译为“水草之海”或“芦苇之泽”，指尼罗河三角洲东部苦湖、提姆萨赫湖等芦苇沼泽水域，绝非开阔大洋深水；
* **无色彩标记**：希伯来语中表述红色之词为 *Adom*（אָדֹם），但在所有古代出埃及文本中，从未出现过 *Yam Adom*（红海）的表达。

#### 1.2 亚历山大里亚译官的“科目升维”
公元前 3 世纪托勒密王朝时期，《七十士译本》（Septuagint）在亚历山大里亚翻译：
* 托勒密王朝正大力经营经由红海（*Erythra Thalassa*）通往东非与印度的皇家象兵与香料航道；
* 译官行使 **Naming Class 资产重述**，将小尺度的游牧逃逸沼泽（Yam Suph）强行并入世界帝国通用的大地理科目 *Erythra Thalassa*；
* 此举导致后世拉丁语《武加大译本》（*Mare Rubrum*）及现代各语言译本（*Red Sea* / 红海）产生了两千年的地理认知倒灌。

### 第三章 Naming Class 认识论同构：地理命名的权力意志

无论是公元前3世纪亚历山大里亚的希腊化学者，还是20世纪30年代莫斯科的苏联国家计委，历史上的统治阶级（Naming Class）始终掌握着对空间与族群历史坐标的**强制再估值权力**：

| 审计维度 | 希腊化七十士译本（前3世纪） | 苏联比罗比詹国家工程（20世纪） |
| :--- | :--- | :--- |
| **原始事实** | 尼罗河三角洲水草沼泽（Yam Suph） | 散居东欧城镇的意第绪语无领土社群 |
