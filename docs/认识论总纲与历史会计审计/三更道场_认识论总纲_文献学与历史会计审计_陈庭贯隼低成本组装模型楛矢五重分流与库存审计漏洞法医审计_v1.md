### 摘要 (Executive Summary)

本案运用现代刑事侦查学、法医创伤学与物证链审计方法，对《国语·鲁语下》陈庭贯隼案的物理实现路径与文本叙事漏洞启动终极历史会计审计。

核心审计成果：
1. **低成本道具组装模型（Prop Assembly Model）**：
   * 彻底剥离“高空极限对狙”与“人腿追鸟累毙”的高成本臆想；
   * 确立最经济、最可控的物理实现模型为：**通过常规方式（诱捕/网捕/栖木近射）获取猛禽 $\to$ 人工以楛矢贯穿尸身 $\to$ 定点越墙投放于陈侯正庭**；
2. **楛矢来源的五重独立核算分流表**：
   * 严密穷尽物理来源：① 陈国故府金椟内部盗取；② 其他受赐诸侯旧藏流转；③ 历史战争/盗掘黑市流入；④ 中原工匠按制仿制；⑤ 东北亚贸易网络直接携入；
3. **《国语》“失踪的库存审计底稿”法医解剖**：
   * 文本存在四处关键物证留白：金椟原装数量未清点、现场箭铭文未核验、创口生前死后反应未鉴定、真实死因未剖验；
   * 证实该文本系**政治神圣叙事工程，而非客观法医勘验笔录**。

### 第三章 证据学解剖：《国语》失踪的库存审计底稿

《国语》文本为了服务于“圣人知识确权与周代天下大一统”叙事，在物证法医上留下了巨大的空白：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 《国语》文本选择性留白（Selective Omission）法医清单                                  │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ 1. [库存盘点未平账]：只写“得之金椟，如之”，未记录金椟原装数量是否与档案相符。         │
│ 2. [现场铭文未核销]：未记录现场贯隼之箭是否带有周王所刻“铭其栝曰肃慎氏之贡矢”。       │
│ 3. [生活反应未鉴定]：未记录创口是否存在生前大出血生活反应（无法排除死后插箭）。       │
│ 4. [发射方式未判定]：未记录箭杆是否有弓弦摩擦痕迹（无法排除手力直接穿刺）。           │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

**审计判决**：
《国语·鲁语下》是一份**经过高度文学剪裁的政治法统宣传公案**。它精准利用了真实存在的“陈国金椟旧藏”与“极北军工楛矢”，构造了一场无懈可击的圣人与帝国双重神话。
