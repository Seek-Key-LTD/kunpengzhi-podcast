### 【破题】
审钱币之面额，莫惑于帝王之冠冕；考帝国之真伪，必验资产之流向。夫“希腊-巴克特里亚”钱币上铸造之希腊字母与神祇，两百年来被西方史学偷换为“中亚已全盘希腊化、成为马其顿文明之分身”。在现代金融工程学与历史会计学视域下，此乃严重之名实偷渡：**贵金属铸币之本质在于金银成色与重量（底层自然货币资产），钱币上的希腊字母不过是跨国贸易中用于验真、定值与防伪之“统一 API 结算协议与国家品牌包装（类似今日跨国合同使用英语与美元符号）”**。若巴克特里亚果真为马其顿殖民输血之忠实属邦，何以阿姆河流域截获之高价值密度、不腐耐磨之神权顶级资产——**和田软玉，从未向马其顿及地中海宗主国系统性回流**？今立语言四层解构与资产流量总账，彻底平核。

---

### 【承题】
盖历史法医反事实推理（Counterfactual Deduction）与结算公理：
$$\text{真实控制力} = \text{真实物资与利润流向 (Asset Flow)}, \quad \text{非钱币宣称之政治头像 (Brand Claim)}$$

1. **萨拉兹姆（Sarazm 5500 BP）之底层实证**：
   - 泽拉夫善河流域萨拉兹姆遗址（距今 5500 年以上，联合国教科文组织世界遗产）早已证实：远在亚历山大到来两千多年前，阿姆河-泽拉夫善水网之**定居农业、冶金手工业与跨山远距离贸易网络早已高度成熟运转**。希腊人面对的是既有繁荣网络，绝非蛮荒空地。
2. **语言文字的四层法医剥离法（防偷换防火墙）**：
   - **第一层：字符/书体（Scripts）**：写的是希腊字母，但字母只是拼音符号，不等于语言本身；
   - **第二层：发音与底层（Phonology）**：铭文中大量人名、地名、神名实为以希腊字母近似转写本地东伊朗/吐火罗语音；
   - **第三层：消费品属性（Commodity/Branding）**：类似于现代印有英文字母之商品包装（“《疯狂英语》/外贸标签”），代表某种国际市场流通溢价，不代表日常生活母语；
   - **第四层：真实使用场景（Execution Context）**：希腊文仅限官方大额铸币与高级总督文书；日常民间借条、市井账簿、陶片涂鸦、家庭契约中，本土东伊朗语与阿拉米符号自始至终占绝对统治地位。
3. **和田玉“不回流宗主国”之杀伤力反事实审计**：
   - 和田玉价值密度极高、重量轻、不腐烂、极适合长途运输与皇家精英消费；
   - 贵霜及中亚城邦大量截获并消费和田玉，证实跨帕米尔商道真实畅通；
   - **若马其顿/塞琉古真是巴克特里亚之绝对宗主，欧洲地中海王廷理应出现系统性和田玉朝贡、皇家珍宝清单与神权玉器回流；**
   - **实际考古事实**：地中海古典世界对和田软玉呈现**全盘缺席与实物零记录**！和田玉被死死锁在**帕米尔—巴克特里亚—南亚印度河**之内部循环网络中，彻底粉碎了“巴克特里亚为马其顿从属输血殖民地”之单向叙事。

   钱币上的文字只能证明发行者的“结算接口与品牌选择”，**资产与利润的真实流向（谁养活了谁）才是判定文明归属与地缘性质的唯一铁证**。
