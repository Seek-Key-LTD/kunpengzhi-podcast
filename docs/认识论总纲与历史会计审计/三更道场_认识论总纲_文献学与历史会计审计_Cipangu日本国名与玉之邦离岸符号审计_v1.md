- 英语 **Japan** 并不完全线性派生自马可·波罗的 **Cipangu**，而是由**印度洋—南洋海路贸易网络（马来语 Japang ➔ 葡语 Japão）**独立塑造；

## 二、“玉之邦”为什么在本土矿物学上“账面不平”？

> [!IMPORTANT]
> **存货证明 $\neq$ 估值证明 $\neq$ 命名权来源！**  
> 必须对日本硬玉进行严格的“四项会计排他性审查”：

```mermaid
classDiagram
    class 资源禀赋四项会计审查 {
        +1. 原料绝对产量 (Absolute Mining Yield)
        +2. 跨区域大宗贸易半径 (Inter-regional Trade Radius)
        +3. 相对昆仑/岫岩玉的交换溢价 (Exchange Premium)
        +4. 统治合法性与国家礼制权重 (Ritual Hegemony)
    }

    class 日本糸鱼川硬玉实测 {
        +产量: 极度受限于新潟等狭小断裂带
        +流通: 仅在列岛与环日本海局部扩散
        +溢价: 未能跨海反向支配大陆中原贵金属/玉衡市场
        +礼制: 虽有三神器之勾玉，但无昆仑/和阗玉的跨文明定价权
    }

    资源禀赋四项会计审查 ..> 日本糸鱼川硬玉实测 : 审查不通过（无法平账）
```

- **本土硬玉事实**：日本新潟糸鱼川（Itoigawa）确有硬玉翡翠，绳文时代已加工勾玉，现代更定为“国石”；
- **历史会计审计穿透**：
  - 这只能证明**“列岛存在古老玉文化残余”**；
  - 它在产量、跨文明贸易结算权、以及对东亚大宗现货市场的定价能力上，**完全无法与“昆仑—和田玉”或“东北亚岫岩/小南山玉网”相提并论**！
  - 企图用“日本自己有玉”来论证“因此得名玉之邦”，是典型的**以局部存货冒充全境内生禀赋的做假账行为**！
