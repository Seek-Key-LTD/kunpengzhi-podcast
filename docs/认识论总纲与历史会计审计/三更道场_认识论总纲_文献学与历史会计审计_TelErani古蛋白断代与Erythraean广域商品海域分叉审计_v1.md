### 摘要 (Executive Summary)

本案引入古蛋白质学（Paleoproteomics）硬证据与古代航海贸易文献，对“红蕉物产假说”实施法医学分叉审计。

核心突破：
1. **时间反例被硬核击穿**：以色列南部 Tel Erani 遗址（约前 1100–1000 年）平民男性牙结石检测出芭蕉科（*Musa* / *Ensete*）果实成熟特异性 β-葡聚糖酶，确证在希罗多德与《七十士译本》（前 5—前 2 世纪）之前 500–800 年，蕉类已作为贸易品进入东地中海普通交换网络；
2. **假说分叉与形状说修正**：希罗多德与《厄立特里亚海航行记》确证古希腊 **Ἐρυθρὰ θάλασσα（Erythraean Sea）** 原始覆盖包括红海、亚丁湾、阿拉伯海及印度洋在内的广域贸易水域。海域最初并非因“海形似香蕉”得名，而是承载红蕉、香料、染料等核心大宗货物的**“商品—航路 Naming Class”**；
3. **地名收缩与固化机制（Geographical Narrowing）**：该广域商品海域在托勒密与罗马帝国特许航线经营下，逐渐向亚非狭长海峡收缩并专属化，最终在公元 4 世纪大抄本中与希伯来 *Yam Suph* 完成后置绑定。

---

### 第一章 科学证据：Tel Erani 古蛋白质谱对传统时间账的逆转

#### 1.1 质谱实测凭证（PNAS 2021）
* **考古地层**：南黎凡特 Tel Erani 铁器时代早期地层（约公元前 1100–1000 年）；
* **分子载体**：人类牙结石（Dental Calculus）微观蛋白质残留；
* **关键标志物**：果实成熟相关 β-葡聚糖酶（Beta-glucanase）特异性肽段，质谱匹配高度收敛于芭蕉科 *Musa*（蕉属）；
* **社会学属性**：墓葬非顶级统治精英，表明蕉类已突破奢侈贡品范畴，进入普通区域贸易流通。

```
【传统古典学假账】                                     【古蛋白质学真实分录】
断言：中东公元7世纪前无香蕉。  ────────►  Tel Erani（前1100-1000年）：蕉属成熟蛋白定植。
结论：红海与蕉类物产无时空交集。                  结论：蕉类贸易先于希腊“红海”命名500-800年！
```

### 第二章 假说分叉：形状命名说 vs 商品航路说

针对红蕉假说的内部逻辑，建立法医压力测试分叉表：

| 审计维度 | 版本 A：海形似蕉说（Shape-based） | 版本 B：商品航路命名说（Commodity-Route） |
| :--- | :--- | :--- |
| **核心机制** | 认为海域因卫星级狭长弯曲海形似香蕉而得名。 | 认为海域因承载红蕉、茜草、苏木等印度洋红物产而得名。 |
| **古典文献检验** | 遭遇严重反例：早期希腊文本中 Erythra 覆盖广阔印度洋，整体并非香蕉形。 | **完全吻合**：希罗多德与《航行记》皆将整条印度洋季风贸易网称为 Erythraean。 |
| **制图学前提** | 要求公元前一千纪具备精确大地测量与宏观海岸测绘。 | 仅需口岸商人与水手对核心货物、补给植物建立 Class 认知。 |
| **法医裁定** | **【存在重大疑点，降为备选】** | **【证据链闭环，确立为主干正典科目】** |

### 第三章 地名地理收缩机制（Geographical Narrowing）

Erythraean Sea 的三阶段会计演变：

```
1. 广域印度洋商品海（前1000—前5世纪）
   └── 覆盖红海、阿拉伯海、印度洋，作为红蕉、香料、染料季风航路代称
         │
2. 帝国专线收缩期（前3世纪—公元1世纪）
   └── 托勒密与罗马开辟红海直航港口（Berenike），专名逐渐向亚非裂谷海峡收敛
         │
3. 经院文本与制图固化期（公元4世纪—1602年）
   └── 《梵蒂冈抄本》将 Yam Suph 钉死为 Red Sea；1602年《坤图》李之藻合并为“东西双红海”
```
