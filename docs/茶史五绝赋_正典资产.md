# 《茶史五绝赋》正典资产（校勘定稿版）

> **作者**：徐厚重（原著）  
> **创作纪年**：始作于己亥（2019）端午，庚子（2020）谷雨初订，辛丑（2021）处暑再订，丙午（2026）白露正典落成。  
> **实体形态原旨**：**“十六面转经走马大茶灯”**——十六面门帘垂落成围合茶室，人在其中，挑帘而入，转灯读史，步步生香。  
> **体制**：五言为体，十六章，章十六句，句五言，共二百五十六句、一千二百八十字；左右双栏对位，一韵到底（通押 `u / ou / ü` 韵部）。

---

## 【序】

茶者，人在草木间也。拆其字：草头为双十，人木为八十有八，合一百零八之数，故称茶寿。上合天罡三十六，下应地煞七十二。一叶至微，暗合天地之数；是以华夏以茶为精神，炎黄以茶为图腾。

昔人论华夷之辨，约有三端：血缘、地缘、冠服。千禧以降，混血之家日众，跨海而居者日多，洋装而裹中国心者比比皆是。以余观之，华夷之隔，不过一茶耳——**认这片叶子者，皆是故人。**

唐有陆羽著《茶经》，千年之距；东瀛有冈仓天心著《茶书》，烟海之隔。东坡居士尝以一百二十句长诗《寄周安孺茶》，写尽人与茶之缘。己亥端午，客居感怀；适有湖北大学同窗故人携恩施富硒之茗（恩施玉露）赴京农展馆参展，余欲为同窗壮其声势；值岁逢风云激荡，感怀系之，乃不揣浅陋，挑战千文之限，以五绝为体，以茶史为经，一韵到底，双栏对位，成十六章、二百五十六句、凡一千二百八十字，名曰《茶史五绝赋》。东坡百二十句，余不能和，乃倍之——以赠故人，兼以自遣。

夫形而上者谓之道，形而下者谓之器，执其中者谓之政。山不厌高，水不厌深，周公吐哺，天下归心——茶之为物，亦犹是也。

## 【凡例与空间装置】

1. **全赋结构**：全赋十六章，章十六句，句五言，共二百五十六句、一千二百八十字。
2. **读法说明**：每章分左右两栏，栏各八句。读法：**先尽左栏（起承），再尽右栏（转合）**。
3. **韵式架构**：每栏偶数句（第二、四、六、八句）通押 `u` 类韵（含 `ou`、`ü` 通韵），双栏各自竖列成韵脚群，一韵到底。非句尾点卯，乃章法层面的韵律骨架。
4. **空间装置（走马大茶灯）**：十六篇赋文原设计印制于十六幅悬垂织物门帘之上，环列为直径丈余之“走马八卦大茶灯”。品茗者挑帘入内，端坐灯中，旋转读赋，人游草木，灯映古今。

## 【跋与校勘记】

### 跋
是赋始作于己亥端午，庚子谷雨初订，辛丑处暑再订，丙午白露正典落成。全文十六章，章十六句，句五言，共一千二百八十字；一韵到底，左右双栏对位而读。

### 校勘记
1. 原序落款“癸亥年端午”系干支之误：港九风云之岁为 2019 年，当为己亥。今正，并依例不点名其事。
2. 原序称“一百二十八句”，与正文二百五十六句不合，系初稿八章之旧数，扩成十六章后未改。今正为二百五十六句、一千二百八十字。
3. 原序“《五经》云：胡汉之辨，衡量有三”一节，查无出处，系凭印象伪托。今改写为“昔人论华夷之辨，约有三端：血缘、地缘、冠服”。
4. 原序“周公吐脯”，“脯”当作“哺”（曹操《短歌行》“周公吐哺，天下归心”）。今正。
5. 第十一章“冰化于炁”仅四字，破五言格，今依赋律校定为“冰融水化炁”（上应冰水相变，下启气化归无），通顺入格。
6. 第十六章“兰亭感流殇”，“殇”依典故校为“觞”（引王羲之兰亭“一觞一咏，亦足以畅叙幽情”）。
7. “一缺金龙咬”（明太祖烧饼歌咬一口缺金龙之典）、“牙佳方为雅”（拆字格）、“银河泄如瀑”（李白望庐山瀑布意象），虽带作者当年独特笔致与民间拆字意趣，皆予以原貌保留，存其真气。
