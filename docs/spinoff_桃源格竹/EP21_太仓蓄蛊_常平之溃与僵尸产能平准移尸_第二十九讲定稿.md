### 【桃園格竹 · 第二十九讲】太仓蓄蛊与平准移尸：论国储失道与慈母覆家之祸

**【格物札记】**

夫财货之流布于天下，犹周身之营卫也。脉络通则百骸调，壅塞滞则疽痈生。  

昔桑孔立平准之法，耿寿昌设常平之仓，本非欲尽圈天下之百物，乃欲乘供求之高下，行“丰则籴以利农，歉则粜以利民”之微调也。其妙在**流通不息，吞吐得宜**。物入则币出，币聚则物行，仓中无积岁之朽腐，市廛无暴跌之恐慌。此治粟之圣道，通商之神枢也。  

曾几何时，良法化为恶政，蓄水之渊变作委卸之窟。  
凡天下之事，未有“溺爱而能成良器”者。  
当道者见外夷阻其商路，不思痛惩过剩之根苗，反发国帑以张大罗之网。无论瑕瑜，一概兜底收储；无论滞塞，尽入官库安顿。  
于是，垦殖者倚公器为盾，愈趋狂暴；纺织者视盈亏如戏，全无戒惧。机梭转而不知其所止，沃水涸而不知其所惜。  

夫库中所藏，本为救急之灵药；今则积压数载，色变味馊，质同槁木。  
有司犹拥册籍自矜，以朽败之残渣，充金银之实数；以糜烂之腐肉，充太仓之盈满。  
欲开仓发卖，则恐崩解现世之虚火；欲封存不动，则日耗山海之仓储与息金。  
救市之水，反成凝固之冰；养生之血，尽成积胸之脓！  
所谓国储，名虽存而骨早化，直一吞纳弃物、掩耳盗铃之垃圾冢耳！  

格竹至此，当发警世之断言：  
**善聚财者不如善散财，善养物者不如善杀物。**  
凡不敢断尾求生、妄图以库藏抗拒造化淘洗者，纵聚万箱之物，终不过为天下积留一堆不能食、不能衣、动辄糜烂其内腑之巨型毒痈而已！

#### 一、 削峰填谷的初衷：管仲与桑弘羊的“吞吐阀门”

国家储备制度（古典时期的常平仓、平准法，以及近现代的国家战略物资储备局）在制度发明之初，本质是一个极其精密的高阶**宏观跨周期稳压器**：

1. **峰谷调节的极简系统动力学**：  
   - **谷底/丰年（物贱伤农）**：市场现货价跌穿生产者的边际成本线，国储适时入场按最低保护价收购，接住砸向深渊的卖盘，托住产业基本盘，防止生产端成建制破产导致次年供给发生断崖式真空；  
   - **峰顶/灾年（物贵伤民）**：市场遭遇天灾或挤兑投机，价格脱轨暴涨，国储果断开仓抛售廉价现货，以充沛供给砸碎投机泡沫，平抑通胀恶疾。

2. **起效的唯一刚性铁律：高频流动与双向对流**：  
   - 血液能够维系生命，前提在于它必须永不停歇地在血管与心脏之间对流循环；  
   - 储备物资必须在物理与化学品质发生严重折旧之前，通过市场化机制完成平价甚至溢价轮换——即“物资进、现金出”与“现金进、物资出”的高频置换。**储备的灵魂是流动性（Liquidity），绝非贪婪的静态占有欲**。

#### 二、 垃圾回收站的成因：当退出通道被“无限溺爱”彻底焊死

现代国储机制在大宗农产品与部分初级原材料上之所以频繁陷入名存实亡的困境，其根源正在于**“只吞不吐、只买单不问责、只兜底不淘汰”的逆向淘汰异化**：

```
                    【国家储备异化为“垃圾回收站”的坏死闭环】
  
  【政策兜底出台】──►【无偿派发看跌期权】──►【上游道德风险爆发】──►【疯狂盲目扩产】
         ▲                                                               │
         │                                                               ▼
  【财政展期维稳】◄──【库容爆满无法抛售】◄──【物理与金融双重坏死】◄──【堆积入库沉没】
  (掩耳盗铃拖延)     (抛售则砸穿现货)        (纤维变质+借贷失血)        (退出通道焊死)
```

1. **兜底变异为道德风险（Moral Hazard）的免费看跌期权**：  
   - 正常的自由市场交易中，种植农户与加工企业必须时刻紧盯下游订单走势、出口关税以及地缘脱钩风险，一旦预期亏损，便会主动调减种植面积、关停低效车间；  
   - 然而，一旦“国储托底收储”被升格为政治硬任务，政府实际上无偿向全产业链派发了一张**“全额兜底看跌期权（Free Put Option）”**——无论外部需求如何腰斩、商誉如何透支，只要产品生产出来，国家就必须无条件按保底价全收入库；  
   - 这种无限度的制度溺爱，彻底摧毁了市场价格对供求的调节功能。上游在道德风险驱使下肆无忌惮地扩大机播面积、拼命抽取地下水、加大化肥农药使用，生产线马力全开，将财政兜底当成了永动机。

2. **储备物资在物理与金融维度的双重癌变**：  
   - **物理维度的不可逆坏死**：大宗商品皆有严格的保质期与理化指标折旧。棉纤维存放三年便泛黄脆化、强力断裂；粮食久储生虫酸败；原油长期封存析出胶质与油泥。这批物资在官方账册上依然按照当年高昂的入库收购价列为“优质存货资产”，但在现实世界中早已退化为现代精密工业无法使用的**物理垃圾**；  
   - **金融维度的失血坏死**：国储收购这批物资，动用的是政策性银行（如农业发展银行）巨额的低息专项贷款与国家财政贴息。数以千亿计的流动性资金沉淀为库房里的死物，每年还需持续拨付数额惊人的仓储租金、消杀熏蒸费、通风防霉电费与巨额利息。**原本救急的流动资产，在资产负债表的借方彻底固化成了不可逆的坏账烂疮**。

3. **想吐吐不出：抛出即暴跌的死局**：  
   - 真正的商业垃圾站尚能实现资源废旧利用，而异化的国储系统甚至丧失了“吐出”的资格；  
   - 若国储按真实的残值折价抛售这批陈化变质的库存，庞大的廉价低质供给会瞬间将脆弱的现货市场砸穿底背离，导致本已在亏损线上挣扎的当季种植户与轧花厂当场大面积破产暴雷；  
   - 若不抛，便只能在昏暗的库房里靠审计签名和贷款展期粉饰太平，维持“这堆发黄烂棉依然值百亿真金”的荒诞神话。

#### 三、 花钱的千古死结：为何“流动性补血”总是滑向“注入血栓”？

“花钱是一门大学问，历朝历代直至今日依然无法破局。”宏观经济治理中最深沉的悲剧，莫过于**原本旨在为机体注入营养的财政血液，往往在官僚与资本的合谋下，被硬生生凝固成了血管中的脂肪血栓**：

| 机制环节 | 理想的流动性补血模型 | 现实中滑向血栓的异化路径 |
| :--- | :--- | :--- |
| **资金投向** | 注入毛细血管：终端消费者钱包、教育研发与民间创新生态 | 被既得利益集团截流：大举修建可供审计核验的宏大硬质设施 |
| **资产形态** | 激发轻资产流转，降低交易成本，促进高频换手 | 固化为无人通行的偏远桥隧，或年年滞销却不断扩容的重资产冷库 |
| **短期政绩** | 见效缓慢、难以量化、政绩难以直接归功于个别长官 | **短期 GDP、固定资产投资与税收报表极其亮眼** |
| **长期后果** | 培育出高度韧性、自主自我造血的多元市民社会 | 资产沉没，全社会被迫承受数十年的财政贴息与通缩通胀复合折磨 |

- **用制造“死资产”来粉饰当期“活数据”**：  
  动用财政资金收购滞销农副产品、大建现代粮棉仓储物流园，在当期的统计年鉴上全是令人瞩目的政绩与就业；但这种花钱方式本质是在向健康肌体的动脉里强行灌注油脂。十年之后回望账本，除了满库发霉变质的陈年死货与背负在纳税人头上的巨额沉没成本，什么也没有留下。

#### 四、 结穴：善聚财不如善散财，善养物不如善杀物

管仲论治国之道，曾言：“不明于岁之通，不可为国；不审于时之利，不可为政。”

- **杀伐决断的经济学意义**：  
  一个健康的经济机体，不仅需要供给的繁衍能力，更需要果断切除坏死组织的“代谢与杀菌能力”。不敢承受资产减值的短期剧痛，便注定要承受全盘感染的终极休克；  
- **破除伪善的救市迷信**：  
  常平仓与国储制度的崇高初衷，绝不是为了替不计后果的盲目扩产买单，更不是为了充当僵尸产能掩耳盗铃的太平间。唯有敢于切断无限兜底的免费期权，让市场之手无情碾碎不合时宜的低劣供给，国家储备才能从垃圾场重回真正的蓄水池。

**【收束语】**  
先师勉斋先生曾论汉唐府库之弊，警示曰：“藏物以待用，非藏物以待腐也。今有司见金帛山积，则喜见于色；见库廪空虚，则忧见于容。此市井守财奴之识，安知大政之盈缩哉！”  
天山脚下的风声依旧凛冽，那些在巨大遮雨棚下静静泛黄老化的棉山，犹如一尊尊无声的泥塑神像，无声嘲弄着人类对抗周期的虚妄与傲慢。治大国如烹小鲜，最忌以无限之溺爱行大恶于天下；唯有当全社会学会如何冷酷而理性地直面损失、清扫垃圾之时，那条被血栓堵塞太久的经济命脉，方能重新奔涌出健康的清泉。
