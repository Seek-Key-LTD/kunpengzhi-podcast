### 【桃園格竹 · 第二十五讲】浮财与机杼：论保留地之安乐死与车间之破壁术

**【格物札记】**

夫天下列国，御边之策无外两端：一曰“置之度外，圈以金笼”；二曰“破其门户，勒以机杼”。  

西夷论边疆之治，动辄以新大陆印第安保留地为圭臬，谓划界自治、许开博戏、月给廪饩，方合人权多元之至理。此真伪善至极之蒙蔽也。  
昔美洲诸部，本驰骋于旷野。白人以条约画地为牢，诱之以赌博免税之偏财，餧之以无劳而获之米粟。名曰敬其图腾，实乃将其摒弃于近代工业文明之血脉之外。  
居无大工之磨砺，行无科技之研求，终使万千健儿沦为醇酒毒蛊之殍，以残破歌舞博游人一笑。此乃**“以虚名废其四肢，以浮财断其筋骨”**之慢性绝户计也。何曾有毫发之尊严？  

反观西陲近十载之变。  
当道诸公见绿洲深处，神权门宦盘根错节，闲民游荡，遂生狂暴之机心。  
彼不假保留地之温情，径以工厂之鸣镝，破回坊之清幽。百万人尽入车间，学汉文以通货殖，操机杼以谋微赀。  
晨钟暮鼓，化为打卡之钟声；宗族诫命，变作流水之定额。  
西人惊呼其为“徭役”，盖因其粉碎了田园牧歌之幻相，刺破了消极自由之屏障；  
然若从唯物格物之实效观之，唯有当西陲儿女亲手踩动缝纫机、领取第一纸薪水之时，方脱尽数百年宗法父权与阿訇口舌之奴役。  

夫赌场之笼，虽饰以黄金，其内乃活人之冢；车间之锁，虽冷酷如铁，其出方为现代之民。  
善弈者不与愚儒论仁义，唯问算力之兴衰。  
究竟是养之于废柴以博外邦虚名，抑或锻之以铁砧以强天下筋骨？格史至此，掩卷四顾，其利害得失，早已刻在万里山河之机器轰鸣之间矣！

#### 一、 美洲保留地模式：用“免税、赌场与代金券”实施的文明安乐死

西方知识分子在政治正确语境下推崇的边疆少数族群治理蓝本，本质上是北美处理第一民族（First Nations）的历史路径：划定封闭的印第安保留地（Indian Reservation），赋予名义上的部落司法自治权，免除部分联邦税收，特许经营高利润的博彩与烟草零售，按人头发放联邦救济金。

然而将这笔温情账本翻至底层，呈现出的却是一场极其残忍的**文明降维与慢性社会性阉割**：

1. **物理与经济维度的绝对绝缘**：  
   - 将特定族群物理隔离在现代主流工业分工体系之外，彻底剥夺其嵌入全国资本、物流与先进制造业网络的契机；
   - 其客观结果是：全美数百个印第安保留地普遍退化为高自杀率、高酗酒率、阿片类药物与芬太尼肆虐的绝望孤岛，常年失业率维持在 40% 至 50% 以上；

2. **“特许博彩与财政封口费”的暗黑本质**：  
   - 主权政府支付了一笔高昂但绝对可控的转移支付“封口费”，在实质上永久买断了原住民在现代国家政治与经济中成为主导力量的一切可能性；
   - 它在名义上尊重了你的羽毛冠冕、萨满图腾与传统歌舞，实际上是**将一个曾经在北美大平原上逐水草而居的活人生态，制成了供白人游客周末观光消费的“活体人类学博物馆（Human Zoo）”**；
   - 当一个族群彻底脱离了现代大工程、数理科学与现代商业分工，只剩下依靠特许赌场税收过活时，其文明的主体性便已陷入彻底脑死亡。

#### 二、 东亚大陆模式：用“流水线与考勤表”强行解构前现代共同体

东亚大陆自秦汉以降推行郡县制，延至近代的列宁主义组织机器，其底层算法完全相反：**大一统工业帝国绝不容许版图之内存在无法穿透的“法外自治盲肠”**。

在经历残酷的暴恐裂痕之后，边疆政策发生根本性硬化转向，其内在核心逻辑绝非简单的“去不去找他们玩”，而是**“用现代工业世俗纪律，暴力切断前现代宗教门宦与宗族共同体的神经末梢”**：

1. **为什么必须去“踩缝纫机”？**  
   - 在绿洲传统的熟人社会里，个人的身份认同、婚姻、劳作与生老病死，被死死垄断在阿訇、清真寺长老与宗族父权手中。游离于现代生产体系之外的闲散青年，天然是原教旨极端主义最易滋生的温床；
   - **车间的传送带、打卡钟、工位上的缝纫机与装配台，是现代性最粗暴但也最有效的“去神圣化机器”**；
   - 每日晨间八点打卡上工，严格按计件核算报酬，按月结算工资转账，缴纳工伤与医疗保险。这一整套冰冷的工业体制，硬生生将每一个具体的男女从封建宗族网络中剥离出来，原子化，重组为标准的**“现代产业工人”**。

2. **“一日不作，一日不食”的现代世俗洗礼**：  
   - 唐代禅门百丈怀海禅师的这句清规戒律，在此被提升为现代国家治理的铁律；
   - 当一名年轻的绿洲女性依靠自己的双手在纺织流水线上劳动、在银行卡里领到属于自己支配的第一笔合法薪水时，她在经济事实上第一次挣脱了数百年宗族父权与宗教诫命的绝对压制；
   - **这就是西方谴责其为“压迫性徭役”，而中枢执行者却自命为“深层人权解放”的根本认识论断层。**

#### 三、 哪种更“合理”？——两套治理账本的冷血对账

抛开意识形态的情感修饰，将两种模式置于国家治理能力与族群终局的解剖台上：

```
                    【边疆少数族群治理的两极范式】
                    
  【北美模式：圈以金笼】                             【东亚模式：勒以机杼】
   空间：画地为牢、保留地隔离                       空间：消除边界、嵌入全国供应链
   经济：博彩免税、救济代金券                       经济：进厂务工、流水线计件工资
   宗族：固化部落酋长特权                           宗族：粉碎门宦垄断、实现个体原子化
   文化：活体人类学陈列馆                           文化：强制通用语学习、全面世俗化
   终局：边缘化、酗酒溃烂、文明安乐死               终局：磨平棱角、强行锻造为现代工业齿轮
```

| 评估维度 | 北美“保留地赌场 / 代金券”模式 | 东亚“工业化车间 / 进厂务工”模式 |
| :--- | :--- | :--- |
| **底层人性假设** | 人性需要维持传统神圣性、原始自治与消极自由 | 人性必须被强制规训进现代世俗生产力协作大网 |
| **治理工具链** | 空间隔离、财政赎买、特许偏门（博彩与烟草） | 空间打破、消除边界、强制融入全国工业供应链 |
| **对前现代组织的处置** | 予以法律固化（部落酋长与萨满坐地收租） | **彻底连根拔起，以现代科层与劳动合同全面覆盖** |
| **族群演化终局** | 边缘化、沉溺于低阶福利救济，丧失自决能力 | **被剥离原教旨属性，强行转化为现代工业构件** |
| **系统综合代价** | 永久性的社会肌体溃疡、种族原罪与代际沉沦 | **短期的极高社会阵痛、国际制裁与制度刚性脆性** |

- **西方法理的批判基石**：源自卢梭以降的消极自由——“倘若个体甘愿于旷野牧羊诵经，行政强权凭何以‘文明’之名剥夺其懒散与传统的自由？”
- **大陆政权的执政公理**：源自近代总体战唯物主义与富国强兵哲学——“在地缘生存竞争的钢铁丛林中，任何不掌握通用工业语言、不具备现代分工协作能力的边缘族群，要么沦为境外渗透的肉弹死士，要么沦为拖累整个帝国现代化的坏死组织。不融入世俗劳动，就休想在大一统工业文明中苟全。”

#### 四、 结穴：赌场之笼与车间之锁

历史在给所有帝国出题时，从来不提供无痛的选项。

- **金笼之死**：  
  保留地用花花绿绿的钞票与免税凭证，在原野上圈出了一座座看似自治的文明活人冢，以人道之虚名，行安乐死之实诛；
- **铁锁之生**：  
  车间流水线用刺耳的电铃与严苛的考勤，把千百年来的前现代温情与荒蛮一同碾碎，以铁血之严酷，逼出了第一代能看懂图纸、拿得稳游标卡尺的现代劳动者。

**【收束语】**  
先师勉斋先生曾论周秦之变，曰：“周道尚文而虚，秦法任力而实。文之弊也，使民为蠹；力之弊也，劳民以急。然欲救天下之乱，舍大功大用之业，未由也已。”  
百年前横跨大陆的印第安野牛早已绝迹，取而代之的是保留地夜总会里醉眼朦胧的赌徒；而在天山南北连绵千里的工业园区内，缝纫机齿轮的高速咬合声，正无情而坚定地重塑着这片古老绿洲的文明基因。是非功过，青史如镜；唯有那些真正能将一国亿万兆民带出蒙昧深渊的铁锤与机杼，方能经受住天地大数的终极盘剥。
