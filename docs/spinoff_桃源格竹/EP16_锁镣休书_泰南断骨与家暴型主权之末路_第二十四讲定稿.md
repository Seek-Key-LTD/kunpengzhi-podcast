### 【桃園格竹 · 第二十四讲】锁镣与休书：泰南断骨与家暴型主权之末路

**【格物札记】**

凡天下言王道者，莫不假“天下大一统”为至善之归宿。然圣人设国，本为庇民；若国已成牢狱，大一统便成锁镣。  

今观暹罗之局，都门曼谷珠翠罗绮，豪商巨贾日进斗金；南疆三府则如置身蛮荒，黎庶困顿，人均资产竟相差达十倍之巨！不仅生计被剥夺，宗族门宦之信仰、父母相传之方言，亦尽遭北方黄袍僧侣与军宪官吏之荡涤。此非同舟共济之邦家，实乃同室操戈之酷刑。  

尤可诛者，在朝诸公怀“预则立”之机心，阴以穷困弱其骨髓，以闭塞遏其生机。彼惧南疆地狭通达而自立，遂甘使万千生灵世受绝户之苦，以此为防微杜渐之良策。此等心术，直以家暴为御妻之术，以断足为防逃之方，名为主权，实同盗跖！  

孟子曰：“君之视臣如土芥，则臣视君如寇仇。”  
泰南健儿揭竿于莽林，炸铁道、袭哨所，世人轻斥为狂热与叛乱，独不见十倍断崖之下，生民被剥夺至一无所有时之绝望狂呼。若婚姻之道，暴虐凌辱至此，则**“劝离而不劝和，革命以求自立”**，正是天道自然之所归，岂容伪儒以“保全宗族”之虚语强行勒逼？  

奈何列国森严，万邦各顾其私。东盟画地为牢，视惨呼于邻壁而不闻；曼谷佩剑端坐，执神权以断生路。  
夫天理虽昭，人间尚乏主持离异之法槌。泰南之创，遂成东亚腹地一道永不结痂之暗疽。  
格史者至此，当发警世之语：**凡不能利其民而专施淫威者，其主权之冠冕，终将化为自焚之烈焰；凡以家暴维系之社稷，纵能锢其躯体于一时，安能阻其骨血生生世世之离心！**

#### 一、 账本上的十倍断层：帝国殖民内化的“经济种姓制”

南北人均财富与收入相差近十倍，绝非单纯的区域经济失衡，而是曼谷中央政权在近代国家构建中推行的典型**“国内殖民（Internal Colonialism）”**：

1. **抽血式的资源单向虹吸**：  
   - 大曼谷都会区集中了全泰国近半数的金融资本、高等教育资源、跨国直接投资与现代医疗系统；
   - 泰南三府（北大年 Pattani、也拉 Yala、陶公 Narathiwat）拥有丰富的天然橡胶、优质渔港与热带矿产，但在中央财政的再分配链条中，南方长期被系统性地排除在国家工业化与基础设施现代化的红利之外，沦为纯粹提供初级原料与廉价劳力的经济附庸。

2. **语言、信仰与法权的全面压制**：  
   - 曼谷不仅在财政上视南方为藩篱，更自二十世纪初起强行推行激进的**“同化泰化政策（Thaification）”**：
     - 在基础公立教育中强制废除传统爪哇文（Jawi）与马来语教学，全面灌输中部泰语与大泰民族认同；
     - 用曼谷法典强行覆盖扎根数百年的伊斯兰沙里亚习惯法；
     - 南方的省府长官、司法官吏与警察指挥系统，绝大多数由曼谷中央直接空降信仰上座部佛教的泰族官僚把持，形成了一道壁垒森严的文化与权力种姓。

3. **“家暴”的常态化法理：以达拜惨案为例**：  
   - 2004 年爆发的“达拜惨案（Tak Bai incident）”，泰国军警在清场示威后，将数百名被捕的穆斯林青年像原木般层层叠压在军用卡车车厢内长途押送，致使 78 名示威者在窒息与高温脱水中活活闷死；
   - 这一人间惨剧彻底撕下了主权同胞的面具——在中央统治精英眼中，南方穆斯林不是享有对等公民尊严的契约同胞，而是**寄养在柴房里、稍有申诉即以军靴践踏的异类贱民**；
   - 当一个政权对特定区域既不提供公共善治，又将枪炮戒严作为日常治理手段时，它已经在实质上**单方面彻底废弃了洛克意义上的“社会契约”**。

#### 二、 预先惩罚的悖论：以贫穷为镇静剂的暗黑统治学

“预则立”的古典治理术，在泰南被畸变成了一种**“对分离主义的预先性惩罚”**，陷入了不可逆的“自证预言（Self-Fulfilling Prophecy）”恶性循环：

1. **防患于未然的过度防御**：  
   - 曼谷之所以长期对克拉地峡深水港、工业走廊与大型跨国陆桥项目阳奉阴违、反复搁置，其深层盘算正是出于对南方的极度不信任——害怕克拉地峡打通、现代工业资本流入后，南方马来穆斯林社会会迅速完成经济自足与阶层发育，从而拥有与曼谷彻底摊牌的资本；
   - 于是，“让南方保持闭塞、贫困与半荒芜”，被暗中当成了维持帝国版图完整的**“地缘镇静剂”**。

2. **统治道义合法性的自我瓦解**：  
   - 如果一个中央政府遏制特定区域发展的核心目的，仅仅是为了防止其羽翼丰满后脱离掌控，那么这个政权便彻底丧失了现代国家的道德根基，退化为一个依靠暴力占山为王的中世纪绑匪集团；
   - 依循美国《独立宣言》与自然法传统：“当任何形式的政府破坏了保障人民生存、自由与追求幸福的目标时，人民便有权改变或废除它。”当维持国家统一的代价是让一方民众生生世世背负十倍的贫困与戒严枪口时，反抗与分离就不再是原罪，而是**基于人类基本生存权的“紧急避险（Duress）”与正当自卫**。

#### 三、 劝离与劝和的终极悖论：谁拥有离婚的法槌？

在道义层面上，“劝离不劝和”占尽了天道人伦；但在现代国际法与现实主义地缘的冷酷铁壁面前，这场漫长家暴却撞上了绝望的死胡同：

```
                    【“家暴型国家”的离异死结模型】
  [道义层：自然法伦理]                          [实体层：韦伯式国家暴力垄断]
   南北人均财富相差达十倍                           曼谷军人集团与王室神权
   文化剥夺 + 军警日常高压                         (垄断合法暴力与无限戒严权)
          │                                                 │
          ▼                                                 ▼
   【契约早已撕毁】                                  【主权神圣不可分割】
   (家暴成立，劝离正当)                              (地峡为帝国咽喉，宁毁不让)
          │                                                 │
          └───────────────────────┬─────────────────────────┘
                                  ▼
                     【现实困境：缺乏破壁法槌】
               东盟宪章“互不干涉内政”神圣原则（东盟铁律）
               马来西亚不敢公开接盘（惧引火烧身打破边境现状）
                                  │
```

1. **没有外在法庭的家庭暴力**：  
   - 凡间婚姻若遇此等暴虐，受害者尚可求助司法裁判、分割财产、强行判离；
   - 然而在威斯特伐利亚主权体系下，**“神圣主权”本身就成了施暴者的终极庇护所**。东盟（ASEAN）奉行“互不干涉内政”的绝对铁律，吉隆坡即便私下对泰南同胞抱有极深同情，但在外交明面上亦只能恪守“此属泰国内政”的口径，唯恐激化边境冲突引发整个中南半岛的领土重组雪崩。

2. **宁可打烂、绝不放手**：  
   - 对于曼谷的军阀与保皇势力而言，泰南三府甚至克拉地峡不仅仅是一片土地，更是**近代“暹罗大一统帝国”叙事的底线图腾**；
   - 一旦允许南方公投离异，近代强行缝合的“大泰国”神话瞬间就会引发连锁多米诺效应——东北部伊森（Isan）的老挝族裔地带、北部兰纳（Lanna）古国故地势必相继离心；
   - 因此，曼谷宁可让泰南三府沦为永无宁日的治安泥潭，宁可以数万驻军每日放血，也绝不可能交出那一纸和解的休书。

#### 四、 结穴：大一统虚妄下的未结死局

近代民族国家的狂妄在于：妄图用一张行政地图和一柄刺刀，强行抹杀千百年来由河流、季风、语言与信仰自然生长的文明边界。

- **伪善的大一统**：  
  只要国家理性依然凌驾于公民生存权之上，只要十倍的经济剥夺依然被包装在“领土神圣”的锦旗之中，泰南丛林里的土制炸弹与暗夜枪声便永远不会停歇；
- **历史的终局法则**：  
  强行捆绑的绳索磨得越紧，陷入肉里的创口就越深。当暴力机器的边际效能终于无法覆盖维稳成本的那一天，帝国在虚妄图腾崩塌时所付出的代价，终将百倍于当年那纸迟迟不愿写下的和平休书。
