### 【桃園格竹 · 第二十二讲】野火与空城：论印支霸权之虚妄与继续革命之穷途

**【格物札记】**

夫天道好还，兵凶战危。河内克西贡之后，骄横日甚，妄图以“印支联邦”之虚名，兼吞老、柬两疆，复假北方苏俄之舰队，立次级帝国于南海之滨。  

然地缘之算，从来不由小邦自专。莫斯科以越南为扼喉之铁爪，北京则以金边为破腹之飞芒。中越十年之龃龉，非关恩义之薄凉，乃天下棋局两极合围与反合围之势所必至也。  

尤堪格物者，乃波尔布特之异端。  
坊间多谓其承袭延安“农村包围城市”之法，此貌合神离之谬论也。昔延安居野，如新教抗议之徒避世修身，志在以乡村之新民，涤荡城市之积弊，所患者在不入朝，所谋者在兼天下。  
柬共之术，则堕于诺斯替之魔障。彼以城市为不可宥之深渊，以生民为待涤之腐肉。夺权甫定，遂空其城邑，毁其庠序，灭其货殖，以极刑御饿殍，以白骨筑公社。此非阶级之进境，实乃愚昧向文明反扑之兽性狂澜。  

夫天下至难者，在野之剑，如何化为在朝之规。  
革命既成，金汤已定，昔日之苦修圣徒，转瞬皆成九重深宫之朱紫。托洛茨基惧其僵死，创“不断革命”之说；毛氏忧其蜕化，发“无产阶级专政下继续革命”之悲鸣。  
盖以造反之烈火，焚自身之庙堂，虽怀“正气存内”之悲愿，终难逃“自伤肺腑”之浩劫。而波氏之流，更将此说推至荒谬绝伦之极境，不杀敌寇，专戮腹心，终致国破族残，反予河内长驱直入之口实。  

格史至此，当明：**破山中贼易，化心内魔难。**  
执纯洁之尺，量凡尘之躯，其终局必非天国之降临，唯见无尽之焦土与杀戮耳！

#### 一、 印度支那联邦：小苏联的幻梦与边缘阻击

越南在 1975 年吞并南方之后产生的“印支联邦”野心，本质上是在**莫斯科大苏联体系的庇护下，试图在中南半岛克隆一个“区域次级苏联（Sub-Soviet）”**：

1. **法属印支的地缘遗产（次级帝国的胃口）**：  
   - 法国殖民时期将越、老、柬整合为统一的殖民行政区与关税区；
   - 河内从建党伊始（印度支那共产党）便自视为印支三邦天然的长兄与宗主。抗美大胜之后，其内部不可避免地滋生出普鲁士式或大塞尔维亚式的地区霸权冲动——试图将老挝、柬埔寨纳为其绝对控制的卫星国，复刻南斯拉夫在巴尔干、苏联在东欧的“大家庭秩序”。

2. **莫斯科的冷酷算盘：铁钳合围中的南翼爪牙**：  
   - 苏联对河内的巨额经济与军火输血，绝非出自无私的共产主义博爱，而是**将其作为全球遏华战略中的“南线铁钳”**；
   - 当年中苏交恶已入至暗时刻，百万苏军陈兵中苏、中蒙边境；苏联若能通过 1978 年《苏越友好合作条约》将金兰湾据为苏联太平洋舰队的前沿母港，并在西南建立一个由河内统领的印支军事同盟，就能在地理上对中国完成极其严密的**“战略大包围（Cordon Sanitaire）”**。

3. **北京的战略抉择：远交近攻的反包围反切**：  
   - 面对这条步步收紧的铁锁链，北京对波尔布特的民主柬埔寨施以全方位经济援助、重型军火与参谋训练，绝非源于在意识形态上认同波尔布特的极端恐怖施政，而是冷酷地缘力学下的**“阻击战役（Anti-Encirclement）”**；
   - 柬埔寨是粉碎“印支联邦”铁板一块的唯一物理楔子。唯有在河内的软肋上扎下一颗硬钉子，才能切断苏联南翼铁钳与印度次大陆的呼应，确保东南亚陆上不被彻底封死。

#### 二、 波尔布特的形似神非：从“清教徒抗议”堕入“诺斯替自噬”

坊间许多不求甚解者，常将红色高棉在柬埔寨的暴政简单比附为延安“农村包围城市”的翻版。这种论调只见皮相，完全失落了二者在政治神学与社会学上的根本断层：

```
                    【两种“农村路线”的本质断层对比】
┌──────────────┬────────────────────────┬────────────────────────┐
│   剖析维度   │   毛泽东的“抗议派清教徒”       │     波尔布特的“诺斯替极端异端” │
├──────────────┼────────────────────────┼────────────────────────┤
│ 权力生态位   │ 在野抗议派，对抗在朝官僚买办   │ 骤然夺权，以绝对国家机器行私刑 │
│ 对城市的态度 │ 视城市为权力与资产阶级堡垒，   │ 视城市为绝对的原罪肉身，       │
│              │ 意在围困、改造并最终接管改造   │ 采取三天内彻底排空的物理灭绝   │
│ 组织与社会学 │ 建立精密的动员神经网（白细胞） │ 摧毁家庭、货币与文字，退行至   │
│              │ 扶正祛邪，赋草民以主体神格     │ 原始兵营，以“安卡”行盲目自杀 │
│ 治理终局     │ 入朝后重塑总体战现代国家       │ 陷入恶魔主义深渊，全盘自我吞噬 │
└──────────────┴────────────────────────┴────────────────────────┘
```

1. **在野清教徒的政治抗议**：  
   - 中共早期的“农村包围城市”，发生于国民政府彻底垄断通商口岸与城市资源、工运陷入物理灭顶的特定生态位下；
   - 它犹如十六世纪的欧洲新教抗议派（Protestants），逃离腐朽的大教堂，遁入乡野苦修，建立纯洁的信徒共同体与动员细胞。其底层逻辑从来不是在物理上摧毁现代城市文明，而是**在乡村积蓄高度组织化的生产力与武装力量，最终进城接管、改造并重组现代政权**。

2. **波尔布特的异端堕落：反现代性的兽性反扑**：  
   - 红色高棉核心层在巴黎受过粗浅左翼哲学与无政府主义思潮的杂交熏陶，回国后直接跳过所有人类文明演进阶段，走向了一种极端的**“农业原教旨诺斯替主义”**；
   - 波尔布特把城市（金边）视为绝对不可救赎的罪恶深渊，把知识、眼镜、医院、货币、商业一概视为必须净化的污浊毒素。夺权仅三天，他便用刺刀和机枪强行将金边两百余万平民驱逐进原始热带丛林；
   - 这根本不是阶级革命，而是一场**以革命为幌子的反文明、反人类浩劫**。当一个政权以消灭家庭、取消文字与盲目杀戮自家骨干为日常时，它便已经丧失了一切文明生存的合法性底线。

#### 三、 在朝者的合法性危机：热月困境与“继续革命”的神学死结

从比较政治制度学剖析，革命力量“从在野到在朝”的转变，面临着人类一切激进政权共同的**“热月危险（Thermidorian Reaction）”**：

1. **在朝后的“官僚科层化僵死”**：  
   - 在野时，你可以凭着清教徒式的道德洁癖、禁欲主义与均贫富口号动员千百万草根；
   - 夺取政权之后，原先身披草鞋的苦修者不可避免地要搬进深宫大院、坐上防弹轿车、管理庞大的官僚与工业体系。昔日的革命先锋，迅速演化为他们当年誓死要推翻的“在朝特权阶层”。

2. **从“不断革命”到“继续革命”的内在引力**：  
   - **托洛茨基的“不断革命论”（Permanent Revolution）**：立足于世界资本主义体系的整体性，认为孤立的一国绝不可能建成社会主义，必须将暴动火种不断引燃至全球工业中心，同时在苏俄内部无情清洗官僚化反动退潮；
   - **毛泽东的“无产阶级专政下继续革命”（Continuous Revolution）**：中国共产党虽在文辞上严厉批托，但在最高统帅的系统动力学诊断上，毛得出了近乎同构的绝望预判——**最大的危险不在于逃亡孤岛的蒋介石，而在党内日渐板结、官僚化的“资产阶级当权派”**；
   - 既然正规的官僚法律与党纪已沦为科层集团自我庇护的盾牌，领袖便试图发明一种**“将自我休克日常化、体制化”的政治神学**：隔若干年便发动群众运动，用在野时期的破坏性烈火，去猛烈焚烧自己一手缔造的国家庙堂骨架。

3. **烈火焚躯的终极悲剧**：  
   文革的沉痛动荡，以及波尔布特在金边对自身中央委员、大军区司令展开的疯狂灭门清洗（S-21集中营屠杀），本质上都是**“执政者妄图用在野时期的反噬烈火来维系所谓纯洁性”所导致的免疫系统系统性崩解**。

#### 四、 结穴：破山中贼易，化心内魔难

将中南半岛的血泪篇章合拢回东亚大棋局，地缘霸权与政治神学的终局冷酷如铁：

- **小霸狂妄的终点**：  
  越南企图依附远方巨灵吞并邻邦、建立印支霸权的迷梦，在 1979 年的隆隆炮声与随后的十年边境消耗战中被彻底击碎，最终不得不狼狈从金边撤军；
- **纯洁神学的绞索**：  
  红色高棉试图用最极端的屠刀在人间建立反智乌托邦，结果自身在恐怖清洗中流尽了最后一滴血，最终反噬而亡，化作历史陈列馆里的一具具累累白骨。
