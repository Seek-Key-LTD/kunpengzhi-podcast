# 《龟蛇锁江》刍议 · 专栏总纲与 EP01

> **主理人**：**珞珈**（武汉大学法学院 / 边界与海洋研究院 · 国际公法与冷战条约 · 湖北黄冈做题家 · 34 岁副教授）
> **地标**：武汉长江大桥头 / 龟山与蛇山对峙江岸（龟蛇锁大江）
> **体裁**：单口硬核国际条约法理解剖脱口秀 / 条约法医室
> **总问题**：一部在纸上编译通过的条约，到了真实世界，到底能不能盛住水？

---

## 专栏总纲：不画电路图，做水压破坏试验

“龟山锁汉水，蛇山锁大江。”

珞珈不把国际法当神谕，也不把它一概骂成废纸。他认定条约是一种精密、脆弱而必要的**制度电路**：文本把主权国家、国际组织、法院、国内机关和私人主体接成有条件的有向图；可一旦地缘冲突、预算约束、选票压力、舰队、资本流与难民潮真正灌进来，纸面上的闭环未必承得住现实中的压力。

因此，《龟蛇锁江》不教观众膜拜条约，也不靠“国际法都是免责声明”的口号取胜。它做的是一项更冷的工作：逐段验收一项国际义务能否从**同意**、**解释**、**国内转换**，一路送达**执行**与**救济**。

### 珞珈的电路图

| 条约结构 | 工程比喻 | 法律上真正要验的东西 |
| --- | --- | --- |
| 定义、适用范围、地域与时间条款 | 口径、限流器、准入规格 | 谁是主体，什么事实触发，适用到哪里 |
| `shall`、`must`、合作义务 | 定向导线 | 义务是结果义务还是尽职义务，谁必须做什么 |
| 例外、保留、国家安全与公共秩序条款 | 旁路、泄压阀 | 阀门由谁启用，能开多大，是否可审查 |
| 争端解决、报告、核验 | 压力表、探伤仪、保险丝 | 谁认定事实，裁决是否有管辖权，如何纠错 |
| 生效、退出、暂停、终止 | 总闸、活接头、检修口 | 谁能拔管，须提前多久通知，代价由谁承担 |

这不是把法律硬说成电子学。比喻的纪律在于：**每一个元器件都必须回到一条确定的文本、一项确定的程序或一种确定的执行能力。**说不清承重主体、触发条件和救济路径，就不准把它叫“保障”。

### 不是总控水泵，是一百台泵的脆弱并网

国际法没有一台能够直接给全世界开阀的总控泵。更接近现实的图景是：一百个各怀心思的鱼缸，自行决定是否接管、何时开阀、装多粗的管、把水送到哪一层；国际组织、秘书处与国际法院能够协调、计量、发出信号，却通常不能替主权国家拧开国内的阀门。

这就是一元论与二元论在工程现场呈现出来的差别：有的法域允许特定条约较直接地成为国内法规范；有的则要求立法转换、行政实施或司法确认。可这层国内接口的阻抗，并不自动抹掉国际层面的欠账。《维也纳条约法公约》第 27 条明确：一国不得援引本国法为不履行条约的理由。

所以珞珈要追问的从来不是一句“条约有效吗”，而是四句：

1. **谁有阀门钥匙？** 是行政机关、议会、法院、地方政府，还是缔约国集体？
2. **管径多大？** 国内转换后，原义务还剩多少可执行内容？
3. **堵了谁通？** 是否有报告、审查、仲裁、反制、赔偿或再谈判机制？
4. **爆了谁赔鱼？** 受害者能否获得救济，还是只留下国家间一笔难以收取的责任账？

### 固定节目程序：四步水压试验

每一期只选一个条约、一个条款群或一组制度接口，按同一套程序解剖：

1. **看电路图**：用文本主义把定义、动词、触发条件、例外、争端处理和退出条款拆出来；
2. **找进水口**：标明真实压力从哪里来——武力、财政、产业、国内程序、事实认定，还是跨境资本；
3. **加压注水**：拿判例、历史危机或极端边界条件测试额定负荷；
4. **听爆裂声**：结论只能落在五种状态之一：正常承载、限流泄压、局部渗漏、执行堵塞、整体击穿。

“条约求导不收敛”的含义也在这里：不是条文有语法错误，而是它试图把不断变化的政治—物理变量装进一个规范方程；当边界条件变化得比解释、履行与救济机制更快，解就不再稳定。

## 人物素描：岩点、锚点、草缸与兜底条款

珞珈固定去室内岩馆，但不徒手、不追险，也不把玩命当成年轻人的证明。他爱读路线：墙上的点很多，真正能承重的必须逐个验；每一步都要问支点在哪里、退路在哪里、保护由谁负责。

他在武大后山折腾过草缸，因此也知道自循环最骗人的地方：图纸上的透明亚克力管很漂亮，真跑起来就有水垢、青苔、生物膜与滤材板结。水流得越久，越不能把“系统仍在嗡嗡响”误认为“每个缸都喝得到干净水”。

他的原则是：

> **“看见攀点，不等于它能承重；能抓住，不等于你有权把全身交给它。先验锚，再上身。”**

攀完后，他会安稳坐在垫子边，用沾着镁粉的手翻出条约文本，继续用红笔圈动词。

### 做题家不是唱反调：去魅以后仍要维修

珞珈要同时拒绝两种偷懒。

- **经院神学式偷懒**：把 `pacta sunt servanda`、善意和“国际共同体”念成护身符，仿佛只要文本庄严，压力就会自行消失；
- **丛林废纸论式偷懒**：把一切条约都归结为大炮射程，因而不再解释国家为何反复谈判、交换照会、争夺一个定义词、花高价把案件送进仲裁。

黄冈做题家的答案不是第三套口号，而是把问题还原为可验算的系统：没有神圣的善意，只有义务、能力、激励与监督能否在给定边界条件下闭合；没有悬空的“正义”，只有谁承担压降、谁拥有阀门、谁在爆管后赔偿。

这也解释了他的刻薄为何不滑向虚无。他嘴上骂“悬空指针”，手上仍逐条圈动词。因为管子再破，拔掉管子也不会自动得到清水；它只会让所有人暴露在旱地里。正因为管网会积垢、会漏、会被人私接旁路，才需要法医拿内窥镜、压力表和扳手，把堵点公开出来，逼系统留下检修口。

### 专栏对读者的承诺

对内行，每一个“水垢”“变径管”“爆管”都必须能回译为真实的条约条文、判例、管辖条件、国内程序或执行豁免；不拿隐喻替代证明。

对普通读者，专栏不要求先背拉丁文。它会把“转换与纳入”“直接效力”“公共政策”“国家豁免”“根本情势变更”逐一翻译成可看见的阀门、管径、滤材与停机程序；随后再把比喻翻译回准确的法律问题。

# EP01 · 条约求导不收敛：北约第五条到底接通了什么

> **本期封账命题**：北约第五条不是“自动宣战”的按钮，也不是一张可以随意糊弄过去的免责声明。它是一项保留行动方式裁量、却仍要求协助的集体防卫义务；它是否有重量，取决于文本之外那套持续供电的能力、协调与政治决断。
> **理论锚点**：S07《血酬》/ S08《铁幕》冷战条约文本解构

## 一、起案：黄冈密卷先看条件，别先背口号

“龟蛇锁大江，江水向东流。各位同仁，我是珞珈。今天在长江大桥底下，咱们拿黄冈密卷的算力，验算一下西方集体安全叙事里最常被背成口号的一行：北约第五条。”

“题干不是‘打一人，自动打全家’。题干是：发生武装攻击时，每一缔约方要协助受攻击方，采取**其认为必要的行动**，包括使用武力，以恢复并维持北大西洋地区安全。注意，这里既有 `will assist`，也有 `as it deems necessary`。做题时只圈后半句，和只圈前半句一样，都是漏条件。”

## 二、画图：第五条不是单线开关

第五条至少有五组串联条件：

1. **事实门槛**：是否发生“武装攻击”；
2. **空间门槛**：攻击是否落在条约第六条界定的范围内；
3. **协助门槛**：受攻击盟国是否请求或同意集体行动；
4. **行动裁量**：各盟国自行判断何种行动为必要，武力是被列入的选项而非机械必选项；
5. **持续供电**：第三条要求各盟国维持、发展抵抗武装攻击的个体与集体能力；没有这一层，五条只是一张漂亮的接线图。

所以第五条的真实结构是：**协助义务确定，行动强度开放；触发判断需要善意，执行效果依赖能力。** 北约自己的说明也承认，各盟国决定如何履行协助义务，但该行动须仍可被视为服务于恢复和维持北大西洋地区安全。

## 三、接水：真正的阻力在文本外

### 1. 国内转换：不是无水，是末端阀门未开

某国已同意受条约拘束，不表示其行政机关可以跳过预算、议会授权、武装力量指挥链、法院审查或地方执行程序。二元论法域尤其显眼：国际主干义务要先经过国内立法与行政管网，才会变成企业、地方机关与个人实际遇到的规则。

珞珈的判词是：**国内法不是国际责任的橡皮擦，却可能是履约水流的变径弯头。** 它使义务在国际层面仍然挂账，却令国内受益者面对漫长、窄口、甚至断流的执行路径。

### 2. 执行堵塞：不是所有“公共政策”都长在同一根管上

投资争端是最容易被讲混的一段。一般商事仲裁的承认与执行，可能面对公共政策审查；但 ICSID 体系不是这一套。依据《ICSID 公约》第 53—55 条，成员国应把 ICSID 裁决作为有约束力的裁决承认，并将其中金钱义务按本国终局判决执行；可具体执行仍由执行地国内法管辖，国家及外国国家财产的执行豁免也被保留。

换句话说：**裁决可能已经进了法院的门，扣押哪一笔国家资产却仍卡在另一扇门。** 这不是“公共政策把 ICSID 裁决一脚踢出去”，而是承认、执行与对具体资产采取强制措施之间存在不同的管段。

### 3. 多缸回流：各国的单边加药会污染共同基线

单边制裁、长臂管辖、资本管制、出口限制与金融恐慌，不是条约正文里一条温柔的“例外”就能消化的输入。它们会改变所有参与者对风险、合规和资产安全的预期，使原本为合作而铺设的管道兼具规避、脱钩与报复用途。

问题不在于“所有加药都违法”或“所有反制都正当”，而在于：一旦共同信任基线被持续腐蚀，缔约方会把更多资源投向自保阀门，主干网的有效流量就会下降。

## 四、听爆裂声：什么是合法检修，什么是砸缸

条约法并没有给国家一把“水质不好就随时拔管”的扳手。

- **暂停、退出或终止**：首先看条约自己的检修口；没有明确条款时，也不能任意撤离。
- **根本情势变更（VCLT 第 62 条）**：是极窄例外，不可预见的变化必须构成原同意的根本基础，并彻底改变尚待履行义务的范围；自己造成的变化不能援引，边界条约也不能据此退出。
- **违约、反制、制裁或武力**：它们不是自动合法的“高压清洗”。每一种措施都要另行经过授权、比例、管辖、责任与适用法的检验。

珞珈不把制度崩坏写成一种爽文式的必然。他把它定义为：**预留排污、复核与修复机制失败后，参与者改用成本更高、合法性更差、外溢更广的方式重新分配压力。**

## 五、结案：别问图纸漂亮不漂亮

“别误会，国际法不是没水，也不是没管子。它最大的问题是：每一口鱼缸都说自己已经接管了；真正开阀的时候，又说阀门得过宪法、过议会、过财政、过地方、过法院，还得看看这缸鱼今天愿不愿意认账。”

“条约在国际层面照样生效，违约账也照样挂着；可对缸里的鱼来说，水就是没来。”

“所以我不问这张水路图画得美不美。我只问四件事：**谁有阀门钥匙，管径到底多大，堵了谁负责通，爆管之后谁赔鱼。**”

“散会。我得回宿舍给我那几个破缸换棉、洗滤材；顺便提醒各位，别把会响的水泵当成正常供水。”
