# 《龟蛇锁江》EP24 · 打劫：用禁全同规则复盘欧亚棋盘上的劫材清算

> **本期封账命题**：围棋里最残酷的规则是禁止全局同形再现（No Immediate Retaking）——你提我一子，我不能马上反提回去，否则这盘棋就在一个局部陷入无限死循环（Infinite Deadlock）。把这条规则映射到欧亚大陆：乌东四州、克里米亚陆桥、黑海深水出海口就是那个"劫眼"；任何一方想要在主战场抢下这个劫，都不能单凭局部的物理存量硬砸，必须去棋盘的另一个角落找"劫材（Ko Threats）"。整场冲突不是堑壕决战，是一场"特大无忧劫与全局劫材清算"。
> **证据标记**：`[史]` 规则/档案支持；`[推]` 制度与符号推演；`[戏]` 节目演绎；`[悬]` 待复核。
> **落花生案**：本期为珞珈（落花生）以围棋打劫规则，把欧亚棋盘上的散点爆破串成一条因果链。

---

## 一、起案：打劫（Ko Fight）——禁全同规则

珞珈手里的红笔在白板上重重一点，顺着棋盘边缘划出一道凄厉的折线：

"这才是围棋博弈学与国际法权在实战中最残忍的咬合——**打劫（Ko Fight）**！世俗媒体天天盯着顿巴斯前线的堑壕米数、海马斯或者无人机的战损比，分析得唾沫横飞，全在看表面皮肉。只要把棋盘拉开，按围棋的'禁全同规则（The Rule of Ko）'去复盘——整场冲突根本不是什么一战式的堑壕决战，它就是一场在全欧亚大陆板块上展开的'特大无忧劫与全局劫材清算'！"

`[史]` 围棋的底层逻辑：禁止全局同形再现——提劫后，对方不能马上反提回去，必须在棋盘别处下一手，逼对方应一手之后，才能提回。这一条规则，把"局部死磕"从数学上判了死刑。

## 二、找进水口：乌东/黑海的"劫争核心"——那个流血不止的劫眼

`[推]` 把这个规则映射到当前的战区：

- **劫争核心（The Ko Point）**：乌东四州（顿涅茨克、卢甘斯克、扎波罗热、赫尔松）、克里米亚的陆桥、黑海舰队的深水出海口——这就是棋盘上的那个"劫眼"；
- **规则禁止"原地反提"**：任何一方想要在主战场抢下这个劫，都不能单凭局部的物理存量硬砸——因为局部已经打成了势均力敌的战壕绞肉机，原地反提就是无限死循环；
- **必须去找"劫材（Ko Threats）"**：在棋盘的另一个角落下刀，威胁对方一个"丢了比丢掉乌东更肉疼"的关键大龙，逼对方不得不回防应劫；只要对方去应了你的劫材，你才能合法、合规地转回头来，在主战场把那个劫给提过来。

> 珞珈按语：战壕里每一米的争夺都不是目的，是提劫的**入场券**。真正决定劫争胜负的手，都下在别处。

## 三、加压注水：满盘寻找"劫材"——为什么必须在其他地方来一下

`[推]` 你说的"在其他地方来一下，避免连续打劫的径手"，直接把这场冲突在全球范围内的散点爆破串成了一条因果链：

```
[ 核心劫眼: 乌东四州 / 克里米亚 / 黑海陆桥 ]
                    │
                    ▼ 陷入死锁，无法原地提劫
┌─────────────────────────────────────────────────────────────┐
│                外围寻找"劫材" (Finding Ko Threats)             │
│                                                             │
│  * 劫材 A: 核电站的临界威胁 (战术安全劫)                        │
│  * 劫材 B: 波罗的海海底光缆与天然气管线的切断事件 (基础设施劫)     │
│  * 劫材 C: 红海方向对苏伊士运河航线的封锁 (航运流体劫)            │
│  * 劫材 D: 萨赫勒走廊的驻军变动 (非洲资源劫)                     │
│  * 劫材 E: 亚太方向弹药流转与试射 (副战场劫)                     │
└─────────────────────────────────────────────────────────────┘
                    │
                    ▼ 逼迫对手做出决断
[ 对方不得不耗费算力应劫 ──► 主战场获得呼吸窗口与谈判筹码 ]
```

### 1. 红海与非洲的"外盘劫材"

`[推]` 俄罗斯在主战场承压，中东红海方向立刻开始用低成本反舰武器打断施米托夫的全球航运流体——欧美必须调动昂贵的航母打击群和防空驱逐舰去护航。这就是在欧亚棋盘的右下角给你造了一个"不应就断大动脉"的死活题，强行摊薄你的拦截弹药和注意力。

`[推]` 同样，萨赫勒走廊的驻军变动（多国法美驻军撤出、俄罗斯背景的军事力量进入）则是在棋盘左上角落子：逼对方在外围消耗政治与后勤资源，为乌东主战场创造应劫空间。

### 2. "边打边谈，打打谈谈"的算力平衡

`[推]` "打"是制造新的劫材，或者在主战场提劫；"谈"是双方坐下来对账——"你看，我手里还有三个劫材，你手里的劫材已经用得差不多了，这盘棋再打下去你全盘大龙都要受损，不如在这个局部形成'双活（Seki）'，或者你让我把这个劫粘上。"

所以，每一次在日内瓦、伊斯坦布尔或者利雅得的秘密穿梭谈判，从来不是因为双方良心发现想搞和平，而是某一阶段的"劫材库（Ko Threat Pool）"打光了，双方都需要一个战术停顿去重新编译新的劫材！

> 珞珈按语：谈判桌不是道德讲台，是**劫材库的结算窗口**。坐下来，不是和解，是对账。

## 四、听爆裂声：终盘视野——大国棋手最害怕的"消劫（Resolving the Ko）"

`[推]` 珞珈推了推眼镜，用红笔在白板上画出两只巨大的夹角：

"为什么整场战争看起来那么拧巴、那么拖沓？因为双方都在算计同一个终极数学边界：**消劫的代价（The Cost of Connecting the Ko）。** 如果要彻底把这个劫粘上（完全占领乌东并获得法理承认，或者彻底驱逐对方恢复原有边界），一方必须拥有压倒性的绝对劫材储备。"

但现在的局面是：

- 一方不可能无限量把全欧的工业产能转化为常规弹药去应劫；
- 另一方也不可能把所有的地缘筹码在这一局全压光——它还得防着中亚后院、外高加索以及远东的大陆架。

于是，双方只能被迫进入这种极其折磨人的"打劫手谈状态"：今天前线放炮，明天后方管道爆裂；今天宣布制裁加码，明天在第三国粮食出口协议上签字；今天在边境无人区突袭一下，后天就在多哈谈换俘与能源隐秘过境。

**这根本不是两支军队在决斗，这是两部庞大的官僚与资本机器，在用整座棋盘上的活人与基础设施当成筹码，一子一子地计算着"退让半目"与"强杀劫争"之间的能量损耗。**

> 珞珈按语：消劫的代价，是数学边界，不是道德边界。**谁先算明白粘劫的账单，谁才会先坐回棋盘前。**

## 五、结案：焦黑的泥土与拔掉的界桩

`[戏]` 珞珈把白板上的所有箭头拉向最终的收口，双手撑在桌沿上：

"看到没有？凡是沉溺在'正义必胜'或者'速胜神话'里的人，都是连死活题都没做及格的门外汉。在大国公法的解剖台上，战争从来不是情绪的宣泄，战争是一套严格遵从对局规则的精密结算过程。"

"乌东是那个流血不止的劫眼，而全世界的能源断口、外汇清算、公海海峡、乃至深海光缆，全都是被各方顺手捡起来向对方脸上招呼的'劫材'。边打边谈，打打谈谈——打，是因为棋盘上还有未被兑现的残余空间；谈，是因为某一方的手筋终于被逼到了气紧的边缘。"

"这盘大棋下到这个份上，早已没有干净的胜利者。最终留在棋盘上的，只有那些被'特事特办'拔掉的界桩，和那片在无数次打劫与互撕中、被生生打成碎末的焦黑泥土。"

"散会。下一次谁再跟你喊'必胜'，你先替他数一遍：**他手里还有几个劫材？**"
