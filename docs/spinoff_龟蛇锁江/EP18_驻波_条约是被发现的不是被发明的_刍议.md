> **落花生案**：本期为珞珈（落花生）以经典电动力学与波动物理学，重审国际法的本体论——条约是驻波（Standing Wave），被发现的，而不是被发明的。

## 二、找进水口：物理学还原——国际公约不是合同，是两列相向而行的波在干涉

`[推]` 去翻翻现代国际法学者的论文，全是"基于规则的国际秩序"、"条约是主权者意志的合意"、"全人类共同价值的发明与构建"。听着多体面、多神圣——但在主权电路与波动方程面前，这全是彻头彻尾的颠倒因果：

```
波源 A (主权实体 A: 自身内核震荡产生的向外法权涟漪) ──►
                                                      ▲
                                                      │ 空间相遇与相位对齐 (Phase Matching)
                                                      ▼
      ◄── 波源 B (主权实体 B: 自身内核震荡产生的向外法权涟漪)
                                                      │
                                                      ▼
                              满足相干条件: 频率匹配、相位差恒定
        ┌────────────────────────────────────────────────────────┐
        │        形成稳定的干涉场与驻波 (Standing Wave)           │
        │  波腹 (Antinodes): 冲突震荡区 ──► 双方高能耗博弈与试探   │
        │  波节 (Nodes):     能量静止点 ──► 振幅为零、不耗能、不坍塌│
        └────────────────────────────────────────────────────────┘
                                                      │
                                                      ▼
        【条约节点 (Treaty Articles)】: 不是被发明的道德条款，
                                       而是被双方法权测绘出的"不动波节"
```

**为什么叫"被发现"，而不是"被发明"？**

两个孤立的主权实体，如果各自内部的自治域（Civitas）没有跑通，它们的涟漪就是充满杂波、频率紊乱的高熵白噪声。两个白噪声在旷野里相撞，除了引发更大规模的能量耗散（Massacre/泥浆肉搏），什么都不会留下。

只有当两个主体各自把微内核的法权打磨到极高纯度、各自向外辐射出具有固定波长和稳定周期的法权涟漪时，干涉（Interference）才有可能发生。

**条约就是"波节（Nodes）"在法理纸面上的投影**：

波在空间传播相遇时，某些点由于相消干涉（Destructive Interference），振幅永远为零。在波腹（Antinode）处：双方利益天天撕扯，摩擦力极大，震荡剧烈；在波节（Node）处：能量流动在物理上静止了——不需要巡洋舰天天对峙，不需要海关官员天天开枪，双方在这个特定点上的势能差自然抹平。

`[推]` 早期的外交家拿着羊皮纸，在漫长几百年的战争、试探与走私之后，终于在地图上画出了一条边界线、在关税账本上敲定了一个税率、在引渡协议上定死了一个罪名。那不是外交官拍脑袋"发明"出来的智慧，那是大自然与博弈力学在这个维度上早已存在的"零能耗驻波节点"，终于被他们像开采矿藏一样给"发现（Discovered）"了。

> 珞珈按语：条约不是立出来的，是测出来的。**外交官是测绘员，不是立法者。**

## 三、加压注水：历史病理学——所有试图"强行发明"的条约，全被高能耗冲烂了

`[史]` 只要你用"驻波是被发现的"这个透镜去看近代史，所有那些暴毙的国际条约，死因一目了然：

### 1. 正面教材：威斯特伐利亚和约（1648年）——反相抵消露出的冰冷波节

三十年战争（1618–1648）把欧洲打成了尸山血海。天主教军团和新教同盟把德意志的人口打掉了多少？传统估算认为德意志人口损失约三分之一；现代学界更常见的估算是总体两到三成，但部分地区——如符腾堡、波美拉尼亚——确实损失超过三分之一。无论取哪个口径，这都是欧洲近代史上最惨烈的人口浩劫之一。

双方在完全耗尽了能量之后，惊骇地发现：谁也消灭不了谁，谁的教权波也吞不掉对方的王权波。于是《威斯特伐利亚和约》诞生了——"教随国定（Cuius regio, eius religio）"。

这不是红衣主教良心发现，这是两股狂暴的能量在泥潭里互相反相抵消，终于露出了那个让全欧洲得以喘息的冰冷波节！

### 2. 反面教材：国联（League of Nations）与巴黎和会的凡尔赛体系

`[史]` 威尔逊那帮空想家，带着"十四点和平原则"（1918年1月8日国会演说）跑到巴黎去开会。他们连各个战败国和战胜国内部脆弱的经济频率都没有校准，甚至连战胜国内部自治域的短路都没有修好，全凭一腔自说自话的道德优越感，在凡尔赛宫"发明"了一套惩罚与国际裁军条约——1919年6月28日签署《凡尔赛条约》，1920年1月国际联盟成立。

结果是什么？根本不存在稳定的相位匹配！没有物理驻波支撑的凡尔赛条约，在希特勒的装甲师和全球大萧条的高频冲击下，连二十年都没撑过去——1919到1939，恰好二十年——就像一张被高压电弧引燃的单薄草纸，瞬间在第二次世界大战的火海中灰飞烟灭。

> 珞珈按语：威斯特伐利亚是打出来的波节，凡尔赛是写出来的幻觉。**前者趴在地图上测量，后者站在讲台上宣示。测出来的能活，宣示出来的会炸。**

## 资料锚点

- 《威斯特伐利亚和约》（Peace of Westphalia）：1648年，三十年战争（1618–1648）终结，"教随国定"原则
- 三十年战争德意志人口损失：传统估算约三分之一；现代学界总体估两到三成，部分地区（符腾堡、波美拉尼亚等）超过三分之一——口径差异见限界声明
- 威尔逊"十四点和平原则"：1918年1月8日美国国会演说
- 《凡尔赛条约》：1919年6月28日签署；国际联盟：1920年1月成立、1946年解散
- 驻波（Standing Wave）概念：两列同频反向波叠加，波节振幅恒为零、波腹振幅最大——波动学基本定律

**限界**：本文"条约=驻波波节"为跨学科推演框架〔推〕，非国际法学界通行理论；三十年战争人口损失取"部分地区超三分之一、总体两到三成"的现代学界口径，传统"三分之一"说法保留为历史叙述中的通行说法并已标注差异；威斯特伐利亚"教随国定"系1555年奥格斯堡和约原则的确认与扩展；凡尔赛体系崩溃的归因（缺相位匹配）系本文解释框架，历史学界另有赔款压力、美国不加入国联等多种归因。〔悬〕
