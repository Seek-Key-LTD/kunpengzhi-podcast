# 《龟蛇锁江》EP06 · 文明接口不是热插拔：计划、限流与可逆交接

> **本期封账命题**：`Plan your trade, trade your plan` 的可贵，不在于承诺“算到完美”，而在于事前公开假设、风险上限、异常处理与退出条件，并在执行时不以情绪越过这些边界。面向自动化与人工社会的深度耦合，最重要的不是造一个全球总控状态机，而是造一组可验证、可限流、可申诉、可回退的接口。  
> **本期工具**：接口契约、速率限制、权限分层、可观测性、熔断、人工复核、可逆迁移。

---

## 一、起案：计划不是预言，执行不是朝令夕改

`[推]` 交易纪律里的那句话，放进制度工程后应当这样翻译：**先把可接受的损失、证据门槛、触发条件和退出路径写清；执行时既不因贪婪临时加码，也不因恐惧临时掀桌。**

珞珈说：“这不是诸葛亮式的神机妙算，更不是在脑中遍历完世界的所有分支。计划的意义，是承认自己看不全，然后把看不全时该怎么办提前写下来。”

战争之所以提醒人们重视预案，是因为生命、基础设施和社会信任常常不可逆；但它也恰恰证明了任何地图都无法替代现实。把这种警告带到条约、供应链和自动化系统里，结论不是追求 `Perfection`，而是追求**故障发生时仍不越过不可逆伤害阈值**。

## 二、碳硅交接：不是文明交棒，而是高风险的社会技术接口

所谓“碳硅交接”不是一种已经完成或必然发生的文明替代，而是一组正在加深的社会技术耦合：模型参与信息分发、授信、招聘、物流、交易、公共服务与安全决策，人仍然生活在这些决策的后果里。

把它称作“全球母板热插拔”有画面，但必须保留三个现实约束：

1. **硅基系统并非零熵**：硬件会失效，数据会偏差，模型会漂移，供应链会中断，攻击者会适应；
2. **碳基社会不是旧系统包袱**：人的尊严、权利、关系与政治授权不是待优化的阻抗，而是系统合法性的来源；
3. **不存在单一总线**：不同法域、行业、组织与群体有不同权限和节奏，任何试图一键接管的架构都会制造单点灾难。

因此真正的难题不是“让机器更快”，而是让机器的速度、权限与影响范围，匹配人类能够理解、质疑、纠错和承受的速度。

## 三、接口契约：每一条自动化总线必须交付什么

珞珈把一张“文明接口验收单”贴在白板上。任何从自动系统流向人的高影响决策，至少需要九项字段：

| 字段 | 要回答的问题 |
| --- | --- |
| 目的 | 为什么要自动化，解决的具体问题是什么 |
| 范围 | 哪些人、事务与时段被覆盖，哪些明确排除 |
| 输入 | 数据从哪里来，哪些偏差、缺口与不确定性已知 |
| 权限 | 系统能建议、预警、限流，还是能直接处分 |
| 阈值 | 什么信号触发升级，何时必须停止自动执行 |
| 速率 | 单位时间内最多影响多少人、多少资产或多少关键资源 |
| 证据 | 决策、版本、操作者和依据能否事后回放 |
| 救济 | 当事人如何获知、解释、申诉、暂停和获得补偿 |
| 退出 | 系统降级、失效、被滥用或政策改变时如何撤回 |

这才是“Plan your trade”的法理版本：不承诺所有输入都正确，而是承诺每一次高风险输出都有边界、有日志、有停机键。

## 四、法律的编译器：不是消灭裁量，而是把裁量类型化

自然语言法律确实会有定义模糊、交叉引用、例外冲突和执行不一致的问题。形式化建模、规则引擎与有限状态机可以帮助发现矛盾、漏项和未定义的状态转换。

但“把所有免责自变量拔掉、换成确定性终局”不是法治升级，而是把正当防卫、紧急避险、能力差异、事实不明与比例判断当作编译错误删除。它会使系统表面更干净，实际更残酷。

正确的“法律编译器”应输出三类不同对象：

1. **可自动执行的硬规则**：清晰、低争议、可逆且损害有限的事项；
2. **须升级审查的软规则**：涉及不确定事实、利益权衡或重大影响的事项；
3. **必须由人承担理由的裁量**：系统可以提供证据和一致性检查，但不能代替公开理由、独立审查与申诉。

裁量不是漏洞；**无记录、无理由、无复核的裁量**才是漏洞。

## 五、光耦隔离：局部病变不能变成全球连锁清算

自动化系统最危险的失败模式，是把一个局部的错误分类、数据污染或激励扭曲，以高速接口扩散成跨域处分。对此需要的不是毫秒级地把所有节点切断，而是分层隔离：

```text
异常信号
  → 降速与限额
  → 局部隔离、保留基本服务
  → 独立复核与影响评估
  → 修复 / 补偿 / 逐步恢复
  → 记录进入下一轮规则修订
```

“最低限度生命维持循环”在这里不是技术酷词，而是明确要求：即使某个接口被暂停，也不能让基本生活、申诉权、关键公共服务和紧急救助随着一个模型分数一起断电。

## 六、竹湖与珞珈：不做总阀门的主人

`[戏]` 竹湖把废硅片放回桌上：“流片之前，最怕没有跑到的角落条件。”

珞珈说：“条约之前也一样。但你们发现角落条件的方式不是把用户删掉；是标出覆盖范围、留冗余、做回归测试、出了问题能回退。”

“那我们怎么让新旧系统接上？”

“不是一夜热插拔。先双轨运行、小规模试点、限额接入、独立审计；证据不足就不扩大权限。人类社会不是你的一块测试板。我们不做总水阀的主人，只做阀门旁边把权限、压力和退路写清的人。”

## 七、结案：图纸要留空白，接口必须留人

“一条 `shall` 写错，确实可能让很多人承担很长的后果；一个模型权限开大，也确实可能把局部错误放大成社会灾难。”

“但结论不是把每个 `may` 都删掉，把每个人都接入同一个中枢。结论是：把 `may` 的操作者、理由、边界、记录和复核写出来；把 `shall` 的能力、成本和救济写出来。”

“计划你的变更，按计划执行；当现实证明计划错了，就按预先留下的程序停机、回退、赔偿、重来。**图纸可以追求严密，接口必须容纳人。**”

“散会。别急着把文明插进新插槽；先确认插头、保险丝和急停键都在谁手里。”
