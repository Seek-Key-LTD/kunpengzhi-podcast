# 《龟蛇锁江》EP09 · 阿米伽狗终审：Alpha 的边界与 Omega 的幻觉

> **本期封账命题**：AlphaGo 代表的是“模型加搜索”的强大近似，不是盲人摸象；OmegaGo 可以作为追求完美预测的文学意象，但不存在已知的量子机制，能够读取所有状态、抵消所有坏分支并吐出唯一的社会最优解。文明的终点不是 Omega 替人类统治，而是让每次高影响决策都可解释、可质疑、可限流、可复位。  
> **证据标记**：`[实]` 已有实验或论文支持；`[物]` 物理与计算边界；`[推]` 制度推演；`[设]` 世界观设定。

---

## 一、先给 AlphaGo 正名：它不是“几块 GPU 的蒙特卡洛瞎撞”

`[实]` AlphaGo 的原始论文描述了一个组合系统：策略网络选择候选走法，价值网络评估局面，再与蒙特卡洛树搜索结合；训练同时使用人类棋局、监督学习与自我对弈。它的力量来自模型、搜索、训练数据、算力和工程实现的耦合，而不是简单地把所有变化一条条试到尽头。[Nature 原始论文](https://www.nature.com/articles/nature16961)

李世石第四局的第 78 手确实成为著名的人类妙手；但它说明的是模型在分布外局面、价值评估与搜索策略上可能出现脆弱点，不等于 AlphaGo 的整套范式被一个“神之一手”物理击穿。Google DeepMind 的资料也明确记录了第 78 手及其比赛背景。[DeepMind 资料](https://deepmind.google/research/alphago/)

“把棋盘扩大到一千乘一千，算法就内存溢出”可以作为复杂性直觉，但不能当作完整复杂度定理。棋盘大小、规则、时间预算、模型归纳偏置和允许的近似方式都必须被定义。

## 二、Omega 的第一处错误：叠加不是免费读取全部答案

`[物]` 量子态可以把多个基态编码在叠加中，但测量并不会把全部分支逐条打印出来。算法必须设计干涉结构，让目标信息以可测方式被放大；量子计算也不提供通用的暴力穷举加速。NIST 对这一点的解释很清楚：叠加不等于可以高效读取所有候选解，量子设备还面临噪声、纠错与测量限制。[NIST：Quantum Computing Explained](https://www.nist.gov/quantum-information-science/quantum-computing-explained)

因此，下列表达只能放在 `OmegaGo` 的科幻设定区：

- “全状态空间同时保存并逐一读取”；
- “所有坏分支自动反相位归零”；
- “测量后必然留下全局唯一最优解”；
- “计算结果等于未来的 Ground Truth”。

它们是很强的神话语法，但不是现有量子计算的工作原理。

## 三、Omega 的第二处错误：算出均衡，不等于取得同意

`[推]` 即使给定一个形式化博弈，也可能存在多个纳什均衡、多个帕累托前沿，或者均衡对信息、时序和收益函数极度敏感。收益函数不是宇宙常数：领土、安全、尊严、代际风险、少数群体权利和生态损失，不能自然地压成一个不带价值选择的标量。

当系统打印“双方各退两海里、关税让渡 3.2%”，它仍然没有回答：

1. 谁定义了双方的损失权重？
2. 谁代表没有坐在桌前的居民、后代与非人类环境？
3. 输入数据被谁验证，错误由谁承担？
4. 不接受输出的一方，是被说服、被制裁，还是被强迫？
5. 结果造成不可逆伤害时，谁有权暂停并赔偿？

最后一问决定它是决策支持系统，还是主权终结机器。

## 四、从 Alpha 到 Omega，真正有意义的跃迁是什么

不是从经典计算跳到全知量子计算，而是从“单次给答案”跳到“持续承担责任”。一套成熟的高影响决策系统，应当保存完整时序：

```text
委托意图 → 数据与模型版本 → 候选方案 → 风险与不确定性
       → 人工审查 → 有限执行 → 反馈与异议 → 复盘、补偿、规则修订
```

这条链比“阿米伽狗在三百年状态空间里看见你死过一万次”更不壮观，却更接近文明实际需要的 Omega：不是提前看完一切，而是在看不全、算不尽、意见不一致时，仍然不把人推入不可逆的黑箱处分。

## 五、暗室不能替代公共理由

EP08 已经说明，承诺协议能防止同时行动中的慢出作弊；它不能替代裁决理由。OmegaGo 即使在计算上很强，也必须把结果拆成可审计对象：使用了哪些数据、采用了什么目标函数、哪些分支被剪枝、误差范围是多少、谁批准执行、何时自动失效。

真正危险的不是系统犯一个可见的错误，而是它以“全局最优”为名拒绝解释，随后把质疑者标记为噪声，把退出者标记为故障，把受害者的损失计入优化成本而不通知本人。

## 六、珞珈的终局审查：不要把 Omega 变成新的神学

`[戏]` 珞珈把红笔停在“绝对真理”四个字上。

“AlphaGo 已经够伟大了。它告诉我们，模型、搜索与算力能把某一类封闭规则游戏推到人类很难达到的高度。但围棋有清楚的棋盘、轮流行动、已知规则和可重来的对局。国家、社会和人的一生不是围棋。”

“OmegaGo 如果存在，它首先得回答的不是‘我算了多少条分支’，而是‘我凭什么替没授权我的人作出不可逆决定’。”

“算得更快，不等于更有权；看得更远，不等于更懂价值；预测失败，不等于可以把失败者从系统里删掉。”

“所以 Alpha 是起点，Omega 不是神座。真正的终局是：任何模型都不能垄断终局，任何执行都留有复核，任何高影响输出都有责任人。”

“散会。别让阿米伽狗替全人类下注；先让它学会在按下按钮之前，把自己的不确定性写在收据上。”

## 七、黑色收束：Ω-Go 还是 Amigo

`[戏]` 珞珈在白板上写下 **Ω-Go**，然后在旁边加了一条斜杠：**Amigo**。

“硅谷喜欢把 Alpha 挂在机器上，仿佛第一个字母就是新手村通关证。那我们就把最后一个字母请出来：Omega。听起来像终局、像全量清算、像一台准备把全宇宙状态空间跑干净的冷面机器。”

“但这台机器真要坐到桌边，最好别学天网。它应该像一个靠在仙人掌旁边的墨西哥老哥，先拍拍两边的肩膀：**Relax, Amigo。**”

“别拔刀了。你在我的模拟里已经把对方打碎七万次，他也把你的金库穿孔八万次；两边合计都是负资产。听哥们儿一句，合同第 42 款的逗号往后挪两格，关税各降三个点，先把这杯特基拉干了，洗洗睡。”

这个笑话的关键不在于 OmegaGo 真能预言三百年，而在于它把“终极技术接管”的威压重新翻译成一场低成本、可回退的调解：计算系统提供方案、风险和证明；真正的停火仍需要当事人同意，条约仍需要理由与程序，执行仍需要责任主体。

所以 `Amigo` 不是给全知机器降智，而是给它加上一根法治地线：**能算出很多坏结局，不等于拥有替所有人签字的权力；能给出更便宜的和平方案，不等于可以跳过授权。**

“当帘幕拉开，屏幕上最好不是‘你必须服从唯一最优解’，而是：这是三种可行方案，这是各自的代价，这是不确定性，这是退出路径。现在，诸位愿不愿意把枪放下，把逗号挪一挪？”

珞珈把红笔盖上。

“这才是 Omega 的人间版本：不是替文明清算归零，而是让文明在最危险的分歧处，还能留下一句——**大家都是一条管网里的鱼，给我这个 Amigo 一个面子，先别把总阀门拧断。**”
