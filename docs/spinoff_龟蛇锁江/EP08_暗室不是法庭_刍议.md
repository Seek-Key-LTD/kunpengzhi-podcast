# 《龟蛇锁江》EP08 · 暗室不是法庭：分歧终端机的设计审查

> **本期封账命题**：一个暗箱可以帮助两方同时落子，不能因此成为替全人类裁判、分配与强制执行的黑箱。密码学承诺解决的是提交时序与篡改问题；争端解决还要面对事实、价值、授权、理由、救济与履行。把这些全部压进“不可挑战的终局盒子”，不会消灭暴力，只会把暴力藏进盒子的权限表。  
> **证据标记**：`[密]` 密码学概念；`[物]` 量子概念边界；`[法]` 争端解决的规范结构；`[推]` 工程推演；`[戏]` 影视意象。

---

## 一、起案：塑料筒不是量子暗室

`[戏]` 《非诚勿扰》里的“分歧终端机”之所以好笑，是它把一件严肃的事做得像手工玩具：两个不信任的人，如何在看不见对方选择的情况下同时落子。

`[密]` 这可以启发我们理解**承诺协议**，但不能直接等同。一个合格的承诺协议至少有两阶段：先提交、后揭示；并要求两种互相拉扯的性质：

- **隐藏性**：提交后，对方不能提前得知你的选择；
- **绑定性**：揭示时，提交者不能把原来的选择换成另一个。

黑筒只能提供一点视觉遮挡。它不能自动证明里面没有偷看、换手、串通、延迟落子或事后改口；更没有时间戳、随机数、验证算法、争议记录和受信执行者。把手伸进去不是 `Hash(Action, Nonce)`，除非整个协议真的提供了可验证的提交与揭示过程。

`[物]` 这也不是量子叠加或退相干。两个人在筒内作出的石头、剪刀、布是经典的、人为选择的动作；帘幕拉开只是信息公开，不会把社会意志“坍缩”为自然界授予的正义答案。

## 二、它真正解决什么：同时行动里的时序作弊

石头剪刀布是一个循环的零和博弈，不是 NAND 环。它的公平性依赖双方同步或以承诺—揭示机制避免“看见你出什么再改手势”。

所以“分歧终端机”最多解决一类很窄的问题：**当行动集合已知、结果规则已同意、参与者对称、输赢代价有限时，怎样避免一方利用时间差作弊。**

这已经很有价值。它可以启发抽签、并发竞价、随机选序、资源配给轮次等制度工具。但它没有回答：

1. 谁被允许进入游戏？
2. 为什么偏偏用这组规则，而不是另一组？
3. 失败者承受的代价是否可接受、是否可补救？
4. 一方声称事实输入造假时，谁能调查？
5. 规则本身不公时，谁能修改或退出？

## 三、从承诺到裁决，中间隔着五道不能消失的门

珞珈在白板上把“终极分歧终端机”拆成六段：

```text
提交 → 揭示 → 验证 → 事实认定 → 给出理由的裁决 → 受约束的执行与救济
```

承诺协议只稳住第一、二段的一部分；技术验证能辅助第三段。后面三段不能被一句“系统已经算出唯一均衡”跳过。

`[法]` 即使国际法院的判决对案件当事方具有约束力，履行仍须依赖国家承诺与现实执行；《联合国宪章》第 94 条规定，不履行时另一方可诉诸安理会，而安理会是否建议或决定采取措施仍是一个政治与制度程序。法律的终局性从来不是一台机器按下按钮就凭空出现。

`[推]` 对领土、资源、税收、战争风险这类争端，输入本身往往就在争：地图、历史、损失、身份、权利、需求、未来风险都不是双方交给黑箱的一串无争议参数。若强行把它们压缩成模型输入，谁制定本体、谁清洗数据、谁设权重，谁就已在裁决。

## 四、黑箱中立的危险：不可干涉不等于无权力

“不可干涉的硅基中枢”听起来中立，实际要问得更凶：谁训练它、托管它、更新它、供电它、定义接口、保管密钥、处理停机、执行输出？

如果系统可以因一方不服从就自动摧毁资产、切断基本资源或永久隔离主体，它不再是争端终端机，而是一台绕开比例原则、正当程序与人权保障的全球强制机器。它会把原本可见的炮火，换成不可见的权限滥用。

真正的安全设计应遵循反向原则：高影响输出越大，越需要多方控制、分权密钥、可审计日志、独立复核、比例限制和人类救济；不能因为输出带着“算法”二字，就取消申诉。

## 五、可以造什么：有限、可审计、可退出的分歧协议

这不意味着技术在争端中无用。一个正当的“分歧终端机”可以服务于双方**已同意**的、边界清晰的程序，例如同时提交报价、随机排序、验证履约证据、在限定额度内触发托管结算。

它的最低工程清单应是：

| 环节 | 最低要求 |
| --- | --- |
| 提交 | 隐藏且绑定，记录时间与版本 |
| 揭示 | 双方或约定条件触发，可验证一致性 |
| 事实 | 保留来源、质疑与独立核验通道 |
| 决策 | 公开适用规则与理由，不能只吐出一个分数 |
| 执行 | 限额、渐进、可暂停，不得自动造成不可逆基本权利损害 |
| 救济 | 允许复核、纠错、补偿与退出，记录用于后续规则修订 |

这台终端机不承诺让输家“认赔出场”。它承诺让各方在可见规则下提交、发现错误、承受有限后果，并保留不把分歧升级为暴力的通道。

## 六、结案：帘幕升起以后，仍然要有人负责

`[戏]` 珞珈合上打火机。

“暗室是好东西。它能防止你偷看我的牌，能让两边同时落子，能少掉一部分因为时序和猜疑而发生的烂架。”

“但暗室不是法庭，哈希不是主权，退相干不是正义。帘幕拉开那一刻，真正困难的事才刚开始：输入对不对？规则谁订的？损失谁担？错了怎么改？执行谁负责？”

“你想减少流血，别造一台能把人静默清算掉的黑盒。造一套让人能先承诺、后揭示、可核验、能申诉、可暂停的协议。**帘幕可以升起，急停键也必须在场。**”

“散会。把塑料筒留给喜剧；把权力的钥匙拆给多个能被追问的人。”
