### 【破题】
审欧亚之大名，必先验唇齿之微力；考万邦之旧牒，莫先于音变之权衡。夫“Cina”、“Jina”与“China”者，东西交通之枢纽，千年指代之宏名也。曩者治名物者，或泥于单字孤证，或执于一国之偏音，不知呼气之间，舌尖微抵下齿，软腭之清浊塞音即易为硬腭之塞擦。今依生理发生学之实测，按历史比较语言学之通则，立借贷双轨，平欧亚总账。

### 【承题】
盖天下之音，发于肺橐，动于咽喉，节于舌齿。
发 `[k]` / `[g]` 之塞音（*Kina / *Gina），舌面隆起于软腭；及逢前高元音 `[i]`，气流顺引向前。
此时**舌尖与舌叶但需微触下前齿槽（Lower Incisors），阻力稍变，清浊塞音瞬间流转为硬腭塞擦音 `[t͡ɕ]`（Cina / 支那）与 `[d͡ʒ]`（Jina / 胜者 / 吉那）**。
此非神鬼莫测之异端，实乃人类口腔力学中能耗最低之“生理经济发音法则”。循此生理通路，欧亚地名之迁徙、梵汉波斯之借贷，截然可通。

### 【起讲】
夫名之流转，必有其物质载体与声学通道。
泰西学者考“China”之源，或争于“秦（*Dzin）”，或辨于“晋（*Cin）”，或推于“日南/夜郎/羌戎”。
然无论始于何方，其跨越帕米尔高原、青藏高原与印度河谷之际，必历经不同语系人群之口耳转译。

1. **塞音原点（Velar Stop Base）**：
   原始软腭塞音态 `*Kina` / `*Gina`。西方古希腊文记为 *Θῖναι* / *Σῖναι*（Sinae/Thinae），拉丁化与日耳曼化保留深层塞音骨架。
2. **腭化滑移（Palatalization Shift）**：
   受前元音 `[i]` 牵引，舌体前推顶下门齿，塞音破裂转为塞擦音，遂成梵语之 **Cīna (चीन)** 与波斯语之 **Čīn (چین)**，汉译为“支那”、“脂那”。
3. **清浊互换与神圣重构（Voicing & Semantic Re-anchoring）**：
   浊化流转为 **Jina (जिन)**。在印度次大陆，此音一方面固化为沙门思潮之“胜者”（Jina，佛陀与大雄之尊号），另一方面与北来、东来之古老部落尊号/地缘名物发生同源共振与借贷混融。

1. **断绝孤立单源论**：
   “China”与“Jina/Cina”的同源演变，不是单一国名（如仅拘泥于“秦”）的线形传递，而是**欧亚大陆在同一生理发音力学约束下，对东方/北方强权名物进行的网络化协同转译**。

   发 `key` 的呼气过程中，舌尖轻触下前齿导致的 `[k] → [t͡ɕ] / [d͡ʒ]`（Kina $\rightarrow$ Cina $\rightarrow$ Jina）转换，构成了跨语系名物转写的底层物理公理。
