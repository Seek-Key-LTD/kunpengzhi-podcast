# 三更道场·文献学与历史会计审计
## 《坤舆万国全图》“东西双红海”对称命名机制、Bermejo 物产词源与制图学合并报表法医审计

### 摘要 (Executive Summary)

本案彻底清除了以“偶发赤潮/海水可见颜色摄影”解释长期世界级海域名命的认知假账，确立了历史地名学中的**“稳定物产锚公理”**与**“制图学合并报表机制”**。

审计证实：
1. 原始欧洲底图上，旧大陆红海（*Mare Rubrum*）与加利福尼亚湾（*Mar Bermejo*）使用不同词根，并不存在“东/西”配对；
2. **“东红海 / 西红海”是 1602 年《坤舆万国全图》李之藻与利玛窦在中文空间里独立完成的跨大洋同类资产科目合并与对仗确权**；
3. *Bermejo* 的底层词源直指晚期拉丁语 *vermiculus*（胭脂虫/朱红染料），与红蕉（*Musa* / *Heliconia*）、红赭矿物共同构成了两岸稳定、可识别、具备航海路标价值的长期物产资产包。

---

### 第一章 认识论纠偏：偶发照片不可充当地名确权凭证

长期稳定的地理命名（Geography Toponyms）属于文明的“资本公积”与长期无形资产科目，具有以下法医学特征：
* **抗波动性**：绝不依赖于随季节、天气、光照、浮游生物爆发而瞬时消失的物理现象（如赤潮、晚霞）；
* **功能可识别性**：必须锚定于海岸线上的**永久性地标（Landmarks）、补给植物（Provisioning Flora）或高价值贸易矿产/染料（High-value Commodities）**；
* **记账主体的主观重述**：成对出现的对称地名，必然存在一个统一实施“合并报表编制”的高级制图学主体。

### 第二章 底图与中文版面的复式分录还原

#### 2.1 欧洲底图的原始分流记账
* **西红海区位**：*Mare Rubrum*（拉丁） / *Red Sea*（英） / *Bahr al-Qulzum*（阿），承袭古希腊罗马与近东贸易航线；
* **加利福尼亚湾区位**：1539年乌乔亚（Francisco de Ulloa）探险队命名为 *Mar Bermejo*（西语朱红之海），1570年奥特柳斯地图承袭该名。两地在西文中无“东/西”成对修辞。

#### 2.2 《坤舆万国全图》的中文科目合并
明末学者李之藻在审读西方全球海图时，调动了中国传统名学“同类相从、东西对举”的治理传统，执行了**二级合并重述**：

【贷：西红海（规范汉字科目）】                              【贷：东红海（规范汉字科目）】
      │                                                             │

### 第三章 稳定物理锚：Bermejo 词源与红蕉/染料资产包

#### 3.1 *Bermejo* 的染料与生物学本义
* *Bermejo* 绝非普通色彩词 *Rojo*（Red），其词源为拉丁语 *vermiculus*（原意为生产朱红染料的虫体，引申为胭脂虫红/朱砂赭红）；
* 加利福尼亚湾与中美洲沿岸是美洲最高价值的**胭脂虫染料、苏木红料、火山红赭土及红苞赫蕉（*Heliconia*）群落**聚集带。

#### 3.2 蕉类植物作为航海生命线与生态路标
无论是旧大陆红海口岸的芭蕉属（*Musa*），还是加利福尼亚湾沿岸的热带赫蕉属（*Heliconia*），在古代航海者眼中共享同一个 **Naming Class**：
1. **淡水路标**：大叶蕉类群落标志着海岸淡水溪流与避风锚地；
2. **形态鲜明**：冲天舟形鲜红苞片提供了极高辨识度的海岸视界（Horizon Identification）；
3. **不可食用违约性**：结出的果实均多硬籽不可充饥，确立了“繁盛大叶红花、贫瘠不可交割”的稳定物候认知。

本案证实了“双红海”是明代中西文明合流时，以中国名物学纲目对全球同类红物产、红染料与红苞植物海岸实施的高阶制图学合并重述。
