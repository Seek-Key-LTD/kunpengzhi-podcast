## 模块一 · 命名氧化还原纪律（词源底座）

### 方法
- 处理地名 / 族名前先做"氧化还原反应"：剥去殖民者 / 外语后缀，还原根词，再查是否与你已铺的同源词族同根。
- 禁止让地图距离替你做"对立"判断。

### 巴克 / 巴库同根案
- 巴克特利亚（Bactria）= 殖民者（希腊）加阴性地名尾 "-ia"（Βακτρία），剥掉得 **巴克（Bak）**。〔史·语言学方法〕
- 巴克 ≈ 巴库（Baku）：同根，不地理对立。根词链：亳（亳州，商都）/ 渤（渤海）/ 博 / 巴尔（巴尔喀什，商人运玉终点湖）/ 巴克 / 巴库 = F-B-P 通转同族，本义为**对商人阶层 / 聚货之地的称呼**。〔设·命名学可玩〕
- **收法**：此前"拜火教起源在巴库还是巴克特里亚"的争执，在命名层消解——不是两地说各管一半，是同一根词"巴克/巴库"在不同时代、不同语言里的音转。这坐实道名记"名不正则言不顺"：源头争端是命名混乱造的，不是地理事实造的。
- **标级〔破·坤图〕**：主流历史语言学不把 Bactria 与 Baku 当同源词（前者 Greek Βακτρία < Old Persian Bāxtri-，后者波斯 bad-kube / 突厥源），故本根词同族链落盘必须标〔设〕，不得擅自升〔史〕。

### 拜火教起源地理校正（顺带收）
- 起源主流 = Bactria-Margiana（今阿富汗—塔吉克，Yaz I 文化 ~1400–1000 BC 取代更早 BMAC）。非巴库。〔史·学界共识〕
- 巴库 Ateshgah = 17 世纪印度帕西人建的天然气火庙，是 later hub，非 birthplace。〔史〕
- "没火山拜个屁的火"逻辑前提错：琐罗亚斯德教"火"是仪式火 / 象征火，不依赖自然火焰。〔破·原刀前提〕
- Dashly = BMAC 遗址，"源头"待核，非定论。〔史·待核〕

## 模块二 · 北高海重构（水文底座）

### 原坤图主张（已否）
- "坤图北高海东西长≥3×宽、土库曼全在湖下" —— 数据不认。〔破·坤图〕

### 真实数据（有出处）
- 古咸海水位（全新世）：青铜时代 42–43m；历次海进最高 52–54m；1960 年 ~53m（接近全新世最高，非低点）。72–73m 高位湖被新研究否掉。〔史·Springer 2023〕
- 里海赫瓦伦期海进（~40–25 ka）：水位 ~+50m asl（比今高约 78m），洪泛北岸低地。〔史·Kurbanov 2023 / Nature Sci Rep 2021〕
- 乌兹博伊（Uzboy）：阿姆河西支分流，~770 km，从萨雷卡梅什盆地穿卡拉库姆西北进里海（克拉斯诺沃茨克湾）。水流靠阿姆河改道（中世纪多次），非湖溢流。〔史·Quaternary Int 2007〕

### 重构结论
- 北高海 = **两湖盆（咸海 / 里海）+ 间歇决口走廊（乌兹博伊—萨雷卡梅什）**，**非稳态大湖**。〔设·地理重构〕
- 该走廊 = 本卷"堰塞 / 溃决脉冲"模型的**河流版实例**：改道窗口 = 间断点，向西脉冲 = 溃决，走廊封闭 = 愈合。自洽。〔史·机制〕/〔设·套用〕
- 高程事实：咸海（~53m asl）高于里海（~-28m asl），方向咸海→里海，与"高的往低的流"直觉一致。〔史〕

### 帕米尔冰量 vs 北高海缺口 对账（模型）
- 左账：帕米尔冰川（冰当量水）≈ 972 / 1296 / 1512 km³（低/中/高，面积 9000–14000 km² × 均厚 120m × 0.9）。季节雪盖不计入（年循环非一次性库）。〔史·量级〕
- 右账：A 仅恢复咸海 1090 km³ / B 里海自身 78200 km³ / C 图兰大泽（估算）32000 km³。〔史·量级〕
- 对账：帕米尔中值冰量 vs 咸海 118.9%，vs 里海 1.7%，vs 图兰 4.0%。〔史·量级〕
- **标级**：帕米尔冰量 ≈ 咸海量级（差一个数量级内），可作旁证；填里海差 2 阶，不认。〔史·量级〕且"左账盖住右账"只能当**潜在/间歇**账，非稳态常账（乌兹博伊是稀有事件，非水管）。〔设·可玩〕

### 雪线高程解谜（你那刀"中间雪没了不对"）
- 葱岭→达拉克（南）、→兴都库什（西北）那圈"饱和度极高"的白，是雪线以上（6000–7000m 峰）积雪/冰川。
- 慕士塔格（7546m）向潘集河做法线，往下穿过雪线（帕米尔约 4000–4500m），进入潘集河/阿姆河走廊（1000–2000m，远低于雪线）= 裸谷，当然没雪。
- "中间没雪"是**高程剖面必然结果**，非异常、非被抽干。菱形内部是雨影高海拔冷荒漠。〔史·地理〕
- "雪山雪线周期"无此词，对应真科学是"雪线随冰期旋回振荡"（冰盛期降 ~1000m）。〔史·科学〕
- Sarez/Usoi 坝（1911 地震滑坡坝）蓄 Lake Sarez ≈17 km³，相对咸海 1090、里海 78200 是九牛一毛，不能当"中间水被存起来"的证据量级。〔史·量级〕

## 模块四 · 铅同位素机制校正（材料底座）

### 三父一女系统（立得住的〔史〕）
- ²³⁸U → ²⁰⁶Pb（半衰期 44.7 亿年）
- ²³⁵U → ²⁰⁷Pb（半衰期 7.04 亿年）
- ²³²Th → ²⁰⁸Pb（半衰期 140 亿年）
- 考古读三个比值（²⁰⁶/²⁰⁴、²⁰⁷/²⁰⁴、²⁰⁸/²⁰⁴）一起画等时线。单条 U-235 链只产 ²⁰⁷Pb 一种，单拎出来既画不出完整指纹，也无法定位矿源。〔史·科学〕

### 两刀校正
1. **"只从 U-235 过来不能完全解释" —— 对，用户直觉正确。** U-235 现占天然铀 0.72%（半衰期短、几十亿年耗散），²⁰⁷Pb 贡献本就比 ²⁰⁶Pb（来自占 99.3% 的 ²³⁸U）小。把占比最小且需亿年积累才显形的链当主锚，方向错。〔史·科学〕
2. **"把石头拿回去再炼一下才能形成特殊铅" —— 工艺错觉，砍。** 铅同位素比值是矿石在地质时间里被 U/Th 衰变"烙"进去的，熔炼过程不改变比值。考古是**读矿石自带源签名**溯源，不是"炼出特殊铅"。〔史·科学〕

### 巴尔喀什裁决（钉死）
- 学界四派，**无一人提巴尔喀什**：
  1. **云南派**：金正耀（1984，USTC，后中国社科院）+ 李晓岑（北京科技大学）—— 源 = 云南金沙 / 滇东北。曾主导学界几十年。
  2. **反驳派**：朱炳泉（广州地化所）+ 常向阳（广州大学）—— 等时线不符（25 亿年 vs 云南年轻铅），且"现今中国境内没有这种铅矿"。
  3. **非洲派**：孙卫东（广州地化所，2016）—— 最激进、最受争议：唯一候选是非洲（他自己在文里问"怎么运过来的"）。
  4. **分型派**：崔剑锋 / 马仁杰（北大，2024）—— 当下最前沿：不再争单一来源，把 HRL 分 (A)(B) 型，按时空演变分别溯源，部分指向川滇。
- **巴尔喀什 = 〔设·待核〕，唯一能钉死或砍掉的方法一条**：巴尔喀什成矿带矿石铅同位素 vs 商周青铜器——对上，你就是学界第一个；对不上，砍。一测便知。〔设·待核〕
