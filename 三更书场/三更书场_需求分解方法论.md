# 三更书场 · 需求分解方法论（第一期打样案例）

> 用途：其他 Agent 照此复制"第一期"及后续任何一期。本文件是"需求分解案例"，
> 不是节目本身。节目本身（壳）不存在，本文件是制作说明书（里）。

## 零、缘起锚（不可动，防作伪铁律）
- 栏目：三更书场（FM91.4 深夜档）
- 整档节目不存在＝荒诞主义壳（助手不许从壳外拽现实监管规矩卡壳里内容）
- 缘起：川大副教授 + 台里老编辑，深夜摆龙门阵
- 底色：茶馆 high touch，非拜占庭 forum
- 青衣规则：1 位嘉宾 + 飞书若干 + 茶代酒 + 花名固定

## 一、需求识别（穿透到雾前边界）
- 表层需求：做一期深夜电台，聊点有含量的
- 雾前真实需求：用荒诞壳装一套"名=产权锚、账本可核对"的硬知识，
  给听众一把判别器（不被糊弄），而不是被情绪消费（反思 theater 反例）
- 边界红线：壳是虚构（不存在），里层映射真实资源；
  不抢名人、不锚帝王单倍群、神话不当史、不打翻黄河

## 二、组件分解（做一期必过 7 块）
1. 主题定位：词牌名实合一（词牌名=当期内容同义）
2. 货盘点：先有货（从对话/检索抽硬事实），无货不打版
3. 壳设计：两层结构（壳=龙门阵闲聊 / 里=硬料过堂）+ 缘起锚
4. 青衣配置：嘉宾 + 飞书 + 茶代酒 + 花名固定
5. 定场：开场定场诗或词牌引子
6. 生产管线：普通话定稿 → 川普口音本地化（双版本）
7. 收口：落双约记 / 天权记实点（回到"名=账本"这根脊）

## 三、纪律红线（违反即废）
- 荒诞主义壳：节目不存在（不准当真栏目写招商/审稿流程）
- 青衣：1 嘉宾 + 花名固定（不破格、不堆嘉宾）
- 词牌名实合一（不挂羊头卖狗肉）
- 先有货再打版（空打版=无货）
- 紧箍咒：正心诚意 / 不打翻黄河 / 不抢名人 / 不锚帝王单倍群 / 神话不当史
- 需求识别穿透到雾前（不停在"聊点有含量的"表面）

## 四、第一期具象映射（样见 第一期_名不正则账不平_普通话定稿.md）
- 主题词牌：《定风波》＝把乱象定成确权账本（名实合一）
- 主线：名不正则账不平（今天整条脊）
- 货（4 块硬料，已盘点）：
  ① 莫卧儿扎吉尔＝约而不确→固收
  ② 家族名/婿养子＝链长价高 vs 冉阿让无 name
  ③ 中国 MBO + 离岸信托＝转让账抽空 / off-ledger 截留
  ④ 米莱 LIBRA＝喊确权自己 rug、讲茶大堂在华盛顿、不敢动潘帕斯大象
- 过堂动作：每块货过完落一句"这格账平没平"
- 收口：会计进千家万户＝把私渠晒成明渠＝拆神学院撬棍

## 五、给其他 Agent 的指引（照此复制第一期）
1. 先锚缘起（川大副教授 + 老编辑），不许换人设、不许加嘉宾
2. 先盘货（从对话/检索抽硬事实，标〔史〕〔推·框架〕〔补精度〕〔破〕）
3. 定词牌，词牌名必须和当期内容同义（名实合一）
4. 写两层：壳（龙门阵闲聊，茶代酒）= 里（硬料过堂，每块落"账平没平"）
5. 收口回"会计 / 确权"这根脊，不飘
6. 出普通话定稿，再出川普本地化版（双版本管线）
7. 全程不碰红线（见三）
8. 第二期、第三期同理复制，本案例只负责教会第一期
