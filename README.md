## 🧬 三、结构性题眼：蛇夫座 = 闰

- **为什么黄道十二宫会与英雄之旅严丝合缝？** 两者本是同一张表：黄道是太阳的年账（播种/收割/冬至结算的记账网格），英雄之旅是把"谷物死而复生的年"投影到一个人身上——召唤=欠债，考验=被清算，深渊=库存归零的至暗时刻，宝藏=盈余，归来=账平。货币周期、太阳周期、英雄叙事，是同一个周期函数。
- **蛇夫座不在网格里，它是天球上的真东西**——第十三格 = 太阴历的**置闰**：人为网格与真实天空之间的修正分录，让账实相符的那一笔。
- 英雄之旅把"宝藏"放在深渊之后、回程之前；S08.5《天权》在同一格放的是**宇宙学**（真实星空 / 巴纳德星 / 9000 年尺度）——英雄必须先拿到"网格之外的真的东西"，才有资格回人间打星球大战。**宝藏就是闰，闰就是宝藏。**
- **S08.5 题眼枢轴**：巴比伦人发明人类第一套系统置闰法——"巴比伦版本冻结"争的是**闰的发布权**：谁能置闰，谁就掌握让全天下的账实相符的立法权。
