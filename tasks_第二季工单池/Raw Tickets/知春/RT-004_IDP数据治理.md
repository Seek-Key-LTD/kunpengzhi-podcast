# RT-004 · IDP 流水线全景与数据治理规范

- **证据复核**：渔阳（资产、版本与责任账）、珞珈（可追溯责任边界）
- **节目收口**：青衣
- **原始工单**：[TK-004](../../idp-pipeline-overview.md)

## 最小交付

1. 定义选题、证据、人物资产、节目稿四类对象的唯一 ID 与状态迁移。
2. 给出“主笔—复核—收口”字段、变更记录和退回规则。
3. 以本批 Raw Ticket 为样例输出一张最小可运行的路由表。
4. 建立 PR 的“四时钟”字段：历史事件时间、正典序列、账本记录时间、受限推理窗口；禁止以提交时间覆盖历史／正典时间。
5. 以 PostgreSQL 18 为目标环境，验证 `vchord`／`vector` 的语义召回与 Apache AGE 的 openCypher 图遍历如何各司其职；版本、安装来源与兼容性须由迁移记录证明，不得以设计文稿代替部署证据。
6. 把“相似不等于同源、连边不等于因果、形式合规不等于命题为真”固化为校验边界：数据库只自动检查实体、来源、权限、父 revision 与时间约束，证据档位与真伪仍由学科席位复核。
7. 实现只追加的正典修订：异议以 `CONTRADICTS`／`SUPERSEDES` 新版本进入，不得原地抹改已发生主线；以 `KYA-06` 时间线继承、`KYA-07` 语义误召回作为验收用例。
