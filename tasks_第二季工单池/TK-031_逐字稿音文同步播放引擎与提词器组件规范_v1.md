## 一、 业务背景与资产战略定位

本功能为 **全平台沉浸式听读一体（Synced Transcript & Teleprompter）** 的核心底层资产。

后续所有播客单集（包括《三更道场》、《鲲鹏志》、《廊桥疑梦》等）的**逐字稿（Transcript）**与**唱词/诗赋（Lyrics）**，均将通过此引擎实现**“随音频播放节律、一行一行向上跃迁蹦出”**的交互方式。

## 三、 Phase 1 详细实现规范（DoD）

### 3.1 数据与协议解析层 (`lib/transcript-parser.ts`)
- 编写无第三方依赖的轻量解析器，解析标准 `.lrc` 及 WebVTT：
  - 时间戳正则：`/\[(\d{2}):(\d{2})\.(\d{2,3})\](.*)/`
  - 统一转换为结构化数组：
    ```ts
    export interface TranscriptLine {
      id: string
      timeMs: number
      endTimeMs?: number
      text: string
    }
    ```
- 按需加载（Lazy Fetching）：仅在用户展开歌词/逐字稿视图时，从 `episode.audio.lrcUrl` 或约定路径拉取并保存在组件 state / 内存缓存中。

### 3.2 播放器交互与状态 (`stores/player-store.ts` & `components/player/`)
- 在 `player-store` 增加全局抽屉/全屏视图状态：`isTranscriptOpen: boolean`，以及 `toggleTranscript()`；
- 在播放器控制栏 (`components/player/layout.tsx`) 右侧操作区添加【逐字稿/歌词】快捷按钮（可使用 `RiChatVoiceLine` 或 `RiFileTextLine` 图标）；
- 点击按钮在移动端唤起**全屏毛玻璃遮罩**，在桌面端唤起**右侧滑出抽屉或主内容浮层**。

### 3.3 逐行渲染与时钟驱动 (`components/player/synced-transcript.tsx`)
- **高精度时钟**：通过 Vidstack 提供的 `useMediaState('currentTime')` 监听播放时间（秒）；
- **快速定位当前行**：使用二分查找定位匹配行索引 `activeLineIndex`；
- **视觉层级排版**：
  - **当前高亮行**：纯白高亮（`text-foreground`）、字号放大 1.05 倍（`scale-105 font-medium`）、不透明度 100%、平滑 CSS 过渡（`transition: all 0.3s cubic-bezier(0.2, 0, 0, 1)`）；
  - **非高亮行**：弱化至 30%~40% 不透明度（`opacity-35`），并带轻微模糊与悬浮变亮效果；
- **视口居中与防打扰**：
  - 自动滚动到当前行：`activeElement.scrollIntoView({ behavior: 'smooth', block: 'center' })` 或 CSS `translateY` 计算；
  - 滚动防打扰（User Scroll Lock）：监听用户 `wheel / touchmove` 事件，一旦用户手动翻看其他段落，暂停自动居中跟随 3 秒，3 秒无操作后自动平滑复位。
- **点击跳播（Click-to-Seek）**：
  - 每行文本绑定点击事件，调用 `player.currentTime = line.timeMs / 1000`，实现精准点句跳播。

  4. 触摸滑动浏览不发生剧烈跳动，点击任意一句能立刻跳转播放。

## 五、 Phase 2 演进预留（音轨强对齐与纯色 Transition）

- 后续生成 Whisper CTC 词级强对齐时间戳（Word-level timestamp），向行对象中注入 `words: { word: string, startMs: number, endMs: number }[]`；
- 增加极简现代纯色背景渲染器，随着不同章节（或角色）的切换，通过 CSS `transition: background-color 1.2s ease` 触发色彩平滑呼吸演变。
