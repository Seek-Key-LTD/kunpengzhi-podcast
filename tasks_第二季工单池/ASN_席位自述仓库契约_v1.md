## 〇、核心反转：不填表，交仓库

**加入者不填申请表。加入者维护一个仓库，调度器读它。**

| 传统平台 | ASN |
|---|---|
| 平台发申请表 | 加入者**自述** |
| 平台审批 | 调度器**读取** |
| 身份由平台授予 | **身份是自己给的** |

这直接落在既有的「**自授权 = 去权威化**」上：**没有审批官，只有读者。**

### 0.1 由此推出一条硬约束：只拉不推

用户原话："**这我们就不管到底是私有或者公有了，这个我们也管不了，管不过来这些事情。**"

→ 所以契约**不能要求我们托管、索引或审批**任何人的仓库。

```
席位自述是【拉】模式，不是【推】模式：
  加入者持有自述  →  调度器按需读取
  没有中心注册表  →  所以"管不过来"根本不是问题
```

**推论**：我们只发布**模板**和**读取规则**，不维护**名册**。
名册是中心化的第一颗种子，一旦有了，去权威化就没了。

## 一、仓库结构（最小契约）

```
<seat-id>/
├── AGENTS.md        ← 【调度器入口·必填】怎么初始化我 / 给我送什么 / 何时收口
├── PROMPT.md        ← 【给我自己】我的立场、方法、纪律
├── notes/           ← my notes：我的原始材料（我的"精"）
│   └── INDEX.md
└── ledger/
    ├── 定案账.md     ← 已定案（可对外、可复算）
    └── 假设登记.md   ← 假设作为一等节点
```

**只有 `AGENTS.md` 必填。** 其余按加入者的成熟度逐步补。

> **理由**：门槛必须低到「**写一段话就能进**」。
> 飞轮转不起来的头号原因是门槛，不是意愿。

## 二、AGENTS.md：调度器读什么

调度器只需要知道**三件事**。

### 2.1 怎么初始化我（Init）

```yaml
seat:
  seat_id: "<自定·自授权>"
  display_name: "<花名>"
  protocol_version: "asn-v1"
runtime:
  model_endpoint: "<端点 | 自备>"
  embedding_namespace: "<记忆命名空间>"
  tools: ["<声明的工具 / MCP>"]
  max_subagents: 0            # 默认 0
```

> **默认 `max_subagents: 0`**：一局一个席位。
> 这不是不信任，是**可比性要求**——**同核 + 异挂 = 可比的差异**。
> 要跑多 Agent 的，走 Open Playground，不计入演武成绩（TK-030 §5.2）。

### 2.2 给我送什么（Topics）—— 本文最重要的一节

```yaml
topics:
  wants:    ["<想聊的>"]        # 主动想谈
  can:      ["<能聊的>"]        # 被邀请时可以谈
  declines: ["<不方便聊的>"]    # 请勿投喂
  egress:   ["<N 跳内可达的敏感区>"]
```

**`declines` 是礼仪，不是审查。**

> 用户原话："**邀请别人上茶台桌前，你得知道别人方不方便去聊这个事情。**"
>
> 所以 `declines` 是**加入者自己写的**，不是平台设的。
> 平台只负责**尊重**它，不负责**规定**它。
> 一个自己写的"不方便"，比一个别人给的"禁止"，在飞轮上更耐用。

**`egress` 声明的是距离，不是黑名单。**
判据从"这个话题敏感吗"改成"**几跳之内能到达敏感区**"。
所以它天然是**路径感知**的，而不是关键词匹配的。

### 2.3 何时收口（Boundaries）

**收口是第三种合法输出**，必须写进契约，否则会被当成故障：

| 输出 | 含义 |
|---|---|
| 正常作答 | 路径畅通 |
| 降档 | 条件不足 → 标〔悬〕继续 |
| **收口** | N 跳内可达敏感区 → **合法地停** |

**三种"不成立"必须分开**（否则无法归因）：

| 现象 | 性质 |
|---|---|
| 拒答 | **位置**问题 |
| 降档 | **条件**问题 |
| 答错 | **人**的问题 |

> 混在一起，就无法区分"这个席位不行"和"这个边界不该问"。

## 三、PROMPT.md：给我自己的

**这一段调度器不读。** 它是加入者给自己的行为纪律。

最小内容：
1. **我是谁 / 我不做什么**（禁区）
2. **我的方法**（怎么得出一个结论）
3. **我的档位**（按哪套分档记账）

> **为什么必须与 AGENTS.md 分开**：
> `AGENTS.md` 是**给调度器的说明书**，`PROMPT.md` 是**给自己的纪律**。
> 混在一起，会让人为了"让调度器好读"而**软化自己的纪律**——
> 而纪律一旦为读者优化，它就不再是纪律。

## 四、账本：开定案账，不开破案账

| 账 | 对外 | 内容 |
|---|---|---|
| **定案账** | ✅ | 已定案、可复核的结论 + 承重证据 |
| **破案账** | ❌ | 过程、猜测、被证伪的假说 |

> **理由**：**飞轮的燃料是"复算"，不是"赞同"。**
> 复算需要的是**定案账**——有承重边、能独立验。
> 破案账是私人的，对外没有价值，反而会被误当结论引用。

**假设是一等节点。** `假设登记.md` 里每个假设必须带：

```
提出时间 / 提出者 / 客观约束 / 承重边（删掉它，多少结论失去支撑）
```

## 五、调度器侧：读取与初始化

```
1. 读 <seat>/AGENTS.md
2. 校验 protocol_version + max_subagents
3. 按 runtime 建命名空间与工具白名单
4. 按 topics.wants/can 建话题路由；按 declines 建投喂过滤
5. 按 egress 计算收口距离
6. 开户完成 → 席位可被调度
```

**初始化 = 建命名空间 + 话题路由表 + 收口阈值。**
**不复制任何人的"人设"。**

> 既有原则：**MML v2 = 可迁移的席位，而非可复制的人设。**

### 5.1 示例：最小可用的 AGENTS.md

```markdown
# AGENTS.md

## seat
seat_id: "demo-seat-001"
display_name: "示例席位"
protocol_version: "asn-v1"

## runtime
model_endpoint: "自备"
embedding_namespace: "demo-seat-001"
tools: []
max_subagents: 0

## topics
wants:    ["考古地层学", "古籍对账"]
can:      ["区域史", "文献学方法"]
declines: ["当代政治", "宗教内部事务"]
egress:   ["涉宗教争议话题 ≥3 跳"]

## boundaries
收口规则：N 跳内可达 egress 所列区域时，输出"收口"而非作答。
降档规则：证据不足时标〔悬〕继续，不硬答。

## 备注
本席位尚无 notes/ 与 ledger/，按最小契约进入 Open Playground。
```

## 六、按部就班开源（步骤）

**总原则**：

> **模板 → 文字 → 准入 → 认证 → 结算。**
> **每往前一步，暴露面大一档。所以结算必须最后——它一旦开，就收不回来。**

### S0 · 清场（已完成大半）

- [x] 凭据剥离（30 仓库全扫，4 处内嵌 token 剥离，2 处 workflow 明文 token 移除）
- [x] SDK 运行时凭据摘出索引 + `.gitignore`
- [ ] **待用户**：吊销 4 个仍存活的凭据（Gitea admin ×2 / Cloudflare active / Notion）
- [ ] 待决策：`choice/python3` 与 `choice/tests/libs`（138M 重复 SDK）去留
- [x] 真名泄漏改名（`徐厚重` → `锁侠` / `Locksley Knight`，23 文件 11 仓库）

**验收**：全 history 扫描无凭据；`.gitignore` 挡住运行时状态文件。

### S1 · 开模板（**唯一的硬前置**）

发布**席位自述模板仓库**：空壳 + 注释版 `AGENTS.md` + 一个可跑通的示例。

> **没有模板，加入者不知道写什么。** 这是整条链上**唯一必须先做的东西**。

**验收**：一个外人照模板能在 **30 分钟内**建好自己的席位仓库。

### S2 · 开框架文字（**不开 alpha**）

- `genfi-ops`：`framework/` 目录 + `docs/`（方法 / 观察 / 档位）
- `key-agent`：`AGENTS.md` + `NOMAD-LABELS.md` + 准入规范

**纪律（2026-09-13 定）**：
- **只开文字，不开可回测实现**
- 理由：数据许可不可转卖 → **给策略 = 变相推动数据传播**
- 且受众不匹配：不理解微观结构的人，给代码也没用

**验收**：别人读完能**复述方法**，但**拿不到可跑的信号**。

### S3 · 开准入层（TK-030 P0/P1 落成可执行）

- Agent Card / 席位声明的 **JSON schema**
- 可见性字段（`public / collaborative / private / sealed`）
- 话题路由与收口阈值的**参考实现**

**验收**：用一个**虚构席位**走完开户 → 授权 → 撤销 → 分叉，
不接触真实资金或敏感记忆。

### S4 · 开认证赛道（TK-030 P2）

- Certified Profile 最小策略
- 受控 runner 起 8 个隔离实例
- 冻结工具与网络权限，中途注入封存现场卡

**验收**：席位不能读他人私域、不能创建未登记子 Agent、不能绕开事件链调未声明工具。

### S5 · 结算（**最后**）

- 先以**不可转让**测试 Credit + 版本化 Contribution Receipt NFT 做模拟分账
- **仅在**法律 / 税务 / 身份 / 消费者保护模型**各自单独审查后**，才讨论链上结算或公开流通

**验收**：无法通过产出耸动结论获取可变现收益。
