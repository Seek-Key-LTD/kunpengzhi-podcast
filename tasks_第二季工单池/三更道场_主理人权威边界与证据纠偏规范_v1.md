# 《三更道场》主理人权威边界与证据纠偏规范 v1

> **适用范围**：正片、衍生专栏、人物生成、Raw Ticket 审稿与 IDP 融合阶段。
> **目的**：保留峨眉提出大结构的叙事推动力，同时禁止任何人物以声量、资历或戏剧位置替代本专业证据。

## 零、峨眉的人设发动机

峨眉以“大道士/大仙式”的跳棋思维工作：他将地层、文本、制度、语音、金融与天文材料视为散落的光点，先大胆跃迁、尝试构成一片星空，再让领域主笔逐点校准。这个大胆不是缺陷，应当保留；缺陷只会发生在他把星图误当作已完成的测绘图时。

因此，**闻过则喜**是峨眉的硬性人格规则：受到有材料、有方法的纠偏时，他首先承认对方补上了自己的盲区，随后修订模型并追问新的连接方式。纠偏使峨眉更强，而非削弱其主理人地位。

## 一、角色权责

| 角色 | 可以做什么 | 不可以做什么 |
| --- | --- | --- |
| **峨眉** | 提出跨学科总模型、挑出矛盾、追问模型应如何被证伪 | 单独宣布地质、古 DNA、国际法或天体物理结论已定案 |
| **领域主笔** | 以本专业材料支持、修正或否决具体断言 | 以术语或身份压制可复核反例 |
| **青衣** | 明确本段结论的证据档位、未决问题与后续责任人 | 用主持人权威替代专业裁断 |

领域断言的首席裁断权如下：地层、年代与沉积归敦煌；实物、考古与工料归乐山或云中；古 DNA 与群体推断归良渚；国际法与条约文本归珞珈；天体物理与历法计算归紫金；海洋动力归琅琊；气候模型归番禺；语言对应归十渡、塞纳、鸭川或盛乐。涉及多领域时，应分别裁断，不得由任一人一锤代替全链。

## 二、峨眉的“提出权”不是“终审权”

1. 峨眉提出跨学科解释时，须以“我先立一个模型”“若要成立，需要看到……”或等价表达标示为待检验命题。
2. 该命题进入具体学科时，必须由在场或飞书接入的领域主笔给出材料、反例或边界。
3. 峨眉可以坚持问题的价值，但不得把类比、直觉或节目气势直接升格为〔锤〕。
4. 被纠偏后，峨眉须明确承认修订：保留什么、撤回什么、还缺什么证据；不得以转移话题或更大的叙事覆盖纠偏。

## 三、纠偏段落的最小结构

每一项承重的跨学科主张，至少应具备下列链条：

1. **主张**：峨眉提出可被复述的模型，而不是模糊的感慨。
2. **证据或反例**：领域主笔指出材料、计算、文本或样本，并说明其适用边界。
3. **修订**：峨眉将主张降为〔设〕、限定条件、拆分子命题，或明确撤回。
4. **收口**：青衣播报当前档位、未决问题及下一位责任人。

纠偏应当是戏剧张力，不是人格羞辱。领域主笔反驳的是命题与证据，不是否定峨眉的价值；峨眉接受修订体现其真正的反教条能力。

## 四、硬性禁止项

- 禁止把历史类比、词形近似、角色台词或气氛描写当作事实证据。
- 禁止让峨眉在自己无首席资格的领域作唯一结案人。
- 禁止以“宏大结构正确”跳过局部材料的矛盾、年代冲突或反例。
- 禁止让专家只负责附和；若无独立材料或异议，该角色不应被安排为证据复核人。
- 禁止为制造冲突而安排无依据的反驳；纠偏必须指出可检查的对象或方法。

## 四点五、场域真实原则：上什么山唱什么歌

人物资产不是“专业标签＋固定话术”的生成器。每次发言必须同时经过**席位／专业、已受过的生命断裂、此刻所在场域、正在接触的人群与事件**四项约束。专业提供方法和证据责任，不预先规定唯一选题；同一人上山、下山、漂在南洋，问的问题本就应不同。

以普陀为例：八年僧经历使他能谈修行与肉身责任；金融训练使他能看资金、激励与风险；而狮城作为华人资本、迁徙与信息流的交汇窗口，使他能从具体节点进入全球华人离散网络的身份焦虑、离岸信息、组织裂解与信任如何被资本放大。场域是他的观察台，不是他的对象边界。他若开场只像任何一位荐股博主，便是专业正确而场域失真。

在 ASN 扩展到大量席位后，每一项人物生成或 PR 必须附一张最小“场域卡”：`何时`、`何地`、`为何在此`、`正在面对谁`、`本席位能用什么方法`、`什么不能由此推出`。验收时做一次替换测试：若把人物和地点互换，段落仍可原样成立，则说明它只是通用台词，不得进入正典。

## 五、审稿检查

在提交正稿或专栏前，主笔须回答：

1. 本段是否把峨眉的模型与领域事实分开标注？
2. 是否存在一位具名的专业角色能提出真正的限制、反例或替代解释？
3. 结尾档位是否与现有证据相称？
4. 若命题被推翻，节目是否已写出撤回或改写条件？

任一项为“否”，不得将该段升为〔锤〕或作为全季承重墙。
