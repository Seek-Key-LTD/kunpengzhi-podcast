### 摘要 (Executive Summary)

本案对《坤舆万国全图》（1602年）中旧大陆“西红海”（Red Sea / *Mare Rubrum*）与新大陆加利福尼亚湾“东红海”（*Mar Bermejo*）的双重地名命名机制进行历史会计与植物名物法医审计。

研究表明：
1. 文学物候中的“绿肥红瘦”在植物名物学上精准对应**红蕉类植物**（大叶绿茂、红苞纤出、终局果实贫瘠不具食用能量交割）；
2. 古代地理命名遵循 **Naming Class（形态-功能-贸易资产包）** 而非林奈现代分类学；
3. 跨大洋的“双红海”在地名生成史上，深度交织了旧大陆芭蕉属（*Musa* / 红蕉 / 印度洋红海香蕉贸易链）与新大陆新热带界赫蕉属（*Heliconia* / 鲜红舟形苞片）的跨大洋形态混同与符号合并记账。

### 第一章 物候原点：“绿肥红瘦”与红蕉的生长会计账

#### 1.1 名物纠偏：从海棠到红蕉
宋代士大夫对“红蕉”的典型定义（如宋祁《红蕉花赞》：“蕉无中干，花产叶间。绿叶外敷，绛质凝殷”）揭示了其独特的物候结算结构：
* **绿肥（Asset Expansion）**：巨型假茎与宽厚叶片展现出高膨胀的生物量表象；
* **红瘦（Liability Clearance）**：自繁茂绿叶中抽出的鲜红苞片/花序虽极艳丽，但最终结出的果实细小、多黑硬石质种子，缺乏可交割的食用淀粉/糖分。

#### 1.2 压缩的制度寓言
“绿肥红瘦”不仅是空间色彩对偶，更是一笔**“生物量繁荣表象与终局热量违约”**的精准物候分录，构成了古代文人对“华而不实、承诺未兑”资产的经典自然模型。

### 第三章 Naming Class 跨大洋穿透：芭蕉属 vs 赫蕉属

#### 3.1 跨大洋形态收敛与分类混同
古代探险家、商人和制图家在没有林奈显微解剖学工具的条件下，依据 **Naming Class** 实施分类：

| 维度 | 旧大陆红蕉类 (*Musa coccinea* / 变种) | 新大陆赫蕉类 (*Heliconia spp.*) | 古代 Naming Class 归集 |
| :--- | :--- | :--- | :--- |
| **分布区** | 华南、中南半岛、印度洋-红海贸易带 | 中美洲、加利福尼亚湾南缘、亚马逊流域 | 均被视为“热带红花大叶蕉类” |
| **视觉特征** | 巨大阔叶，叶间抽出直立鲜红苞片 | 巨大阔叶，顶生/下垂朱红舟形大苞片 | **外形几何几乎完全同构** |
| **果实/利用** | 浆果多籽不可食，主要赏红苞 | 蒴果坚硬不可食，作为观赏及包裹材料 | **皆具“丰产假象、零食用交付”** |
| **地名印记** | 红海口岸及东非沿海重要驯化物产 | *Mar Bermejo* 沿岸标志性热带动植物景观 | 汇入“红海/红蕉”全球符号网络 |

#### 3.2 汉语翻译者的“名物升维”
李之藻与利玛窦在将西语海图汉化时，面对西语的 *Mare Rubrum*（红海）与 *Mar Bermejo*（朱红之海），并未机械音译，而是调动了中国古典名物学中成熟的“东西对仗”与“红蕉名物”，在《坤舆万国全图》上确立了**“东红海与西红海”**的双子法统。

本案澄清了“相交（ASR误读）”与“红蕉（物候实指）”的本质区别，通过将“绿肥红瘦”的物候会计模型推广至《坤舆万国全图》东西双红海的制图法医审计，证实了前现代全球化时期跨大洋植物认知遵循 Naming Class 资产包归集的历史公理。
