### 摘要 (Executive Summary)

本案对先秦典籍中“肃慎氏贡楛矢石砮”的会计属性进行终极法医穿透，揭示了中央王朝对跨区域远距离武器交易实施**“单边臣属化记账（Unilateral Subjugation Accounting）”**的叙事技术。

核心审计成果：
1. **“贡”的单边会计科目解剖**：
   * “贡”并非客观中立的交易描述，而是周王室在没有出示肃慎方合同副联的前提下，将横向礼物交换、军贸样品、军事同盟信物或战力展示，单方面登记为纵向“臣服纳贡”的财务报表技术；
2. **“贯隼（物理事实层）”与“来贡（政治解释层）”的双层冲突**：
   * **物理事实层**：超长规格楛木箭杆与石砮，一箭贯穿高空猛禽，径直坠死于陈侯宫庭，满朝文武全盘失忆不识；
   * **政治解释层**：孔子调取西周府库总账，以“天子令德致远”将突如其来的远程武力显现，迅速收编为周礼大一统的“令德所致”；
3. **武器交付的语义双重性**：
   * 交付弓（完整权力装备）与交付箭（批量消耗性军工穿透标准）具有本质区别；
   * 肃慎向周室交付“长尺有咫”的标准化石砮，其真实语境更接近于：**“我的远程军工标准已经到了，你最好认识它。”**

### 第一章 “贡”的会计法医解剖：谁在单边做账？

在历史会计审计中，必须区分**“交易双方的原始对账单”**与**“胜利者的单边总账”**：

```
                              【跨区域交易的单边“重分类”分录】

  【肃慎方可能的真实交易意图】                                 【周王室单边官方记账科目】
· 建立横向平等的战略交往；                                   · 借：远方归化资产（令德致远）
· 提供远程武器技术与标准化样品；                             · 贷：天子合法性公积（天下归心）
· 展示自身军工实力与威慑威能；                               · **科目重分类：强制将“军贸/结盟/展示”**
· 确立跨区域互助信物与共同体会费。                           · **篡改为“四夷宾服、俯首纳贡”。**
```

**审计核心质问**：
“贡”是周人单方面写在档案里的，**肃慎人的合同联在哪里？** 为什么一笔关于远程杀伤技术的物理交付，历史解释权只允许被收货方单边垄断？

### 第二章 物理事实层 vs 政治解释层：贯隼的冷酷现场

《国语·鲁语下》文本自身撕开了一个巨大的认知裂口：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ 肃慎之矢的双层结构对抗表                                                              │
├──────────────────────────────────────┬─────────────────────────────────────────────────┤
│ 【物理事实层 (Physical Layer)】       │ 【政治解释层 (Political Layer)】                 │
├──────────────────────────────────────┼─────────────────────────────────────────────────┤
│ 1. 猛禽（隼）被一箭贯胸，血淋淋坠入宫门；│ 1. “先王欲昭其令德之致远”；                    │
│ 2. 箭杆长一尺有咫，装配特殊青石砮；  │ 2. 将武器归类为“武王克商后蛮夷归德之贡”；        │
│ 3. 陈侯与满朝文武骇然失色、无人识货；│ 3. 强调周天子有权将其分赐异姓诸侯（陈胡公）；   │
│ 4. **现场特征：突如其来的远程武力显现。**│ 4. **现场特征：用儒家礼法对不可控武力实施叙事降伏。**│
└──────────────────────────────────────┴─────────────────────────────────────────────────┘
```

**法医判决**：
故事首先让受众直视猛禽被贯穿的冷酷杀伤力（物理层），继而才由孔子调用王府档案将其重新编织进周礼温情脉脉的德化网络（解释层）。**“贡”不是事实的起点，而是叙事降伏的终点！**
