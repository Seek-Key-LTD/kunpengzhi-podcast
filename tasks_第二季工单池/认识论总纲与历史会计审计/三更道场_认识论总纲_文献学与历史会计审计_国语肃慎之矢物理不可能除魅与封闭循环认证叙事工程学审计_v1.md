### 摘要 (Executive Summary)

本案对《国语·鲁语下》“肃慎之矢贯隼坠庭”故事的物理真实性、证据学回路及其背后的政治叙事工程学启动终极历史会计审计。

核心审计成果：
1. **中弹猛禽“长途跨国精准制导”的物理不可能除魅**：
   * 猛禽胸口被“长尺有咫”重型青石砮贯穿，在生物生理学上绝对无法完成从东北黑龙江至河南淮阳数千里的长途飞行并精准坠死在陈侯正庭；
   * 隼系**“负责递送物证的叙事传送带”**，巨箭系**“诱导陈国开库对账的物理钥匙”**；
2. **证据学封闭循环认证（The Circular Authentication Loop）**：
   * 揭示“孔子断言庭箭为肃慎箭 $\to$ 依据陈国旧府藏有肃慎箭 $\to$ 旧府之箭被认定为肃慎箭 $\to$ 再次反向依据孔子口述历史”的**无外部独立背书闭环**；
3. **春秋晚期三大叙事动机与最大收益人分析**：
   * **孔门知识神话**：确立孔子超越列国太史官的“天下首席礼法与军工审计官”神圣地位；
   * **周王室天下追认**：在礼崩乐坏之际用古物追认极东北“自古向周天子纳贡”；
   * **地缘历史密钥投递**：在近郊近距离投掷，利用建国档案对陈国实施精准心理威慑与历史还魂。

### 第四章 案情物理闭合：恐吓包裹模型（Threat-Package Model）

**隼不是自己带着箭飞进陈侯院子的；它是被人在野外射杀以后，连尸带箭作为"恐吓包裹"投进高墙的。**

否则传统解释存在两个根本矛盾：

1. 游隼警觉、迅疾，不会老老实实蹲在侯府屋檐上等人近距离发射一支异常长大的楛矢。
2. 已被石砮贯穿致死的隼，更不可能从肃慎方向飞越数千里，恰好死在陈侯庭院。

一旦把它理解成一次**人工投递**，所有部件便各归其位：

| 部件 | 实际功能 |
|---|---|
| 被贯穿的游隼 | 信封，同时展示射手能力 |
| 留在尸体中的楛矢石砮 | 正文，也是发送者签名 |
| 陈侯之庭 | 指定收件地址 |
| 高墙投递 | 匿名、越过外交礼仪的威吓 |
| 故府金椟中的旧箭 | 用于验明发送者身份的历史底样 |
| 孔子 | 唯一能够读取这套商人密码的人 |

所以孔子那句"**隼之来也远矣**"也具有双层意思。陈人以为说的是鸟飞得远；孔子真正指出的，是**这封信的发送系统和政治来历很远**。远的不是已经被贯穿的鸟，而是箭的来源以及箭后面的商人网络。

而且这解释了为什么发送者不署名。现代人寄刀片、子弹，也不会附身份证；**器物制式本身就是署名**。陈国如果属于这套东北商人共同体，一见楛木杆、石砮和异常长度就应该立即读懂。结果满朝无人认识，反而证明**陈国只是保存了周王转交的旧物，并不掌握它背后的族群记忆**。

孔子的作用就更加尖锐了：他不在陈国故府任职，却能在开箱以前断言里面有什么。这不是一般知识，而是一次**身份认证**：

> 陈人有档案而没有密码；孔子没有档案，却拥有密码。

接下来追查陈、宋之间的现实摩擦，方向也不能再宽泛地查"有没有战争"，而应集中在：

* 商旅是否遭到扣押或征敛；
* 陈国是否封锁、改道或抽取商路利益；
* 宋人、商裔是否在陈境受到侵害；
* 陈宋之间是否存在人口、货物或政治难民纠纷；
* 事件是否发生在孔子居陈的年代窗口附近。

《左传·哀公三年》明确记着"孔子在陈"，同年经文又记"宋乐髡帅师伐曹"；宋国继续扩张商路与外围控制，陈国则夹在吴楚争夺中。这至少给出一个非常具体的背景：**宋正在扩张商路与外围控制，陈正在政权和交通安全剧烈动荡的节点上。** 但现存编年史尚不能仅凭这几句锁死某一桩陈宋贸易案，**不能凭空补案名**。
（**注**：陈宋旧账的更早一端，见**第六章 · 宋文公厚葬案**——宋文公靠行贿获诸侯承认，而陈国正是当年讨宋联军成员之一。哀公三年一段属**宋景公**在位期，与宋文公相隔百余年，勿混。）

就《国语》内部的案情而言，确实已经极其清晰：

> 有人先在野外射杀游隼，再把带箭尸体投进陈侯庭院；陈人看见恐吓信却不识发送者，孔子凭商裔记忆指出旧档所在；开金椟比对以后，发送系统完成认证。

因此它不是"神鸟携贡矢从东北飞来"，而是一场**标准的地下政治通信**。**隼是包裹，箭是口信，金椟是旧底档；真正需要寻找的，只剩这封恐吓信所催讨的那笔陈宋旧账。**

### 第五章 训诂与验尸：为什么传统解释没有进入"案情"

传统语料几乎只完成了"**训诂**"，没有真正进入"**案情**"。它通常把这段压扁成三句话：

* 肃慎向周朝进贡楛矢石砮；
* 一只中箭的隼从远方飞到陈国；
* 孔子凭博学认出古物。

**每个字都解释了，整件事却没有解释。** 它完全不追问：

* 被石箭贯穿的隼怎么可能远距离飞行？
* 为什么尸体精准落入陈侯的高墙庭院？
* 为什么表达臣服只送箭，不送弓？
* "贡"是谁给这件物品定的性？
* 周王为什么把威胁物转交陈国？
* 陈国既保存原件，为什么举国无人认识？
* 孔子为什么不仅认识，还能预言故府库存？
* 作者为什么必须安排一次"开金椟、取旧矢、比对相同"？

传统解释实际上是把所有异常分别塞进几个现成抽屉：

> 远方来物＝贡品；古怪事件＝祥异；孔子破案＝博学。

这样做**没有解释任何因果，只是给每个名词贴了标签**。

而"验尸式"读法，是把文字当作一份**经过删节、伪装和官方改写的案卷**，重新追问四件事：

1. **物理上如何发生**：隼在野外被射杀，随后作为载体投进侯府。
2. **信息如何编码**：尸体是信封，楛矢石砮是正文兼署名。
3. **权力如何改写**：周室把"军事警告"铭刻为"贡矢"，完成政治语义洗白。
4. **谁拥有解码能力**：陈人有实物而失去记忆；商人后裔孔子没有实物却能准确定位旧档。

所以"**微言大义**"不是在字缝里随意联想，而恰恰是一种**严格阅读**：作者不明说动机，却把动机所必需的**物证、地点、转手记录、身份差异和最终复核**全部留齐。读者必须把这些离散信息重新装回同一条因果链。

**分野**：传统注释解释了**词义**；验尸式读法解释的是**作者为什么偏偏要写这些词**。前者读的是**周王朝整理过的案卷摘要**——看到"贡"便沿"贡品"继续推演，却**没有先审讯这个"贡"字是谁刻的、何时刻的、为何要刻**；后者去验尸。

### 第六章 并账：宋文公墓的"蜃炭"——宋国水域经济与商式王陵工程

> **【人物对账 · 防串】**：**宋文公**（卒于前 589 年，《左传·成公二年》"始厚葬，用蜃炭……"）与**宋景公**（前 516–前 451 年在位，《左传·哀公三年》"孔子在陈"）是**两个不同的人、两个不同的年代**，不得混为一谈。本章材料属**宋文公**。
> 另需校正：通常进入"**春秋五霸**"名单的是**宋襄公**，不是宋文公；宋文公是宋襄公的**孙辈**。三者勿混。

原文（《左传·成公二年》）：

> 八月，宋文公卒。始厚葬，用蜃炭，益车马，始用殉，重器备。椁有四阿，棺有翰桧。
> 君子谓："华元、乐举，于是乎不臣……君生则纵其惑，死又益其侈……"

原字通常作"蜃炭"；后世常将它解释为焚烧大蛤壳所得的蜃灰，或墓中蜃灰、木炭组合的防潮层。

**第一层 · 一整套地下防腐工程**
蜃壳的主要成分是碳酸钙。经过高温煅烧成为生石灰，再经吸水、熟化和重新碳酸化，可以形成：吸湿层／强碱抑菌层／防虫层／密封加固层／墓室内相对稳定的微环境。如果"蜃炭"还包含大量木炭，两种材料正好分工：蜃灰负责密封、杀菌、隔水，木炭负责吸湿、吸附腐败气体。**它不是在墓墙上刷一层白颜色，而是把整个墓室做成一个巨大的地下保存容器。**

**第二层 · 被一句话压缩掉的工业体系**
一座诸侯级大墓要铺设足够厚的蜃灰层，需要的不是几篮子贝壳，而是成吨乃至更大数量的原料。这意味着背后至少存在：

> 捕捞或采集 → 清理堆积 → 集中运输 → 建窑煅烧 → 控温供燃料 → 粉碎筛选 → 墓坑分层夯筑

所以"用蜃炭"四个字，实际记录的是**捕捞业、窑业、燃料业、运输业和大型地下工程的总承包**。左丘明没有画施工图，却把核心材料清单留下来了。

**第三层 · 宋国真正的水域经济底盘**
宋都在商丘一带，并非通常想象中的海滨城市。倘若墓中采用的是海生大型贝类，那么这不是一件轻巧的珍宝，而是**大宗低单位价值建材从海滨向内陆持续运输**，证明宋国拥有一条相当成熟的**沿海—淮泗—内陆物流网络**。即便部分蜃来自孟诸泽、泗水水系等淡水湿地，结论仍然相近：宋国不是一块封闭农田，而是**控制着大泽、水道、贝类资源和重货运输的商业节点**。
这与"宋是商人之后"发生了**物证咬合**。不是仅凭"商人"二字玩同音，而是宋国王陵的建筑材料本身就在透露：**这群人仍然能够调动跨水域的大宗商品网络。**

**第四层 · 一套商式王陵规制的回潮**
左丘明不是只写"蜃炭"，而是故意把它和另外几项并排：

| 记载 | 暴露的制度 |
| --- | --- |
| 用蜃炭 | 大型地下防腐与密封工程 |
| 益车马 | 交通、军事及身份资产随葬 |
| 始用殉 | 重新启用人身占有与殉葬制度 |
| 重器备 | 青铜礼器等国家级重资产齐备 |
| 椁有四阿 | 带四面坡顶结构的建筑式椁室 |
| 棺有翰桧 | 高等级棺饰与木作体系 |

把这些拼起来，它不像一个暴发户临时多塞几件陪葬品，而像宋国这支商王室后裔，**重新调出了某套古老王陵工程标准**。

**第五层 · 批评对象其实也被故意挪动了**
《左传》表面并不是直接骂死人，而是骂华元、乐举"不臣"："生则纵其惑，死又益其侈。" 这句话证明这座墓**不是宋文公死前一个人偷偷设计的**——它需要宋国执政集团、工匠系统、物资系统共同执行。左丘明借"臣下没有劝阻"进行道德批判，却顺手保存了一张**国家工程能力清单**。
这正是最需要小心的地方：**道德评语可能是保险箱，真正的历史数据被藏在罪状清单里。**
普通读法只得到："宋文公厚葬，非常奢侈。"
但"蜃炭"一旦展开，得到的是：**宋国掌握贝类资源、大宗水运、高温煅烧、复合防潮、地下密封和大型墓室营造；其商式人殉、重器与建筑式椁室又在宋文公葬礼中成套出现。**

**并账**：宋文公本人即位时还有一笔值得并账的旧账：他是在**宋昭公被杀后上位**；晋、卫、陈、郑曾组成联军讨宋，后来宋文公通过**行贿**获得承认。二十多年后，他的墓葬又显示出极强的物资调动能力。于是"**宋国的商业财富—诸侯受赂—陈国介入—商人网络**"并不是彼此孤立的几条材料。
所以真正的信息量不只是"宋国有钱"，而是：

> **左丘明借一句批判厚葬的话，泄露了宋国仍然拥有一套可以把水域资源、工业窑炉、远程物流、商式礼制与国家工程组织起来的完整系统。**

**待验〔悬〕**：如果未来真能确定宋文公墓的位置，最值得检测的甚至不是金玉，而是这层"蜃炭"——**贝壳种属与锶氧同位素**可以回答它来自近地湖泽还是远方海岸；**木炭树种**可以反推燃料供应半径。那一个"蜃"字，确实有可能直接拉出宋国整张水运贸易地图。

### 第七章 专项验证：紫海蜗牛假说的三道证明与档位审计

**结论先给**：**宋文公墓目前没有被可靠识别或正式发掘，因此没有墓墙颜色、蜃炭残留或装饰照片可供比对。** 所以"墓内是否呈紫色"现在**无法从实物回答**。

**人名校正**：死后"用蜃炭"的是**宋文公**；通常进入"春秋五霸"名单的是**宋襄公**，不是宋文公。宋文公是宋襄公的**孙辈**。

**故城与发掘现状**：商丘的宋国故城已经定位，面积约 10.5 平方公里；2021 年以来的发掘主要集中在城墙、城门和"城摞城"地层，最深处受黄河沉积与历代城址叠压，公开成果**没有宣布发现宋文公墓**。目前甚至有论文专门用其他春秋墓葬来反推宋文公的葬礼，恰恰因为**缺少能够确认属于宋文公的墓葬本体**。

至于"紫海蜗牛＝蜃＝墓内紫色"，这里需要分成**三道证明**，不能一步跨完。

**第一道 · 紫海蜗牛是不是"蜃"？**
有一个很漂亮的行为学咬合点：*Janthina janthina* 终生漂浮于海面；用黏液包裹空气形成气泡筏；大量聚集时确实呈现"海面有物吐泡成气"的视觉效果；其反荫蔽紫色又非常醒目。这比"大蛤凭空吐出一座城市"更有生物学解释力。
但**它目前还不是已经完成的物种鉴定**。先秦经注通常把"蜃"解释成"蚌蛤之属"，而紫海蜗牛只有约四厘米、壳薄如纸，与"大蛤"的传统形态不完全相符。要坐实，需要至少出现一项：

* 宋墓蜃炭中的腹足类壳体微结构；
* 可鉴定的螺旋壳碎片；
* 古代图像呈现紫海蜗牛的反荫蔽、气泡筏；
* 古代产地、季节和搁浅记录与 *Janthina* 洋流分布吻合。

**它是一个值得专项验证的候选，不是凭行为相似便已结案。**

**第二道 · 紫壳烧成灰以后还会不会紫？**
这是目前**最大的物理障碍**。*Janthina* 的壳虽然呈紫色、活体还会释放可染色的紫色分泌物，但"紫壳"与"紫灰"并不是一回事。《左传》作"用蜃炭"；杜预解释为：

> "烧蛤为炭，以瘗圹。"

也就是需要煅烧。贝壳主体是碳酸钙；达到制灰温度以后，壳内有机色素通常会分解、碳化或烧失，所得氧化钙／氢氧化钙主要趋向白色或灰白色。**紫色并不会因为原壳紫，就自动保留在灰浆里。**
即使拿著名的"泰尔紫"作比较，其紫色也来自骨螺腺体中的有机溴靛类物质，**不是把紫色螺壳烧成灰以后得到的**；高温反而会破坏染料。
因此：**若宋文公墓只是使用煅烧蜃灰，墓墙呈持久紫色的概率不高。**
要形成紫色墓室，至少还需要一道独立工序：将未经煅烧的紫壳研粉作为表层骨料／提取活体紫色分泌物作为颜料／在白色蜃灰层上另施紫色涂层／或镶嵌大量完整紫壳，使其产生珠光紫效果。

**第三道 · 即便墓室是紫色，是否代表宋文公自认王者？**
这个方向有可能，但**不能只凭"紫"直接定性**。春秋时期紫色已经可以成为高贵、奢华和权力颜色（著名的"齐桓公好紫"便说明它具有强烈身份溢价）；但"紫＝天子专属正色"并不是整个先秦始终不变的礼制公式。
宋文公葬礼的僭越证据实际上来自**整个组合**：

> 蜃炭＋大量车马＋人殉＋重器齐备＋四阿之椁＋翰桧之棺。

后世经注甚至直接说"始用蜃炭，言僭天子也"。也就是说，**即使墓墙最终是白色，宋文公仍然在调用接近王礼的葬制**。倘若将来再发现紫色墙面或紫壳镶嵌，那才会成为额外的一层王权自我定位。

**审计结果**：

| 命题 | 状态 |
| --- | --- |
| 宋文公墓已经找到 | 否 |
| 已知墓墙颜色 | 否 |
| *Janthina* 会制造气泡筏、漂浮海面 | 是 |
| *Janthina* 可作为"蜃"的动物学候选 | 可以 |
| 已证明古代"蜃"就是 *Janthina* | 尚未 |
| 紫色螺壳烧灰后仍呈紫色 | 化学上很可疑 |
| 宋文公葬礼具有僭越王礼倾向 | 文本证据很强 |
| 紫色墓室表达王权 | 若发现实物，可以成立为强解释 |

**破案靶点**：不是泛泛寻找"豪华墓"，而是寻找**前 589 年前后的宋国君主墓**，检测墓圹填料中的**壳体微结构、色素残留和元素组成**。如果发现大量 *Janthina* 壳片，而且不是完全煅烧，而是作为**紫色表层或镶嵌材料**使用，那么"宋文公以紫自居"的案子才会真正钉死。

### 第八章 断句审计："蜃炭"是一个词，还是"蜃、炭"两项材料？

**（一）"炭"≠"碳"：不许倒推古人知道元素 C**
原文作"蜃**炭**"，不是现代化学的"蜃**碳**"。两字同音，概念形成时间却完全不同："**炭**"是古字，指木材等经过不完全燃烧后形成的具体物质，也可泛指经过火加工的灰炭；"**碳**"是近代为了表示化学元素 carbon（C）而专门分化出来的科技用字——借"炭"表音，再加石旁表明元素类别。
因此，现代人把贝壳写成"碳酸钙"，**并不是古人先知道它含有元素碳、所以称其为"炭"**；恰恰相反，是现代"碳"字后来借用了古代"炭"的读音。
所以：**"蜃炭"与现代"碳酸钙"在今天看起来音义巧合，不能倒推成 2500 年前已有元素 C 和 CaCO₃ 的化学概念。**

**（二）真正未结案的：中间该不该加一个顿号？**
古书没有现代标点，可以存在两种断法：

| 断法 | 含义 |
| --- | --- |
| 用"蜃炭" | 把蜃壳烧成一种灰炭，即蜃灰 |
| 用"蜃、炭" | 同时使用蜃壳材料和木炭，两种不同墓葬填料 |

杜预选择第一种，注为："烧蛤为炭，以瘗圹。"但后世确实有人反驳：周礼体系里本来分别设有"**掌蜃**"和"**掌炭**"，因此《左传》的"蜃炭"可能就是"蜃与炭"两项并列材料，而非"用贝壳烧出碳"。现代研究也把这两派解释明确列出，**并没有完全定案**。
如果采用第二种解释，上一轮"贝壳必定经过高温、紫色必定毁掉"的判断就不成立。可能的墓葬结构会变成：一层蜃壳或蜃壳粉／一层木炭；二者分别承担封闭、吸湿、装饰或礼制功能。这样，**"紫色是否被保留"确实要重新打开，不能提前判死刑**。

**（三）若第一种解释成立：烧制的工程作用很明确**

$$\mathrm{CaCO_3 \xrightarrow{\Delta} CaO + CO_2}$$

贝壳中的碳酸钙经高温煅烧成为氧化钙（生石灰）；加水后成为氢氧化钙：

$$\mathrm{CaO + H_2O \rightarrow Ca(OH)_2}$$

随后重新吸收空气中的二氧化碳，硬化成碳酸钙：

$$\mathrm{Ca(OH)_2 + CO_2 \rightarrow CaCO_3 + H_2O}$$

因此**煅烧不是为了得到黑色"碳"，而是把惰性的硬壳转化成具有反应性和胶凝能力的石灰**。它可以：填满墓圹缝隙／凝结成密封层／吸水并抑制微生物／提供强碱环境／最终硬化成壳状保护层。
**所以烧制在工程上很有用，但在保留紫色方面确实适得其反。**

**（四）一条旁证：蜃制材料在别的传统里追求的是"白"**
《周礼·掌蜃》还出现"**白盛之蜃**"，经注解释成用蜃灰把器物或墙面饰白。这意味着**至少在一条古代工艺传统里，蜃制材料追求的是白，不是紫**。

**（五）目前最精确的结论**
1. "炭"不能证明古人知道元素 C 或"碳酸钙"这个分子概念。
2. 杜预确实把"蜃炭"读成烧壳所得的灰，但这不是唯一读法。
3. 如果是烧壳制灰，工程用途很大，紫色基本难以保留。
4. 如果是"蜃、炭"两项并列，贝壳可能未经煅烧，那么紫壳装饰假说仍然有空间。
5. 要真正判决，只能靠墓葬材料。

**（六）实物判决法（＝开箱条件）**

| 检测所见 | 判决 |
| --- | --- |
| 壳体层状微结构还在 | **未烧**（支持"蜃、炭"二物说） |
| 只剩再碳酸化石灰晶体 | **烧过**（支持"蜃炭"一物说） |
| 木炭另成独立层 | 支持"蜃、炭"二物说 |

**方法论自记**：这一轮真正被逼出的，是上一轮**未经说明就采用的前提**——把杜预的"烧蛤为炭"当成了唯一解释。**真正尚未结案的，是"蜃炭"中间到底应不应该加一个顿号。**

### 第九章 时间层级审计：杜预注是西晋解释传统，不是春秋现场证词

**杜预甚至不是东汉人，而是西晋人。** 时间层级一拉开，"杜注＝春秋现场说明"这件事就显得非常危险。

这里至少叠了**四层完全不同的东西**：

| 层级 | 内容 | 与事件的距离 |
| --- | --- | ---: |
| 春秋事件层 | 宋文公葬礼实际用了什么 | 现场 |
| 《左传》记述层 | "用蜃炭"四字 | 已经过选择与压缩 |
| 两汉传本层 | 经学师承、抄本、今古文学争论 | 数百年 |
| 杜预注释层 | "烧蛤为炭，以瘗圹" | 距事件约八百年 |

杜预所做的事情，是**从"名"直接跨到了"实"**：

* 原文只留下名称：蜃炭。
* 杜预加入不存在于原文的动作：**烧**。
* 又加入不存在于原文的物态：**灰**。
* 再加入用途判断：**瘗圹**。
* 后人随后把整套推演倒灌回春秋现场。

**这已经不是简单训诂，而是在替缺失的工艺档案写说明书。**

**关于西汉—东汉之间的断裂**：严格说，新莽覆亡前后不是"王莽本人纵火毁掉长安"，而是公元 23 年绿林军攻入长安、宫室起火、王莽被杀，随后赤眉入关等连续战争又进一步摧毁城市与档案系统。无论责任怎样细分，结果都是：**西汉国家机器、皇家藏书、技术官僚传承和都城物质档案遭到了巨大断裂。**

到了东汉以后，人们可能还保留：经文／器物名称／礼仪名目／零散操作口诀；**却已经不知道它们最初对应的具体实物和生产程序**。于是便不断发生：

> **名还在，实已亡；后人依据自己时代的"实"，重新解释前代的"名"。**

杜预又晚于东汉覆亡。他面对的不是完整西汉档案，而是经过新莽之乱、东汉经学重构、汉末党锢、黄巾、董卓焚洛阳以及魏晋改朝换代之后的文本残余。他当然可能保存了古说，**但不能因为写进注疏，就获得跨越八百年的现场证人资格。**

**与"丹朱案"同法**：**先不接受后人告诉我们的"这是谁"，而是追问这个字最初到底在指什么。**
"丹朱"如果被后世先定义为一个人的固定姓名，后续所有材料就都会围绕"尧有一个叫丹朱的儿子"自我闭合；但如果一个字已经暴露"丹"与"朱"之间是**颜色、物质、职能或称号关系**，那么所谓姓名可能只是后代把一个描述性名号**人格化**的结果。
现在"蜃炭"也是一样：

> 原文究竟在列举两项实物——"蜃、炭"，还是在命名一种叫"蜃炭"的材料？

**只差一个后世标点，整个物质世界便不同。** 杜预为了把它解释成单一材料，实际上必须**偷偷补进"烧"这个动词**。可左丘明没写"烧蜃为炭"，也没写"蜃灰"，只写了"用蜃炭"。

因此最稳妥的态度不是宣布杜预必错，而是把他的注释**降级**：

> **杜预注是一条西晋解释传统，可以作为证词；不能作为春秋工艺事实。**

而且**越是经历过档案毁灭的时代，后世注家越容易把"自己所能理解的用途"误认为"古人唯一可能的用途"**。这就是为什么必须反复强调名实关系：**真正的文明断层不会把所有字都烧掉，它最常留下的，恰恰是失去实物对应关系的名字。** 后人仍能朗朗上口，于是误以为知识从未中断。
