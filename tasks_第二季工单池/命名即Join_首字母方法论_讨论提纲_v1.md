## 一、这笔"欠论文"的账

首字母理论（Initial Feature / 首部特征，"K 系网络"所依赖的认知起点）在天权记 192 已经"开刃"，道名记卷首立了"命名权力学"的纲，但**始终缺一篇把方法论立规矩的论文**。现拟题：

**《命名即 Join》**

> 一个荒诞市场案例破门 → 提出"首部特征 = 低认知成本的 Candidate Join Key" → 把词源树降格为"强关系的一种" → 给出命名权力学、商业扩张与可审计数据库模型。

## 二、核心命题（全篇承重墙）

1. 名称不必与对象存在实体关系，仍可成为群体协调行动的接口；**弱关联未必是真相，却可以制造真实**。
2. 首部特征（Initial Feature）＝ 低认知成本的 **候选 Join 索引（Candidate Join Index）**；不是主键，不是同源证明。
3. 命名不只是表征——**命名是一种 Join 操作**。
4. 一个成熟的历史数据库，不以"把所有东西解释掉"为能力；**以能把无法证明的关系诚实留在"未知"栏为能力**。

## 三、立论结构（八章 + 结语）

- 导论 0.1：A 股谐音涨停破门（奥巴马-澳柯玛 / 川普-川大智胜）
- 第一章：反对"拼写即实体"（账名≠资产；汉字错字可还原；无录音≠可把拼写当声波）
- 第二章：共价键的有效边界（PIE 不是原罪；对"大馅饼 PIE"定向批判）
- 第三章：范德华力——弱连接（Initial Feature ≈ 候选召回器，不是裁决器；认知成本定义）
- 第四章：命名即 Join（名称=社会接口；命名政治经济学；命名权力学）
- 第五章：从单树到多表 Join（数据模型：节点/边/证据向量）
- 第六章：反格林伯格协议（Candidate Recall ≠ Cognacy Claim；允许"未知"；不许脑中黑箱 Join）
- 第七章：可证伪预言与实验设计（R_onset > R_medial/R_final；零模型；贸易半径预言；A 股快速实验场）
- 结语落款：**命名不只是表征；命名是一种 Join 操作。**

## 四、四项写作原则（agents 也必须守）

1. 不把"首字母"说成主键，只说候选索引；
2. 不把"K 网络"说成同源证明，只说待审计的弱连接候选；
3. 不把"商业解释一切"说成总因，只说命名扩张的重要底层驱动变量；
4. 不把 PIE 整体骂成无效，只批判其越界外推、单向 Join 与解释权垄断。
