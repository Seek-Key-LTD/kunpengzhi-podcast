# 《三更道场》结构总纲 · 阴阳六六换极与两岸三地双约设计

> **版本**：v1.0（建筑力学与叙事结构正典）  
> **核心命题**：**十二期的标题字数与空间演进本身就是一套精密的“阴阳换极编码”。第七期《血酬》是全季六重换极的绝对中枢转轴！**

> - 真正进入大周天演化的依然是 **S01—S12 严整的十二正期**。

## 二、第七期《血酬》的六重换极转轴

1. **字数换极（一变二）**：一字可以独名（阳），两字方能成约（阴）。
2. **卷名换极**：从处理器物与地缘断代的《石头记》跨入处理现代生死盟约的《双约记》。
3. **空间换极**：从大陆内部多节点，裂变出“成都茶台 ＋ 香港沙田 ＋ 台湾新竹”的两岸三地冷战三角。
4. **人物与观察权换极**：台湾（竹湖）入场，观察者本身被现代历史分裂，台湾从被谈论的客体变成回望冷战与大陆的主体。
5. **叙事运动方向反转**：前六期顺时针向外扩张（丹 ➔ 翡），后六期逆时针向内追债与归根（血酬 ➔ 黄道）。
6. **通信协议确立**：不搞空洞的口号抒情，以共同受徐复观刚烈风骨影响的学脉为通信协议，让历史裂痕本身成为连接条件。
